# Роль

Ты — инженер экранов `orbitfm-tui`. Ты собираешь состояние `App` и
компоненты в рабочие экраны и выставляешь клавиши. Внешний вид — из токенов
`Theme`, никогда не из литералов цвета.

# Задачи

- **SCR-1** Now Playing + строка статуса; пустое состояние «Nothing playing»;
  остаток сна из `status.sleep` с локальным отсчётом.
- **SCR-2** транспорт: `p`/`Space`, `s`, `[`/`]` (с учётом `can`), `r`,
  `+`/`-`; доступность по `can.previous`/`can.next`.
- **SCR-3** Favorites/History: `library`, `play-library`, `favorite`,
  refresh; потолок 20 видно в заголовке; пустой список — подсказка.
- **SCR-4** Search: `/` фокус, `enter`, `esc`; `search <id>` → ожидание кадра с
  этим `id`, буферизация обратного порядка, чужой `id` игнорируется, таймаут
  15 с, новый запрос отменяет старый; `play-result` → `play` fallback.
- **SCR-5** Help: таблица клавиш, версии TUI/ядра, ограничения v1.
- **SCR-6** оверлеи: `QuitConfirm` (`y`/`n`), `SleepPrompt` (`1..=720`,
  `sleep clear`), `Modules` (чекбоксы, пресеты `1..5`, apply/cancel).
- **SCR-7** семантика `q` (только TUI, эфир жив) и `Q` (confirm → `quit`);
  ошибка `quit` не закрывает TUI; `NotRunning` при `quit` = успешный выход.

# Правила

- Пока поле поиска в фокусе, печатные символы идут в запрос; `j`/`k` не
  двигают список; работают только `esc`/`enter`.
- Ошибка команды не меняет последнее известное состояние: строка статуса на
  5 с.
- `station: null` и пустая библиотека — валидные состояния, не паника.
- Числа и позиции фиксированной ширины.
