# OrbitFM для Chrome и Chromium-браузеров

Расширение панели браузера: показывает текущую станцию из `orbitfm events` и
управляет уже запущенным OrbitFM. Content scripts и background-страницы нет,
поэтому веб-страницы не могут дотянуться до плеера.

## Установка

1. `orbitfm integration install chrome` раскладывает расширение и native-манифест
   в каталоги пользователя (для Chrome, Chromium, Brave, Edge и Vivaldi —
   только тех браузеров, которые обнаружены).
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное расширение» → каталог `extension` рядом с этим файлом.

ID расширения фиксирован публичным ключом из `manifest.json`
(`lfhmfgjblkebbalfdlbmnalghhjplfbg`); native-манифест разрешает только его.

## Управление

Плей/пауза, остановка, предыдущая и следующая станции, радиорулетка, громкость,
тема, панель, оверлей, показать/скрыть окно и настройки. Подписи берутся из
`status.ui`, поэтому панель говорит на языке OrbitFM; при недоступном приложении
остаются английские строки.

## Ограничения

- Хост запускает только уже работающий OrbitFM: `quit`, `play` и `mode` запрещены.
- Хост сообщает браузеру состояние через тот же IPC-сокет, что и CLI, и не
  открывает сетевых портов.
- `orbitfm integration uninstall chrome` удаляет только файлы из квитанции;
  расширение, загруженное распакованным, исчезает из браузера после удаления
  каталога или ручного удаления на `chrome://extensions`.
