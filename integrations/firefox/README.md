# OrbitFM для Firefox

Расширение повторяет выпадающую панель OrbitFM: текущая станция, транспорт,
громкость, темы, поиск по Radio Browser, избранное и история. Content scripts и
background-страницы не регистрируются: доступ к вкладке выдаётся только на клик
«Play this page» через `activeTab` и `scripting` (Firefox 109+).

## Установка

1. `orbitfm integration install firefox` раскладывает расширение и native-манифест
   `~/.mozilla/native-messaging-hosts/org.modernbyte.orbitfm.json`.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. «Загрузить временное дополнение» → `manifest.json` в каталоге `extension`.

Временное дополнение действует до перезапуска Firefox. Постоянная установка
требует подписи Mozilla и в этом репозитории не публикуется; ID расширения —
`orbitfm@modernbyte`, он же разрешён в native-манифесте.

## Управление

- Карточка станции с избранным, транспорт, громкость и переключение темы.
- Вкладки «Поиск», «Избранное» и «История»; поиск идёт через companion-контур и
  не открывает окно приложения.
- «Play this page» сканирует активную вкладку (`og:audio`, `<audio>`, `<source>`)
  и передаёт выбранный адрес команде `play-url`: HLS отклоняется, LAN-адреса
  разрешены только по этому явному действию.
- Подписи берутся из `status.ui`, поэтому панель говорит на языке OrbitFM; при
  недоступном приложении остаются английские строки.

## Разрешения

`nativeMessaging`, `activeTab`, `scripting`. `host_permissions` нет, фоновых
скриптов нет: без клика пользователя расширение не читает вкладки и не ходит в
сеть. Приложение по-прежнему принимает только уже работающий процесс: `quit`,
`play` и `mode` запрещены, играть можно результат поиска, элемент библиотеки или
явно выбранный URL страницы.

## Ограничения

- Хост сообщает браузеру состояние через тот же IPC-сокет, что и CLI, и не
  открывает сетевых портов.
- `orbitfm integration uninstall firefox` удаляет только файлы из квитанции;
  временное дополнение исчезает из Firefox после перезапуска.
