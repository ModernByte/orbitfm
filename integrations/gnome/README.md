# OrbitFM для GNOME Shell

Расширение панели для GNOME Shell 45–51. Установка:

```
orbitfm integration install gnome
gnome-extensions enable orbitfm@modernbyte
```

На Wayland после установки может понадобиться выйти из сеанса и войти снова:
GNOME Shell сканирует каталог расширений при старте. `stylesheet.css`
загружается Shell автоматически вместе с расширением.

## Управление

Кнопка в панели открывает меню:

- карточка текущей станции: имя, страна/битрейт, теги и точка состояния;
- транспорт с символическими иконками: пуск/пауза, предыдущая, следующая,
  стоп, радиорулетка;
- громкость `Volume · NN%` и шаги `Volume up` / `Volume down`;
- подменю темы: системная, тёмная, светлая (текущая отмечена точкой);
- подменю «О станции»: добавить/убрать избранное и открыть домашнюю страницу,
  если она начинается с `http(s)://`;
- показать/скрыть окно и настройки.

Название станции и громкость видны в панели. Подписи приходят из
`orbitfm status --json` (`ui`), поэтому расширение не дублирует переводы
приложения. Цвет панельной подписи отражает состояние: играет, пауза,
загрузка, ошибка.

## Как это работает

Раз в 2 секунды расширение запускает `orbitfm status --json` через
`Gio.Subprocess` и разбирает JSON. Команды передаются тому же бинарнику:
`playpause`, `previous`, `next`, `stop`, `roulette`, `volume-up`,
`volume-down`, `theme …`, `favorite`, `toggle` и `settings`. Домашняя
страница открывается системным обработчиком URL только по явному клику.
Если OrbitFM не запущен, кнопка показывает «OrbitFM»; второй экземпляр не
запускается.

Удаление:

```
orbitfm integration uninstall gnome
```
