# OrbitFM для Plasma 6

Виджет панели Plasma 6. Установка:

```
orbitfm integration install plasma6
kbuildsycoca6 --noincremental
```

Затем ПКМ по панели → «Добавить виджеты» → OrbitFM. На Wayland при
необходимости перезапустите Plasma.

## Установка из релиза (.plasmoid)

В разделе Releases лежит готовый `OrbitFM-<версия>-plasma.plasmoid`:

```
kpackagetool6 -t Plasma/Applet -i OrbitFM-0.16.0-rc.3-plasma.plasmoid
```

Или в режиме редактирования панели: «Добавить виджеты» → «Установить из
файла». Архив вызывает `orbitfm` из `PATH`, поэтому команда должна быть
доступна; установщик `orbitfm integration install plasma6` подставляет
абсолютный путь сам. Обновление — `kpackagetool6 -t Plasma/Applet -u`,
удаление — `kpackagetool6 -t Plasma/Applet -r org.modernbyte.orbitfm`.

## Управление

Компактный вид — стеклянная пилюля с иконкой, названием станции и точкой
состояния (играет, пауза, загрузка, ошибка).

Полная карточка виджета:

- карточка станции: монограмма, имя, страна/битрейт, два тега и избранное;
- транспорт с символическими иконками: предыдущая, пуск/пауза, стоп,
  следующая, радиорулетка;
- слайдер громкости с процентом; значение отправляется при отпускании;
- переключатель темы: системная, тёмная, светлая;
- кнопка OrbitFM открывает выпадающую панель, рядом — показать/скрыть окно
  и настройки.

ЛКМ по пилюле — пуск/пауза, ПКМ — панель, колесо — громкость.
Подписи берутся из `orbitfm status --json` (`ui`), цвета акцента и
состояния — из `status.accent` и `status.state`.

## Как это работает

Виджет опрашивает `orbitfm status --json` через
`Plasma5Support.DataSource` (`executable`) раз в 2 секунды и отправляет
команды тем же бинарником. Своего состояния виджет не хранит. Если OrbitFM
не запущен, виджет показывает «OrbitFM» и не создаёт второй процесс.

Виджет не меняет конфиги Plasma. Удаление:

```
orbitfm integration uninstall plasma6
```
