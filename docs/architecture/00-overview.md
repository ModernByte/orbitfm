## 1. Назначение и область применения

OrbitFM — кроссплатформенное десктоп-приложение (приоритет — Linux), которое предоставляет интерактивный 3D-глобус для поиска и прослушивания интернет-радиостанций из базы Radio Browser.

Приложение работает как **единый процесс** (single-instance) и поддерживает два режима отображения:

- Обычное десктоп-окно (Standalone)
- Режим оверлея / всплывающего окна, управляемый через IPC (основной сценарий — интеграция с Noctalia v5 и другими панелями)

Документ описывает высокоуровневую архитектуру. Значимые решения фиксируются в ADR. Контракты модулей — в каталогах `modules/` и `interfaces/`.

## 2. Приоритетные атрибуты качества

1. **Надёжность** — стабильное воспроизведение с автоматическим переподключением при обрыве потока
2. **Отзывчивость** — UI не блокируется сетевыми и аудио-операциями
3. **Linux First** — качественная интеграция с Wayland-композиторами (Niri, Hyprland) и Noctalia v5
4. **Кроссплатформенность** — поддержка Windows и macOS без серьёзных архитектурных компромиссов
5. **Работа offline** — геоданные и последний известный список станций доступны без сети
6. **Сопровождаемость** — чёткие границы модулей, документированные интерфейсы, решения через ADR

## 3. Архитектурный стиль

- Слоистая архитектура с однонаправленными зависимостями (UI → Application → Domain → Infrastructure)
- Единый процесс с внутренней передачей сообщений
- Immediate-mode GUI (egui) — быстрая итерация, низкие накладные расходы
- Кастомный render pass для 3D-глобуса внутри кадра egui
- Абстракция платформы для IPC, медиа-контролей и правил оконных менеджеров

## 5. Ключевые внешние зависимости (проверено по официальным источникам)

| Задача                 | Решение                          | Обоснование / Источник                                      |
|------------------------|----------------------------------|-------------------------------------------------------------|
| GUI                    | eframe + egui                    | Официальный фреймворк, native Linux/macOS/Windows           |
| 3D внутри egui         | egui-wgpu Callback               | Официальный путь кастомного рендеринга                      |
| Декодирование аудио    | libmpv (обёртка libmpv2)         | Зрелый движок, широкая поддержка форматов, устойчивость к сети |
| Данные радиостанций    | Radio Browser API                | Сообщество, бесплатно, DNS-discovery                        |
| Геопространственные данные | geo + geojson                 | Экосистема GeoRust, Point-in-Polygon                        |
| Медиа-кнопки / MPRIS   | playwire                         | Кроссплатформенный API; Linux — MPRIS v2 через zbus         |
| Интеграция с Noctalia  | plugin.toml + Luau               | docs.noctalia.dev                                           |

## 7. Модель поставки

- Основной целевой артефакт: нативный бинарник для Linux (x86_64 + aarch64)
- Вторичные: Windows и macOS
- Упаковка: AppImage / Flatpak (Linux), MSI/Portable (Windows), DMG (macOS)
- Плагин Noctalia распространяется отдельным каталогом или через каталог плагинов
