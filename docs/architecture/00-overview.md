## 1. Назначение и область применения

OrbitFM — кроссплатформенное десктоп-приложение (приоритет — Linux), которое предоставляет интерактивный 3D-глобус для поиска и прослушивания интернет-радиостанций из базы Radio Browser.

Приложение работает как **единый процесс** (single-instance) и поддерживает два режима отображения:

- Обычное десктоп-окно (Standalone)
- Режим оверлея / всплывающего окна, управляемый через IPC (основной сценарий — интеграция с Noctalia v5 и другими панелями)

Документ описывает высокоуровневую архитектуру. Значимые решения фиксируются в ADR. Контракты модулей — в каталогах `modules/` и `interfaces/`.

## 2. Приоритетные атрибуты качества

1. **Надёжность** — стабильное воспроизведение с автоматическим переподключением при обрыве потока
2. **Отзывчивость** — UI не блокируется сетевыми и аудио-операциями
3. **Linux First** — качественная интеграция с Wayland-композиторами (Niri, Hyprland) и Noctalia v5
4. **Кроссплатформенность** — поддержка Windows и macOS без серьёзных архитектурных компромиссов
5. **Работа offline** — геоданные и последний известный список станций доступны без сети
6. **Сопровождаемость** — чёткие границы модулей, документированные интерфейсы, решения через ADR

## 3. Архитектурный стиль

- Слоистая архитектура с однонаправленными зависимостями (UI → Application → Domain → Infrastructure)
- Единый процесс с внутренней передачей сообщений
- Immediate-mode GUI (egui) — быстрая итерация, низкие накладные расходы
- Кастомный render pass для 3D-глобуса внутри кадра egui
- Абстракция платформы для IPC, медиа-контролей и правил оконных менеджеров

### 4.1 Модули Application Layer (`src/session/`)

Слой владеет всем, что переживает закрытие окна (ADR-0018): скрытие — это
реальное закрытие root-вьюпорта, поэтому `OrbitApp` из presentation-слоя
создаётся заново при каждом показе, а `Session` живёт в `main` и не знает про
egui.

| Модуль | Ответственность |
|--------|-----------------|
| `session` (`mod.rs`) | `Session`: подсистемы, `WindowState`, `WakeHandle`, простой без окна (`park`), двусторонний контракт с UI через `Notice` и `UiIntent` |
| `session::commands` | Исполнение IPC-команд и настроек оформления; ответ клиенту |
| `session::playback` | Воспроизведение, избранное, история, очередь prev/next, витрина MPRIS |
| `session::search` | Поиск по имени/стране/жанру с защитой от устаревших ответов, рулетка |
| `session::park` | Припаркованный цикл `select!`: IPC, MPRIS, трей, аудио, ответ рулетки |
| `session::tray` | Исполнение команд трея и публикация `TraySnapshot` (ADR-0020) |
| `session::markers` | Агрегация станций с координатами в маркеры глобуса |

`src/tray/` — доменный сервис SNI-трея: отдельный `std::thread`, процедурная
иконка и витрина меню; бизнес-логику он не содержит и лишь переводит клики в
`TrayCommand` (ADR-0020).

`src/ipc/` остаётся транспортом (сокет, разбор текста, очередь) и бизнес-логику
не содержит (ADR-0005).

## 5. Ключевые внешние зависимости (проверено по официальным источникам)

| Задача                 | Решение                          | Обоснование / Источник                                      |
|------------------------|----------------------------------|-------------------------------------------------------------|
| GUI                    | eframe + egui                    | Официальный фреймворк, native Linux/macOS/Windows           |
| 3D внутри egui         | egui-wgpu Callback               | Официальный путь кастомного рендеринга                      |
| Декодирование аудио    | libmpv (обёртка libmpv2)         | Зрелый движок, широкая поддержка форматов, устойчивость к сети |
| Данные радиостанций    | Radio Browser API                | Сообщество, бесплатно, DNS-discovery                        |
| Геопространственные данные | geo + geojson                 | Экосистема GeoRust, Point-in-Polygon                        |
| Медиа-кнопки / MPRIS   | playwire                         | Кроссплатформенный API; Linux — MPRIS v2 через zbus         |
| Избранное и история    | serde_json + XDG                 | Небольшой JSON в `$XDG_DATA_HOME`, атомарная запись (ADR-0013) |
| Темы и акцент          | serde_json + XDG                 | Настройки оформления в `$XDG_CONFIG_HOME`, атомарная запись (ADR-0014) |
| UX «Orbital Desk»      | egui + существующий render/geo   | Focus-раскладка, режимы Country/GlobalGenre, контур страны; без новых зависимостей в MVP (ADR-0015) |
| Favicon-аватары        | reqwest + image (png/ico)        | Асинхронный кэш `FaviconCache` в presentation-слое, без новых crate'ов (ADR-0016) |
| Флаги стран            | epaint `color_fonts` + системный Noto Color Emoji | Цветной флаг-эмодзи в тултипе глобуса; feature включается прямой зависимостью, деградация без шрифта (ADR-0017) |
| Интеграция с Noctalia  | plugin.toml + Luau               | docs.noctalia.dev                                           |
| Иконка в системном трее | ksni (SNI/StatusNotifierItem)  | Прямая работа с D-Bus без Qt; опциональная фича `tray` (ADR-0020) |

## 7. Модель поставки

- Проверенный артефакт: AppImage для Linux x86_64 с встроенными libmpv/FFmpeg,
  desktop entry и AppStream-метаданными (ADR-0011)
- Flatpak для Linux x86_64: runtime 25.08, libmpv/libass/libplacebo из исходников,
  vendored cargo-исходники (ADR-0011)
- Исходная сборка: нативный бинарник для Linux (x86_64)
- CI: Linux (`fmt`/`clippy`/тесты), macOS (сборка, тесты и release с libmpv из
  Homebrew), Windows (`fmt`/`clippy`); отдельные джобы собирают MSI (MSYS2 +
  WiX 5) и DMG (`dylibbundler` + ad-hoc подпись) и публикуют артефакты
- Не реализовано: aarch64 Linux, привязка SMTC к HWND и рантайм-проверка
  Now Playing; установщики не подписаны сертификатами и не нотаризованы
- Плагин Noctalia распространяется отдельным каталогом или через каталог плагинов
