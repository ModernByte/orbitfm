## Правила версионирования

- **MAJOR** — несовместимые изменения API / IPC / поведения
- **MINOR** — новая функциональность с обратной совместимостью
- **PATCH** — исправления ошибок и мелкие улучшения

До версии 1.0.0 допускаются breaking changes в MINOR-релизах (с записью в CHANGELOG и ADR при необходимости).
