# Version Map OrbitFM

**Организация:** ModernByte  

Карта версий показывает, какие возможности появляются в каких релизах.

| Версия | Статус       | Ключевые возможности                                      | Примечание                  |
|--------|--------------|-----------------------------------------------------------|-----------------------------|
| 0.0.x  | Завершено    | SRS, ADR, архитектура, ROADMAP                            | Этап документации           |
| 0.1.0  | В разработке | Single-instance, IPC, базовый egui, libmpv play/stop      | MVP-0: каркас готов, аудио — Этап 2 |
| 0.2.0  | Планируется  | Radio Browser discovery + поиск                           |                             |
| 0.3.0  | Планируется  | 3D-глобус + raycasting + выбор страны                     |                             |
| 0.4.0  | Планируется  | Noctalia plugin + window rules Niri/Hyprland                |                             |
| 0.5.0  | Планируется  | MPRIS + базовые медиа-клавиши                             |                             |
| 1.0.0  | Цель         | Стабильный релиз: overlay, избранное, кроссплатформа      |                             |

## Правила версионирования

- **MAJOR** — несовместимые изменения API / IPC / поведения
- **MINOR** — новая функциональность с обратной совместимостью
- **PATCH** — исправления ошибок и мелкие улучшения

До версии 1.0.0 допускаются breaking changes в MINOR-релизах (с записью в CHANGELOG и ADR при необходимости).
