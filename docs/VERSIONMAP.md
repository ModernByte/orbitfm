# Version Map OrbitFM

**Организация:** ModernByte  

Карта версий показывает, какие возможности появляются в каких релизах.

| Версия | Статус       | Ключевые возможности                                      | Примечание                  |
|--------|--------------|-----------------------------------------------------------|-----------------------------|
| 0.0.x  | Завершено    | SRS, ADR, архитектура, ROADMAP                            | Этап документации           |
| 0.1.0  | Реализовано (без релиза) | Single-instance, IPC, egui, libmpv play/pause/stop/volume/reconnect, MPRIS Linux | MVP-0: каркас + аудио (Этапы 1–2) |
| 0.2.0  | Реализовано (без релиза) | Radio Browser discovery + поиск, `play <uuid>`, click-tracking, метаданные станции в MPRIS | Этап 3 |
| 0.3.0  | Реализовано (без релиза) | 3D-глобус + raycasting + выбор страны, поиск станций по стране | Этап 4 |
| 0.4.0  | Реализовано (без релиза) | Noctalia plugin + window rules Niri/Hyprland | Этап 5 |
| 0.5.0  | В работе     | Полировка, кроссплатформа (SMTC/macOS), FFT, упаковка     | FFT, AppImage и Flatpak готовы; остальное заблокировано |
| 0.6.0  | Реализовано (без релиза) | Маркеры станций на глобусе, избранное и история, темы, каталог Noctalia | Этап 7 завершён; плагин доступен как git-источник, внешняя публикация не выполняется |
| 1.0.0  | Цель         | Стабильный релиз                                          |                             |

## Правила версионирования

- **MAJOR** — несовместимые изменения API / IPC / поведения
- **MINOR** — новая функциональность с обратной совместимостью
- **PATCH** — исправления ошибок и мелкие улучшения

До версии 1.0.0 допускаются breaking changes в MINOR-релизах (с записью в CHANGELOG и ADR при необходимости).
