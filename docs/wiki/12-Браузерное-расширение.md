# Браузерное расширение

> Страница описывает панель OrbitFM для Chrome/Chromium-браузеров и Firefox,
> входящую в 0.15.0-rc.1. В этой сборке доступны и `orbitfm integration`,
> и расширения.

Панель OrbitFM живёт в кнопке на панели браузера: показывает текущую станцию и
даёт транспорт, громкость, тему и показ окна. Она не открывает второй процесс и
не запускает OrbitFM сама — управляет тем экземпляром, который уже работает.
Подписи приходят из приложения, поэтому панель говорит на выбранном в OrbitFM
языке.

## Что нужно

- Linux: установщик интеграций рассчитан на Linux.
- OrbitFM **уже запущен**. Если приложение закрыто, панель покажет «OrbitFM не
  запущен» и предложит повторить; холодный старт из браузера запрещён.
- Chrome, Chromium, Brave, Edge или Vivaldi — либо Firefox 109+.

## Установка

### Chrome и Chromium-браузеры

```bash
orbitfm integration install chrome
```

Команда раскладывает расширение в
`~/.local/share/orbitfm/integrations/chrome/` и пишет native-манифест в
каталоги тех браузеров, которые нашла. Затем:

1. Откройте `chrome://extensions` и включите **«Режим разработчика»**.
2. Нажмите **«Загрузить распакованное расширение»**.
3. Выберите каталог `~/.local/share/orbitfm/integrations/chrome/extension`.

Расширение появится на панели браузера. Его ID фиксирован публичным ключом
(`lfhmfgjblkebbalfdlbmnalghhjplfbg`), поэтому native-манифест продолжает
совпадать с расширением после перезапуска браузера.

### Firefox

```bash
orbitfm integration install firefox
```

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите
   `~/.local/share/orbitfm/integrations/firefox/extension/manifest.json`.

Временное дополнение работает до перезапуска Firefox: после перезапуска его
нужно загрузить снова. Постоянная установка требует подписи Mozilla; в этом
репозитории подписанный XPI не публикуется.

### Все цели сразу

```bash
orbitfm integration install all
```

`all` включает `chrome` и `firefox` наряду с плагинами оболочек и баров. Если
браузера в системе нет, файлы расширения всё равно установятся, а
native-манифест будет пропущен — установите браузер и повторите команду.

## Что умеет панель

| Элемент | Действие |
|---------|----------|
| Название станции | Текущий эфир или «Ничего не играет» |
| Плей/пауза, Стоп | Управление воспроизведением |
| Предыдущая / Следующая | Переход по видимому списку; кнопки гаснут, когда переход недоступен |
| Радиорулетка | Случайная станция |
| Громкость | Ползунок 0–100 %; значение уходит в приложение при отпускании |
| Тема | Системная / тёмная / светлая |
| Показать/Скрыть окно | Показ или скрытие окна OrbitFM |
| Панель / Оверлей | Выпадающая панель или капсула Overlay |
| Настройки | Окно настроек уже запущенного приложения |

Состояние обновляется само: панель подписана на поток `orbitfm events`
(ADR-0039), поэтому смена трека, пауза и громкость видны без опроса. Пока
панель открыта, она получает `snapshot` и последующие `state`; `keepalive`
означает «ничего не меняется», а не ошибку.

## Чего панель не делает

- **Не запускает OrbitFM.** Все команды работают только с уже запущенным
  экземпляром; `orbitfm show` из терминала остаётся способом открыть окно.
- **Не завершает процесс.** Команда `quit` запрещена: выход — только через
  CLI, трей или меню приложения.
- **Не запускает произвольную станцию.** `play <uuid>` запрещён; для выбора
  станции есть глобус, список, рулетка и `next`/`previous`.
- **Не переключает режим окна.** `mode` запрещён; доступны только показ,
  скрытие, панель и оверлей.
- **Не читает страницы.** У расширения нет content scripts, фоновой страницы и
  доступа к вкладкам: веб-сайты не могут дотянуться до плеера через него.

## Безопасность

- Соединение идёт по native messaging: браузер запускает локальный хост
  `orbitfm native-host`, который общается с приложением через тот же сокет,
  что и CLI. Новых сетевых портов нет.
- Native-манифест разрешает ровно один ID расширения; wildcard нет.
- Хост принимает только безопасный набор команд и ограничивает сообщения
  1 МиБ в обе стороны.
- Расширение распространяется распакованным и не подписано магазином:
  включайте режим разработчика и загружайте файлы только из каталога, куда их
  положил установщик OrbitFM.
- Локальный процесс, который может писать в ваш IPC-сокет, и так управляет
  плеером; панель не расширяет эти права.

## Если панель не работает

| Симптом | Что проверить |
|---------|----------------|
| «OrbitFM не запущен» | Запустите OrbitFM любым обычным способом и нажмите «Повторить» |
| «Specified native messaging host not found» | Манифест не установлен или браузер не был обнаружен; выполните `orbitfm integration install chrome` (или `firefox`) и перезапустите браузер |
| Панель есть, но кнопки не работают | Приложение закрыто или команда запрещена; откройте OrbitFM и проверьте `orbitfm status` |
| Chrome не видит расширение | Включён ли «Режим разработчика», выбран ли каталог `extension`, а не его родитель |
| Firefox потерял дополнение после перезапуска | Временное дополнение не переживает перезапуск; загрузите `manifest.json` снова или используйте подписанный XPI, когда он появится |
| Chrome с `--user-data-dir` не находит хост | Такой профиль ищет манифесты в `<user-data-dir>/NativeMessagingHosts`; скопируйте туда `org.modernbyte.orbitfm.json` из стандартного каталога |
| Нужен Brave/Edge/Vivaldi | `install chrome` пишет манифест в каждый обнаруженный Chromium-каталог; расширение загружается так же, как в Chrome |
| Работает только на Linux | Да, установщик интеграций сейчас Linux-only; Windows-реестр и macOS-раскладка не входят в пакет |

## Обновление и удаление

При обновлении OrbitFM переустановите расширение: путь к бинарнику и версия
могут измениться.

```bash
orbitfm integration status chrome      # установлено, изменено или отсутствует
orbitfm integration install chrome     # обновить файлы и манифест
orbitfm integration uninstall chrome   # удалить только файлы OrbitFM
orbitfm integration uninstall firefox
```

`uninstall` удаляет файлы из квитанции и native-манифесты. Само расширение
исчезнет из браузера после удаления каталога или ручного удаления на странице
расширений; настройки браузера установщик не трогает.

## Доказательность

Панель проверена живьём 2026-10-31 на Linux/niri: Chrome for Testing 153 и
Firefox 159, реальный popup через native host, snapshot от запущенного
приложения, round-trip громкости и русские подписи. Brave, Edge, Vivaldi и
постоянно подписанный Firefox не запускались; для них проверены общий код,
манифесты и установщик. Подробности — в ADR-0038 и
`docs/modules/17-browser-companion.md`.
