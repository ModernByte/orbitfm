# Первый запуск

← [Домой](Home.md)

Задача страницы — провести вас от «двойного клика по иконке» до звучащей станции примерно за две минуты
и объяснить, что на экране где находится.

![Режим Focus: сверху строка HUD с вкладками «Страна / Жанр» и поиском, в центре глобус с аудиокольцом, снизу строка транспорта](images/01-focus.png)
*Режим Focus — полный стол: HUD сверху, глобус с аудиокольцом, легенда «Плотность» и строка транспорта снизу.*

---

## Что происходит при запуске

Приложение — **один процесс**. Крестик на окне не завершает его: окно прячется, а звук и IPC-сокет
остаются живыми. Выйти полностью можно через трей (трей-иконка есть на Linux) или командой `orbitfm quit`.

```mermaid
flowchart TD
    S["Запуск: AppImage / ярлык / orbitfm"] --> P["Один процесс OrbitFM"]
    P --> W["Окно (Focus, 1100×800)"]
    P --> T["Трей (Linux) и MPRIS-плеер"]
    P --> I["IPC: orbitfm.sock / named pipe"]
    W -->|"крестик или «Скрыть окно»"| H["Окно спрятано —<br/>процесс и звук живы"]
    I -->|"orbitfm show"| W
    I -->|"orbitfm hide"| H
    I -->|"orbitfm quit"| X["Завершение процесса"]
    T -->|"Выход из меню трей"| X
```

## Шаг 1. Первое окно и карточка жестов

Первый запуск показывает окно **1100×800** с заголовком `OrbitFM` и всплывающую карточку управления мышью:

| Жест | Что делает |
|---|---|
| Правая кнопка мыши | орбита глобуса |
| Левая кнопка мыши | выбрать страну, затем станцию |
| Колесо | зум |

Карточка гаснет **навсегда** после первого же действия на глобусе — левого клика по стране или
запуска станции; убрать её можно и `Esc`. Это разовое обучение: флаг `help_seen` сохраняется в
настройках. Вернуть её можно в любой момент: **«Настройки» → «Показать управление мышью»** либо
кнопка **«Управление мышью»** в строке HUD.

![Карточка жестов поверх глобуса, под ней открытая панель станций с вкладками](images/05-help.png)
*Карточка жестов и панель «Станции» — вид в первый запуск.*

## Шаг 2. Найдите свою страну

Вращайте глобус правой кнопкой мыши, пока не увидите нужный регион; колесом можно приблизить.
Границы стран вшиты в бинарник, поэтому глобус рисуется и работает **без интернета**.
В строке HUD можно набрать название страны или станции и нажать `Enter`; переключатель **«Жанр»** ищет
по жанру во всём мире (до 200 станций, с маркерами на глобусе).

## Шаг 3. Клик по стране

Левый клик по территории страны открывает панель **«Станции»** со списком из этого региона
(за один раз показывается до 100 станций) и тремя вкладками:

| Вкладка | Содержимое | Нужна сеть? |
|---|---|---|
| **Результаты (N)** | последние найденные станции (страна, жанр или строка поиска) | да |
| **Избранное (N)** | ваши отмеченные станции | нет, открываются офлайн |
| **История (N)** | 20 последних прослушанных станций, есть «Очистить историю» | нет для самого списка |

Если список пустой, во вкладке будет «Станции не найдены» / «Избранное пусто» — для «Результатов»
это почти всегда недоступный Radio Browser (см. [Неполадки](09-Неполадки.md)).

```mermaid
flowchart LR
    A["Левый клик<br/>по стране"] --> B["Панель «Станции»<br/>вкладка Результаты"]
    B --> C["Клик по названию<br/>или кнопка Play"]
    C --> D["Строка транспорта внизу:<br/>название, битрейт, громкость"]
    D --> E["Позже: звезда → Избранное,<br/>станция → История"]
```

## Шаг 4. Play

Кликните по станции — через секунду-другой появится звук, а нижняя строка транспорта покажет,
что играет («Сейчас играет»), битрейт и громкость. Можно и с клавиатуры: выделите станцию стрелками
и нажмите `Space`.

![Строка транспорта: название станции, play/stop, громкость и радиорулетка](images/06-transport.png)
*Строка транспорта после запуска станции.*

С этого момента карточка жестов больше не появится при следующих запусках.

## Шаг 5. Избранное и история

У каждой станции в списке есть **звезда** — отметьте её, и станция уйдёт во вкладку «Избранное»
(она открывается даже без сети). Прослушанные станции автоматически копятся в «Истории» (хранится
20 последних, чистятся кнопкой во вкладке).

## Шаг 6. Радиорулетка

Кнопка **«Радиорулетка»** находится в строке транспорта: она берёт случайную станцию со всего мира,
камера перелетает к ней, а результат показывается уведомлением. Пока идёт выбор, кнопка подписана
«Крутим…». Это же действие есть в меню трей-иконки (трей — только на Linux).

## Шаг 7. Настройки

Шестерёнка в интерфейсе или **Ctrl+,** открывает панель настроек: язык и тема, раздел «Окно»
с выпадающим списком компоновки (Focus / Overlay / Listening), галка «Уменьшить движение» и пункт
«Показать управление мышью».

![Боковая панель настроек, открытая поверх глобуса](images/02-drawer.png)
*Панель настроек. Подробно — [Настройки и язык](04-Настройки-и-язык.md).*

## Шаг 8. Скрыть окно — это не выход

Есть два разных действия, их важно не путать:

| Действие | Результат |
|---|---|
| Крестик на окне Focus / «Скрыть окно» / `orbitfm hide` | окно пропало, **процесс и звук живы** |
| `orbitfm show`, `orbitfm toggle` (команда по умолчанию) | окно снова на месте |
| «Выход» в трее (Linux) / `orbitfm quit` | процесс завершён |

Проверить, жив ли процесс, можно из терминала: `orbitfm status`. Команды CLI работают только если
бинарник лежит в PATH — см. [Установка](01-Установка.md).

Между запусками режим окна **не запоминается**: после следующего старта вы снова увидите Focus
(1100×800). Про Overlay и Listening — на странице [Режимы окна](03-Режимы-окна.md).

## Где лежат файлы состояния

| Что | Путь |
|---|---|
| Настройки, флаг `help_seen` | `$XDG_CONFIG_HOME/orbitfm/settings.json` (обычно `~/.config/orbitfm/settings.json`) |
| Избранное и история | `$XDG_DATA_HOME/orbitfm/library.json` (обычно `~/.local/share/orbitfm/library.json`) |
| IPC-сокет | `$XDG_RUNTIME_DIR/orbitfm.sock` (Linux), `\\.\pipe\orbitfm` (Windows), сокет в `$TMPDIR` (macOS) |

Оба файла — обычный JSON с отступами, их можно править руками и переносить между машинами. Чтобы
«забыть» пользователя, удалите `settings.json` и `library.json`: при следующем запуске каталоги и файлы
создадутся заново со значениями по умолчанию.
