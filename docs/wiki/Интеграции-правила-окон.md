# Интеграции: правила окон

← [Интеграции](06-Интеграции) · [Домой](Home)

В тайловых окружениях окно без правил занимает весь тайл. OrbitFM — не
обычный стол: у него три компоновки и выпадающая панель, и каждой нужен свой
размер. Готовые правила для **niri** и **Hyprland** лежат в репозитории и
ставятся тем же установщиком, что и виджеты, — кнопкой на странице
**«Настройки → Интеграции»** или командой.

Правила подбираются по паре «класс окна + заголовок» — `app-id`
(`org.modernbyte.OrbitFM`) и `title`. Заголовок различает поверхности,
поэтому они не пересекаются:

| Поверхность | Заголовок окна | Размер |
|---|---|---|
| Focus | `OrbitFM` | 1100×800 |
| Overlay | `OrbitFM · Overlay` | 500×620 |
| Listening | `OrbitFM · Listening` | 420×152 |
| Panel | `OrbitFM · Panel` | 400×640 |
| Настройки, Compact | `OrbitFM · Settings · Compact` | 420×560 |
| Настройки, Medium | `OrbitFM · Settings · Medium` | 760×544 |
| Настройки, Wide | `OrbitFM · Settings · Wide` | 1040×720 |
| Предупреждение таймера сна | `OrbitFM · Sleep Warning` | 420×320 |

В niri — восемь блоков `window-rule`, в Hyprland — 18 строк `windowrulev2`:
три классовые (`float`, `center`, `stayfocused`) и 15 по заголовку. Окна
настроек и предупреждения центрируются композитором: размер задаётся
правилом, а якоря к правому верхнему углу у них нет.

Проверить, что окно вообще попадает под правило, можно одной командой:
`niri msg windows` (раздел «Проверить размер») должна показать у каждого окна
OrbitFM `App ID: "org.modernbyte.OrbitFM"`. Пустой app-id означает, что
окно не найдёт ни одно правило — так было в 0.21.0-rc.2 и rc.3 для окон
настроек и предупреждения; в 0.21.0-rc.4 исправлено.

Правила не трогают воспроизведение и не мешают переключать режимы: меняется
только то, как композитор показывает окно.

## niri

```bash
orbitfm integration install niri
orbitfm integration uninstall niri
```

Установка кладёт правила в `~/.config/niri/cfg/orbitfm.kdl` и добавляет в
`~/.config/niri/config.kdl` ровно одну строку:

```kdl
// ~/.config/niri/config.kdl
include "./cfg/orbitfm.kdl"
```

Это единственный чужой файл, который установщик правит. Перед первой правкой
рядом ложится копия `config.kdl.orbitfm.bak` (больше она не перезаписывается),
запись атомарная, строка ищется целиком — повторная установка не дублирует её.
Снятие убирает свою строку, файл правил и пустой каталог `cfg/`. Строку,
которую вы добавили сами до установки, снятие оставит в конфиге и сообщит об
этом: без файла правил такой `include` niri не разберёт. Установка отвечает
тем же — если строку добавили не вы, вывод честно говорит об этом и не
показывает несуществующую резервную копию.

niri 26.04+ перечитывает конфиг сам, отдельной команды перезагрузки нет.

Внутри файла — восемь `window-rule`, каждый фиксирует ширину, высоту и
плавающее открытие, а не-Focus режимы дополнительно гасят рамку и тень. Окно
ставится под панель Noctalia якорем в правый верхний угол
(`relative-to="top-right"`). Отступ `x` подобран под правую секцию бара; при
другой раскладке его меняют вручную:

```kdl
window-rule {
    match app-id="org.modernbyte.OrbitFM" title=r"^OrbitFM · Overlay$"
    open-floating true
    default-column-width { fixed 500; }
    default-window-height { fixed 620; }
    default-floating-position x=270 y=48 relative-to="top-right"
    draw-border-with-background false
    border { off; }
    shadow { off; }
}
```

В том же файле для Focus — `x=60` и `1100×800`, для Listening — `x=310` и
`420×152`, для Panel — `x=310`, `400×640` и дополнительно выключенное
focus-ring: панель должна читаться как продолжение бара.

Если капсула ушла под виджет бара, правьте `x` так, чтобы её центр совпал с
иконкой. Центр окна считается как `ширина_экрана − x − ширина/2`. Для Overlay
(500 px, `x=270`) и Listening (420 px, `x=310`) он лежит в одной точке — 520 px
от правого края экрана.

### Проверить размер под niri

Имя сокета зависит от версии и бэкенда — найдите его в `$XDG_RUNTIME_DIR` (на
niri 26.04 это, например, `niri.wayland-1.1108.sock`):

```bash
ls "$XDG_RUNTIME_DIR" | grep niri
NIRI_SOCKET="$XDG_RUNTIME_DIR/niri.wayland-1.1108.sock" niri msg windows
```

Реальный фрагмент вывода для капсулы Overlay:

```text
  Title: "OrbitFM · Overlay"
  App ID: "org.modernbyte.OrbitFM"
  Is floating: yes
  PID: 59220
  Layout:
    Tile size: 500 x 620
    Workspace-view position: 1150, 84
    Window size: 500 x 620
    Window offset in tile: 0 x 0
```

- `Window size` — фактический размер окна; сравнивайте с ожиданиями режима
  (500×620 для Overlay).
- `Tile size` — тайл вместе с рамкой и тенью, на пару пикселей больше, и это
  нормально; если правило выключает рамку и тень, тайл равен размеру окна.
- `Workspace-view position` — смещение от угла экрана; если окно залезает под
  панель Noctalia, увеличивайте `x` в правиле.

После `orbitfm hide` окно исчезает из этого списка целиком, а процесс остаётся
живым. Растянутая на весь тайл капсула — знак неподключённого правила.

## Hyprland

```bash
orbitfm integration install hyprland
orbitfm integration uninstall hyprland
```

Установка кладёт `~/.config/hypr/orbitfm.conf` и сразу применяет его 18 правил
текущему сеансу командами `hyprctl keyword windowrulev2 …` — перезапуск для
этого не нужен. Чужой `hyprland.conf` установщик **не** правит: строку
`source = ~/.config/hypr/orbitfm.conf` добавляете вы сами, иначе правила
исчезнут после перезапуска сеанса. Готовую строку печатает установка и
показывает подробность цели на странице «Интеграции».

```ini
windowrulev2 = float, class:^(org\.modernbyte\.OrbitFM)$
windowrulev2 = center, class:^(org\.modernbyte\.OrbitFM)$
windowrulev2 = stayfocused, class:^(org\.modernbyte\.OrbitFM)$
windowrulev2 = size 1100 800, title:^OrbitFM$
windowrulev2 = size 500 620, title:^OrbitFM · Overlay$
windowrulev2 = noborder, title:^OrbitFM · Overlay$
windowrulev2 = noshadow, title:^OrbitFM · Overlay$
windowrulev2 = size 420 152, title:^OrbitFM · Listening$
windowrulev2 = noborder, title:^OrbitFM · Listening$
windowrulev2 = noshadow, title:^OrbitFM · Listening$
windowrulev2 = size 400 640, title:^OrbitFM · Panel$
windowrulev2 = noborder, title:^OrbitFM · Panel$
windowrulev2 = noshadow, title:^OrbitFM · Panel$
windowrulev2 = noblur, title:^OrbitFM · Panel$
windowrulev2 = size 420 560, title:^OrbitFM · Settings · Compact$
windowrulev2 = size 760 544, title:^OrbitFM · Settings · Medium$
windowrulev2 = size 1040 720, title:^OrbitFM · Settings · Wide$
windowrulev2 = size 420 320, title:^OrbitFM · Sleep Warning$
```

Синтаксис `windowrulev2` работает в Hyprland 0.52 и в совместимом режиме 0.53+,
где помечен как устаревший (новый формат — `windowrule { … }`). При обновлении
Hyprland сверьтесь с его документацией: предупреждение об устаревании — не
дефект OrbitFM.

Снятие убирает файл правил и квитанцию; правила, поставленные на живой сеанс,
`hyprctl` не отменяет — они истекают вместе с сеансом.

## Если правила не сработали

| Симптом | Что проверить |
|---|---|
| niri не применил правила | в `config.kdl` есть строка `include "./cfg/orbitfm.kdl"` и файл `cfg/orbitfm.kdl`; niri 26.04+ перечитывает конфиг сам, более старым версиям нужен перезапуск |
| Hyprland теряет правила после перезапуска | в `hyprland.conf` добавлена строка `source = ~/.config/hypr/orbitfm.conf` — установщик её не пишет |
| Капсула растянута на весь тайл | правило не подключено или не совпал заголовок окна; проверьте `niri msg windows` |
| Окно настроек или предупреждения растянуто на весь тайл | у окна пустой `App ID` (правило требует его вместе с заголовком) — обновите сборку до 0.21.0-rc.4 или новее |
| Окно ушло под панель | увеличьте `x` в правиле niri, чтобы центр окна совпал с иконкой виджета |
| Окно открывается в центре экрана | для niri нет якоря `relative-to="top-right"`; переустановите цель `niri` |
| После удаления niri ругается на `include` | строку добавили вручную до установки; удалите её сами или восстановите файл правил |
