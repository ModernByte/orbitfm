# Установка OrbitFM

← [Домой](Home.md)

Плеер ставится одним бинарником: отдельных «движков» и сервисов доустанавливать не нужно. Выбирайте один
из трёх путей — если хотите просто слушать радио, берите готовый пакет для своей системы.

| Способ | Кому подходит | Сложность |
|---|---|---|
| Готовый пакет (AppImage / MSI / DMG) | обычный пользователь | низкая |
| Сборка из исходников (`cargo`) | своя версия, патч, другой тулчейн | средняя |
| Flatpak локально из репозитория | песочницы; **без** виджета Noctalia и внешнего CLI | средняя |

> Готовых пакетов в AUR, Flathub и Homebrew **нет**: проект распространяется только через релизы GitHub
> и сборку из исходников.

## 1. Готовые пакеты

Файлы на странице релизов: <https://github.com/ModernByte/orbitfm/releases>. Для 0.12.0-rc.2 там четыре файла:

| Файл | Система |
|---|---|
| `OrbitFM-0.12.0-rc.2-x86_64.AppImage` | Linux x86_64 |
| `OrbitFM-0.12.0-rc.2-windows-x64.msi` | Windows x64 |
| `OrbitFM-0.12.0-rc.2-macos-arm64.dmg` | macOS на Apple Silicon (CI-раннер — arm64) |
| `SHA256SUMS` | контрольные суммы всех трёх |

Проверка целостности — из каталога, куда скачали (`sha256sum` есть в Linux и macOS):

```bash
sha256sum -c SHA256SUMS     # ожидаемый вывод: по строке "OK" на каждый файл
```

В Windows хеш получают так и сравнивают с первой колонкой `SHA256SUMS` (регистр не важен):
`Get-FileHash .\OrbitFM-0.12.0-rc.2-windows-x64.msi -Algorithm SHA256`

### 1.1. Linux — AppImage

AppImage не устанавливается, а запускается. Внутри уже лежат `libmpv` и его нативные зависимости, так что
`mpv`/`libmpv` из пакетного менеджера ставить **не нужно**.

```bash
chmod +x OrbitFM-0.12.0-rc.2-x86_64.AppImage
./OrbitFM-0.12.0-rc.2-x86_64.AppImage
```

Нет FUSE (контейнеры, системы с заблокированной `libfuse`) — раскройте и запустите файл так:
`APPIMAGE_EXTRACT_AND_RUN=1 ./OrbitFM-0.12.0-rc.2-x86_64.AppImage`

**Выложите бинарник в PATH.** Для запуска это не нужно, но без этого не работают команды `orbitfm …`
из терминала и виджет Noctalia — они обращаются к приложению по имени:

```bash
mkdir -p ~/.local/bin
ln -sf ~/Downloads/OrbitFM-0.12.0-rc.2-x86_64.AppImage ~/.local/bin/orbitfm
```

Проверьте `echo $PATH`: `~/.local/bin` должен там быть, иначе добавьте в свой shell-rc.

Меню приложений и иконка — готовые файлы из `packaging/linux/`:

```bash
mkdir -p ~/.local/share/applications ~/.local/share/icons/hicolor/scalable/apps
cp packaging/linux/org.modernbyte.OrbitFM.desktop ~/.local/share/applications/
cp packaging/linux/org.modernbyte.OrbitFM.svg ~/.local/share/icons/hicolor/scalable/apps/
```

В `.desktop` по умолчанию `Exec=orbitfm mode focus` и `Icon=org.modernbyte.OrbitFM`: запускатель должен находить
`orbitfm` в PATH (симлинк выше), иначе замените `Exec=` на абсолютный путь к AppImage. Из-за `mode focus` клик по
ярлыку всегда даёт стол Focus, а не переключает видимость окна. Имя `Icon=`
совпадает с именем `.svg`, поэтому иконка берётся из каталога hicolor. Metainfo
(`org.modernbyte.OrbitFM.metainfo.xml`) можно положить в `~/.local/share/metainfo/` — его читают центры
приложения, на запуск это не влияет.

### 1.2. Windows — MSI

MSI ставится **для текущего пользователя** (`Scope="perUser"`), права администратора не нужны.

1. Запустите `OrbitFM-0.12.0-rc.2-windows-x64.msi`, нажмите **Next → Install**.
2. Файлы лягут в `%LOCALAPPDATA%\Programs\OrbitFM`, ярлык — в меню «Пуск» (дальше: `Win` → `OrbitFM`).
3. На первом запуске SmartScreen покажет «Windows protected your PC», потому что установщик **не подписан**
   Authenticode-сертификатом: нажмите **More info → Run anyway**.

### 1.3. macOS — DMG

Подпись в сборке только ad-hoc (`codesign --sign -`), нотаризации нет, поэтому Gatekeeper на первом запуске
открытие запретит.

1. Откройте `.dmg`, перетащите `OrbitFM.app` в `/Applications`.
2. Первый запуск — **правый клик по иконке → Open → Open** (один раз; дальше обычный двойной клик).
   Альтернатива: `xattr -d com.apple.quarantine /Applications/OrbitFM.app`
3. Ничего не запускается — проверьте систему: заявлено минимум `LSMinimumSystemVersion = 13.0`.

Бинарник внутри бандла — `/Applications/OrbitFM.app/Contents/MacOS/orbitfm`; чтобы работали команды
`orbitfm …`, добавьте эту директорию в `PATH` или сделайте симлинк в `~/.local/bin`.

## 2. Сборка из исходников

Нужен Rust **1.95+** (Edition 2024) и системные библиотеки, которые проект линкует напрямую.

Debian / Ubuntu — ровно тот набор, что ставит CI:

```bash
sudo apt install -y libgl1-mesa-dev libmpv-dev libwayland-dev libx11-dev \
  libxcursor-dev libxi-dev libxkbcommon-dev libxrandr-dev
```

Arch (`libmpv` входит в пакет `mpv`) и Fedora: `sudo pacman -S mpv`, `sudo dnf install mpv-libs-devel`.

```bash
git clone https://github.com/ModernByte/orbitfm
cd orbitfm
cargo build --release
./target/release/orbitfm
```

Локальный AppImage из этого же дерева: `./packaging/linux/build-appimage.sh` — файл появится в
`target/appimage/OrbitFM-<version>-x86_64.AppImage`.

Чтобы работали `orbitfm status` и виджет Noctalia, собранный бинарник тоже нужен в PATH:

```bash
ln -sf "$(pwd)/target/release/orbitfm" ~/.local/bin/orbitfm
```

## 3. Flatpak (локально из репозитория)

Flatpak **не входит в релизы**, собирайте сами; нужны `flatpak-builder` и runtime `freedesktop` 25.08:

```bash
./packaging/linux/build-flatpak.sh
```

Ограничение: IPC-сокет Flatpak-сборки живёт в песочнице, поэтому **виджет Noctalia и команды `orbitfm …`
из внешней оболочки с ней не работают**. Нужна интеграция с рабочим столом — берите AppImage.

## 4. После установки

Запустите приложение и пройдите первые две минуты — [Первый запуск](02-Первый-запуск.md). Сеть нужна только
для каталога Radio Browser: глобус рисуется без интернета, границы стран вшиты в бинарник.

## Частые грабли при установке

| Симптом | Причина | Что делать |
|---|---|---|
| `Permission denied` при запуске AppImage | файл не исполняемый | `chmod +x OrbitFM-…AppImage` |
| AppImage падает на FUSE | нет / заблокирован `libfuse` | `APPIMAGE_EXTRACT_AND_RUN=1 ./OrbitFM-….AppImage` |
| `orbitfm: команда не найдена` | бинарник не в PATH | симлинк в `~/.local/bin/orbitfm`, проверить `echo $PATH` |
| Виджет Noctalia пустой | нет `orbitfm` в PATH либо сборка Flatpak | см. п. 1.1; с Flatpak не починить |
| `cargo build`: ошибка по `libmpv` | не поставлены dev-пакеты | `libmpv-dev` (Debian) / `mpv-libs-devel` (Fedora) |
| Сборка падает на Edition 2024 | старый Rust | `rustup update stable`, нужен 1.95+ |
| SmartScreen блокирует MSI | нет подписи Authenticode | «More info → Run anyway» |
| macOS: «проверено не было» | ad-hoc подпись, нет нотаризации | правый клик → «Открыть» либо снять `com.apple.quarantine` |
| Нет звука / станция не стартует | это не установка: сеть, кодек, битый URL | [Неполадки](09-Неполадки.md) |
