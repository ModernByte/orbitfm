# Интеграции: браузер

← [Интеграции](06-Интеграции) · [Домой](Home)

Панель OrbitFM живёт в кнопке на панели браузера и повторяет выпадающую панель
Noctalia: карточка станции, транспорт, громкость, тема, поиск, избранное,
история и «Play this page». Она не открывает второй процесс и не запускает
OrbitFM сама — управляет тем экземпляром, который уже работает. Подписи
приходят из приложения, поэтому панель говорит на выбранном в OrbitFM языке.

## Что нужно

- **OrbitFM уже запущен.** Если приложение закрыто, панель покажет «OrbitFM не
  запущен» и предложит повторить; холодный старт из браузера запрещён.
- **`orbitfm` в `PATH`** — для AppImage это делает `install-appimage.sh` или
  символическая ссылка на образ.
- **Не Flatpak.** Установщик и сокет команд рассчитаны на обычную сборку.
- Chrome, Chromium, Brave, Edge или Vivaldi — либо Firefox 109+.
- Установщик интеграций сейчас работает только на Linux.

## Установка

Поставить панель можно кнопкой на странице **«Настройки → Интеграции» →
Браузеры** или командой. Цели `chrome` и `firefox` независимы: можно выполнить
обе подряд.

### Chrome и Chromium-браузеры

```bash
orbitfm integration install chrome
```

Команда раскладывает расширение в
`~/.local/share/orbitfm/integrations/chrome/` и пишет native-манифест в каталоги
тех браузеров, которые нашла. Затем:

1. Откройте `chrome://extensions` и включите **«Режим разработчика»**.
2. Нажмите **«Загрузить распакованное расширение»**.
3. Выберите каталог `~/.local/share/orbitfm/integrations/chrome/extension`.

Расширение появится на панели браузера. Его ID фиксирован публичным ключом
(`lfhmfgjblkebbalfdlbmnalghhjplfbg`), поэтому native-манифест продолжает
совпадать с расширением после перезапуска браузера.

### Firefox

```bash
orbitfm integration install firefox
```

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите
   `~/.local/share/orbitfm/integrations/firefox/extension/manifest.json`.

Временное дополнение работает до перезапуска Firefox: после перезапуска его
нужно загрузить снова. Постоянная установка требует подписи Mozilla; в этом
репозитории подписанный XPI не публикуется.

### Если браузер не найден

Массовой установки нет: `chrome` и `firefox` ставятся по отдельности, как и
любая цель для панелей. Если браузера в системе нет, файлы расширения всё равно
установятся, а native-манифест будет пропущен — установите браузер и повторите
`orbitfm integration install chrome` или `orbitfm integration install firefox`.

## Что умеет панель

| Элемент | Действие |
|---|---|
| Карточка станции | Имя, страна/теги/битрейт, бейдж `stream`, монограмма и декоративный визуализатор |
| Сердце | Добавить или убрать текущую станцию из избранного |
| Плей/пауза, Стоп | Управление воспроизведением |
| Предыдущая / Следующая | Переход по видимому списку; кнопки гаснут, когда переход недоступен |
| Радиорулетка | Случайная станция |
| Громкость | Ползунок 0–100 % и кнопки ±5 %; значение уходит в приложение |
| Тема | Циклическое переключение системной, тёмной и светлой |
| Показать/Скрыть окно | Показ или скрытие окна OrbitFM |
| Настройки | Окно настроек уже запущенного приложения |
| Поиск | Запрос по каталогу Radio Browser с задержкой 300 мс, до 20 результатов |
| Избранное / История | По 20 записей; запуск без повторного поиска в сети |
| Play this page | Скан активной вкладки и импорт найденного аудиопотока |

Состояние обновляется само: панель подписана на поток `orbitfm events`,
поэтому смена трека, пауза и громкость видны без опроса. Пока панель открыта,
она получает `snapshot` и последующие `state`; `keepalive` означает «ничего не
меняется», а не ошибку. Результаты поиска приходят кадром `search` только для
своего поколения (`id`), поэтому устаревший ответ не перебивает новый запрос.

### Поиск, избранное и история

Поиск отправляет `search <запрос>`; приложение отвечает `search <id>`, а
результаты публикует кадром `search`. Клик по результату шлёт
`play-result <uuid>` — играть можно только станцию из последней выдачи. Вкладки
«Избранное» и «История» читают библиотеку и запускают станцию
`play-library <uuid>` без обращения к Radio Browser. Сердце переключает
`favorite`, а списки перечитываются после изменения.

### Play this page

Кнопка в футере сканирует **активную вкладку и только по клику**:
`og:audio`, `<audio src>`, `<source src>` и URL самой страницы. Относительные
адреса приводятся к абсолютным, остаются только `http(s)`, дубликаты
убираются, кандидатов не больше 20. Вы выбираете запись — расширение шлёт
`play-url <url>`, приложение разбирает страницу, `.m3u`/`.pls` или прямой поток.
HLS не поддерживается. Без разрешения `scripting` остаётся только URL вкладки.
Автозапуска нет: импорт начинается лишь после вашего клика.

## Чего панель не делает

- **Не запускает OrbitFM.** Все команды работают только с уже запущенным
  экземпляром; `orbitfm show` из терминала остаётся способом открыть окно.
- **Не завершает процесс.** Команда `quit` запрещена: выход — только через CLI,
  трей или меню приложения.
- **Не запускает произвольную станцию по UUID.** `play` запрещён; играть можно
  результат поиска, элемент избранного/истории или URL после явного клика.
- **Не переключает режим окна.** `mode` запрещён; доступны показ, скрытие,
  панель и оверлей.
- **Не трогает статистику прослушивания.** `stats`, `stats --json` и
  `stats clear` вне белого списка native host, поэтому хост отвечает на них
  `forbidden`: панель не читает приватные счётчики и не стирает их. Статистика
  остаётся доступной из окна настроек и CLI.
- **Не читает страницы в фоне.** У расширения нет content scripts, фоновой
  страницы и постоянных разрешений на сайты. Разрешения `activeTab` и
  `scripting` дают разовый скан активной вкладки только по нажатию
  «Play this page»; без `scripting` остаётся URL вкладки.

## Безопасность

- Соединение идёт по native messaging: браузер запускает локальный хост
  `orbitfm native-host`, который общается с приложением через тот же сокет, что
  и CLI. Новых сетевых портов нет.
- Native-манифест разрешает ровно один ID расширения; wildcard нет.
- Хост принимает только безопасный набор команд и ограничивает сообщения 1 МиБ
  в обе стороны.
- `activeTab` и `scripting` не дают фонового доступа: вкладка сканируется один
  раз и только по вашему клику, без content scripts и постоянных разрешений.
- `play-url` принимает только `http(s)`, отклоняет userinfo и HLS, читает не
  больше 1 МиБ; адреса локальной сети разрешены, потому что импорт запускает
  явное действие пользователя, а не страница. При этом публичная страница не
  может увести импорт во внутреннюю сеть через редирект или плейлист — такой
  переход отклоняется.
- Расширение распространяется распакованным и не подписано магазином: включайте
  режим разработчика и загружайте файлы только из каталога, куда их положил
  установщик OrbitFM.
- Локальный процесс, который может писать в ваш сокет команд, и так управляет
  плеером; панель не расширяет эти права.

## Если панель не работает

| Симптом | Что проверить |
|---|---|
| «OrbitFM не запущен» | Запустите OrbitFM обычным способом и нажмите «Повторить» |
| «Specified native messaging host not found» | Манифест не установлен или браузер не был обнаружен; выполните `orbitfm integration install chrome` (или `firefox`) и перезапустите браузер |
| Панель есть, но кнопки не работают | Приложение закрыто или команда запрещена; откройте OrbitFM и проверьте `orbitfm status` |
| Поиск ничего не находит | Проверьте запрос и сеть; индикатор и «Повторить» показывают таймаут или ошибку каталога |
| «Play this page» не находит аудио | На странице нет `og:audio`/`<audio>`; служебные страницы браузера не сканируются — остаётся URL вкладки |
| Импорт URL отклонён | HLS (`.m3u8`), `file://`, userinfo и тело больше 1 МиБ не поддерживаются; используйте страницу с `og:audio`, `.m3u`/`.pls` или прямой аудиофайл |
| Chrome не видит расширение | Включён ли «Режим разработчика», выбран ли каталог `extension`, а не его родитель |
| Firefox потерял дополнение после перезапуска | Временное дополнение не переживает перезапуск; загрузите `manifest.json` снова или дождитесь подписанного XPI |
| Chrome с `--user-data-dir` не находит хост | Такой профиль ищет манифесты в `<user-data-dir>/NativeMessagingHosts`; скопируйте туда `org.modernbyte.orbitfm.json` из стандартного каталога |
| Нужен Brave/Edge/Vivaldi | `install chrome` пишет манифест в каждый обнаруженный Chromium-каталог; расширение загружается так же, как в Chrome |

## Обновление и удаление

При обновлении OrbitFM переустановите расширение: путь к бинарнику и версия
могут измениться.

```bash
orbitfm integration status chrome      # установлено, изменено или отсутствует
orbitfm integration install chrome     # обновить файлы и манифест
orbitfm integration uninstall chrome   # удалить только файлы OrbitFM
orbitfm integration uninstall firefox
```

`uninstall` удаляет файлы из квитанции и native-манифесты. Само расширение
исчезнет из браузера после удаления каталога или ручного удаления на странице
расширений; настройки браузера установщик не трогает.

## Что проверено

Панель проверена живьём на Linux/niri, OrbitFM 0.16.0-rc.2: Chrome for Testing
153 с распакованным расширением — поиск (20 результатов), запуск результата,
избранное, история и запуск из неё, громкость кнопками и клавиатурой,
переключение темы, офлайн и «Повторить», а также настоящий клик по кнопке
расширения со сканом вкладки и импортом `og:audio`. Chrome 156 с профилем
пользователя показал ту же панель. Firefox 159 проверялся в 0.13.0-rc.2; в 0.16
повторно не запускался. Brave, Edge, Vivaldi и постоянно подписанный Firefox не
запускались; для них проверены общий код, манифесты и установщик.
