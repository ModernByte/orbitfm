# Документация OrbitFM

[English](README.md) · **Русский**

Это входная точка во всю документацию OrbitFM. Выберите раздел, который нужен.

## Для пользователей

Пошаговые руководства по установке и прослушиванию. Кроме умения открыть
терминал для команд из примеров, ничего знать не нужно.

| Язык | С чего начать |
|------|---------------|
| [English](user/en/index.md) | OrbitFM user guide (по умолчанию) |
| **Русский** | [Руководство пользователя](user/ru/index.md) |

Руководство покрывает установку на Linux, Windows и macOS, мастер первого
запуска, режимы окна, настройки, клавиатуру и медиа-клавиши, интеграции
(Noctalia, Plasma 6, GNOME, Waybar и другие), панель браузера, правила окон,
трей и MPRIS, десять реальных сценариев, неполадки и глоссарий.

На каждой странице сверху есть переключатель языка: английские страницы ведут
на русские и наоборот. В пользовательском руководстве намеренно нет
архитектурных решений и внутренних заметок — за ними идите в раздел для
разработчиков.

ADR — единственное место, где фиксируются архитектурные решения. Они написаны
для сопровождающих и не входят в пользовательское руководство: страницы для
пользователей описывают поведение, а не причины решений.

## Языки документации

- Пользовательская документация двуязычная: английский — по умолчанию, русский —
  полноценный перевод. Оба дерева используют одинаковые имена файлов, поэтому при
  переключении языка вы остаётесь на той же странице.
- Документация разработчика (архитектура, ADR, модули, интерфейсы, паттерны)
  ведётся на русском — рабочем языке проекта.
- Строки интерфейса локализуются отдельно в самом приложении (семнадцать языков,
  включая английский и русский); см. [«Настройки и язык»](user/ru/settings.md).
