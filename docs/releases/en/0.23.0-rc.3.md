PATCH: builds moved to Rust 1.100 and Flatpak is gone — Linux keeps a single delivery channel, the AppImage, with the same CLI and widget.

### Changed
- **Toolchain moved to Rust 1.100; the project MSRV went from 1.95 to 1.100**
  (`Cargo.toml`, SRS, README, architecture overview, TUI module spec, user guide).
  The reason is `docs/AGENTS.md` §1.7, "latest stable versions": cargo already
  refuses to build with a compiler older than the declared MSRV, and the pinned
  CI toolchain 1.98.1 would have drifted away from the manifest.
- **Targeted refactoring onto the new language features** — only where it removes
  a branch or a copy, with no behaviour change:
  - `Option/Result::map_or_default` (1.98) instead of `map(..).unwrap_or_default()`
    in 10 places (`wm`, `library`, `stats`, `stream`, `artwork`, `capsule`,
    `transport`); the `map_unwrap_or` lint from `[lints.clippy]` started
    suggesting this rewrite only with the raised MSRV, so CI fails without it;
  - `str::trim_suffix`/`[T]::trim_suffix` (1.100) instead of
    `strip_suffix(..).unwrap_or(..)`: IPC command framing that strips exactly one
    `\n` and exactly one `\r`, and the trailing-dot removal in the SSRF host
    policy;
  - `u32::bit_width` (1.97) in `mip_levels` instead of `32 - leading_zeros()`:
    the same mip count, read without arithmetic;
  - `String::from_utf8_lossy_owned` (1.99) on the stdout of an external Noctalia
    command — no mandatory `Cow → String` copy;
  - `Vec::from_fn` (1.100) and `bool::toggle` (1.100) — three index-built vectors
    and the panel toggle;
  - `assert_matches!` (1.96) in 14 tests instead of `assert!(matches!(..))`: a
    panic prints the actual value, not just the fact of a mismatch. Three places
    (`FaviconState`, `IpcServer`) stay on `assert!` because those types do not
    implement `Debug`, and a public type is not made debug-printable for a test.
    The private `native_host::FrameRead` got `#[derive(Debug)]`.

### Removed
- **Flatpak is removed from the project completely** (ADR-0011 rev. 2). Gone: the
  manifest `packaging/linux/org.modernbyte.OrbitFM.yml`, the vendored source list
  `packaging/linux/flatpak-cargo-sources.json`, `build-flatpak.sh` and the
  `check-flatpak-sources.py` checker; the packaging CI job no longer runs "Check
  Flatpak manifest and vendored sources" and "Check Flatpak build script syntax";
  `/.flatpak-builder` left `.gitignore`; the sandbox-detection placeholder comment
  left `src/tray/sni.rs`. The reason: inside the sandbox the IPC socket lives in a
  private runtime directory, so the Noctalia widget, window rules and `orbitfm ...`
  from an outside shell do not work with such a build, and the second channel
  required keeping the manifest, the vendoring and the checker in sync with
  `Cargo.lock` on every dependency update. Flatpak was never part of the releases.
- The local `.flatpak-builder` build cache (≈2 GiB) is deleted.

### Packaging / CI
- **Toolchain pins in `ci.yml`, `release.yml` and `advisories.yml` raised from
  1.98.1 to 1.100.0**; the MSRV job is renamed to "MSRV 1.100" (a compiler checks
  the declared MSRV, not a word in the manifest).
- **`[lints.cargo] unused_dependencies = "warn"`** — the Cargo 1.100 lint surfaces
  idle dependencies; the Linux graph is clean, and platform `cfg` branches are
  accounted for from the manifest.
- **The Flatpak steps are gone from the packaging job**, and the
  `.github/dependabot.yml` comment no longer requires regenerating Flatpak
  vendoring when dependencies change.
