PATCH: install OrbitFM with one curl command — SHA256 verification, app-menu entry and icon included; the user guide is now bilingual, English by default with a Russian switch.

### Added
- **One-command installation** (`install.sh`, ADR-0011): `curl -fsSL
  https://raw.githubusercontent.com/ModernByte/orbitfm/main/install.sh | sh`
  finds the latest release, downloads the AppImage and `install-appimage.sh`,
  verifies both against `SHA256SUMS` and hands the installation to the published
  helper — no root required. Flags: `--release <version>` (pin a version),
  `--dry-run` (download and verify only), `--uninstall` (removal offline, with
  the saved helper of that version). Linux x86_64 only; macOS and Windows keep
  using the DMG and the MSI.
- **`install-appimage.sh --extract-and-run`**: when `libfuse2` is missing
  (Ubuntu 24.04 and newer) the installer writes `env APPIMAGE_EXTRACT_AND_RUN=1`
  into `Exec`, so the menu entry starts without FUSE at the cost of unpacking the
  image on launch. `desktop-file-validate` passes.
- **Bilingual release notes**: the Russian text stays in `docs/CHANGELOG.md`, the
  English one lives in `docs/releases/en/<version>.md`; the release workflow
  assembles a single body (`## English` after the Russian block) and refuses to
  publish without the English file. The template and first-paragraph rules are in
  `docs/dev/release-notes.md`.

### Changed
- **README split by language:** `README.md` is English (default), `README.ru.md`
  is Russian. Both are now landing pages: features, requirements, installation,
  quick start, window modes, guide links and honest support levels. The full
  legal text moved to `LEGAL.md` (English and Russian), the dependency table and
  asset credits to `docs/dev/acknowledgements.md`.

### Packaging / CI
- **Documentation CI gate:** the `docs` job and `packaging/check-docs.sh` check
  language-tree parity, a language switch on every page, no ADRs or developer
  links on user pages, live relative links, no stale `docs/wiki` paths, the
  English release notes for the `Cargo.toml` version, and that every
  `docs/releases/en/*.md` maps to a CHANGELOG section.
- **Release workflow:** the release body is assembled from both languages and
  fails when the English file is missing; the guide-links footer is now
  language-neutral.
- **CI:** `bash -n install.sh` in the `packaging` job — the installer syntax is
  checked before a release.

### Documentation
- **The user guide is now bilingual.** `docs/user/en` is English by default,
  `docs/user/ru` is the Russian translation; both trees use identical file names
  and every page carries a language switch. The old `docs/wiki` tree is gone and
  references in ADRs, modules, README and the release workflow point to the new
  paths.
- **A developer section `docs/dev/` appeared:** entry point, English index of all
  66 ADRs, engineering rules, pre-PR checks, documentation layout and the release
  notes template. ADRs, modules, interfaces, patterns and audits stay Russian —
  the project's working language.
- **User pages no longer mention ADRs** and do not link into `docs/adr`,
  `docs/modules` or `docs/interfaces`: they explain behavior, not the decision
  behind it. ADR mentions were removed from the guide and the facts rewritten in
  user language. A "Security and privacy" page was added in both languages.
- **Project rules synchronized:** `docs/AGENTS.md` § 6.3 and § 7, plus the
  `orbitfm-core` and `orbitfm-docs` skills, describe the new language policy and
  bilingual release notes.
