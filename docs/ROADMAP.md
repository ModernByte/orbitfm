## Этап 6: Полировка и кроссплатформа — продолжается

Открытые пункты касаются только рантайм-проверок macOS и Windows; сборка, CI и
упаковка закрыты, поэтому основной поток работ перешёл в Этап 10.

- [x] Windows: named pipe IPC (`src/ipc/pipe.rs`) и CI-проверка на `windows-latest`
- [x] Windows (SMTC) — ADR-0024 принят: скрытое top-level окно на выделенном потоке
  отдаёт HWND для playwire, контролы переживают скрытие окна; осталось

- [ ] macOS (Now Playing) — метаданные playwire публикуются; осталось
  рантайм-проверить, а доставку remote-команд при скрытом окне закрывает

## Этап 9: Аудио-реактивная планета — завершён (0.9.0-rc.1)

Концепция, контракты и фазы — [`docs/ui/audio-reactive-globe.md`](ui/audio-reactive-globe.md);
решения — [ADR-0027](adr/0027-трёхполосный-анализ-эфира.md) (полосы эфира)
и [ADR-0028](adr/0028-аудио-реактивная-деформация-глобуса.md) (деформация).
Оба ADR приняты; фазы 0–4 реализованы, Linux принят на niri/Wayland.
Старый Fresnel-пульс снят с глобуса до начала работ, чтобы не мешал
пересмотру визуала.

- [x] Вне фаз: орбитальное аудиокольцо за глобусом (ADR-0029) — haze, корона
  из 120 столбцов, аврора, комета, искры на onset; Focus-only, без новых
  зависимостей и без влияния на hit-testing
- [x] Фаза 0: полосы эфира — `@level` + `@spectrum` (`acrossover`/`amerge`/`pan`),
  Bass/Mid/High без PCM-tap, mono/stereo и fallback (ADR-0027)
- [x] Фаза 1: ядро движения — `MotionMixer`, spring-squash с сохранением объёма,
  idle-дыхание, `GlobeDeform` для шейдера/маркеров/стран/hit-test, настройки
  Motion и Reduce motion, анализ по требованию, кадры 30/15 fps
- [x] Фаза 2: onset, бит и шесть стилей — детектор удара (20 Гц, медианная
  базовая линия, рефрактерность, период 60–180 BPM), Auto с удержанием 3 с и
  кроссфейдом, uniform `motion2`, Fresnel-вспышка, выбор стиля в HUD
- [x] Фаза 3: камера и режимы — музыкальный sway в `eye()`, приоритет
  drag/zoom/fly, перевороты-roll с кулдауном 12 с и `allow_flips`,
  Overlay ≤ Low, Listening Off
- [x] Фаза 4: полировка и приёмка — live-проверки на niri 26.04/Wayland
  (FLAC/MP3, hide/show, Overlay/Listening/Focus, стоп/выход), замеры CPU/GPU,
  снятие анализа в `park` (19–23 % → ≈2 %), 280 тестов; §11 закрыт,
  ADR-0027/0028 сверены с реализацией. Моно-поток и реконнект закрыты
  ignored live-тестами 2026-10-24. Остаётся отложенной только рантайм-проверка
  Windows/macOS (сборки и тесты идут в CI)

## Открытые решения — ждут ответа владельца

Подняты 2026-10-25 по итогам приёмки этапа 10; ответ ожидается 2026-10-26. Ни одно
из них не блокирует выпущенный `0.10.0-rc.1` — это расхождения, которые нельзя
копить дальше.

1. **Подзаголовок релиза.** Сейчас `release.yml` публикует голое имя
   «OrbitFM 0.10.0-rc.1», тело релиза берётся из секции CHANGELOG. В практике
   предыдущих релизов было имя с подзаголовком —
   «OrbitFM 0.10.0-rc.1 — язык, настройки и ритм интерфейса». Решить: вернуть
   подзаголовок (тогда в workflow добавляется поле) или оставляем голое имя.
2. **Две отложенные проверки live-приёмки** (строка чек-листа этапа 10 выше):
   клик по галке «Уменьшить движение» и перетаскивание ползунка громкости с
   фиксацией при отпускании. На машине приёмки нет синтетического ввода; нужен
   `wtype` (пакет из `cachyos-extra-v3`, ставится вручную: `sudo pacman -S wtype`) —
   либо фиксируем, что оба пути подтверждены сборкой и тестами и ручной прогон
   не требуется.
3. **Уборка ветвей и объём README.** Смержены squash-ем и больше не нужны
   `feat/i18n-settings-motion` и `fix/release-notes-from-changelog` (локальные и
