## 1. Всплывающий маркер страны (Country Callout)

Появляется при **hover** и/или **select** страны в режиме Country.

### 1.1. Внешний вид

```
        ┌─────────────────────────────┐
        │ 🇬🇧  United Kingdom          │
        │     128 stations            │
        └─────────────┬───────────────┘
                      │ leader line
                      ▼
                 [контур страны]
```

| Элемент | Спецификация |
|---------|----------------|
| Контейнер | Glass panel: `rgba(18, 24, 38, 0.92)`, border `1px` `rgba(91, 140, 255, 0.35)`, radius **10–12px**, soft shadow |
| Флаг | Эмодзи или маленькая текстура **20×14** / **24×16**, слева, скругление 2px |
| Название страны | Primary text `#E8ECF4`, 13–14px, semibold |
| Подзаголовок | `{N} stations` — muted `#8B93A7`, 11–12px |
| Leader line | Тонкая линия 1px от нижней грани callout к центроиду/якорю страны, цвет accent с alpha 0.6–0.9 |
| Якорь | Малая точка/пин на поверхности в accent или signal.live |

### 1.2. Поведение

- **Hover (ещё не клик):** callout полупрозрачный (alpha ~0.85), контур страны `country.hover`.
- **Select (ЛКМ):** callout ярче, контур `country.selected` толще/ярче; панель станций обновляется.
- **Смена страны:** старый callout fade-out 120–180ms, новый fade-in + лёгкий slide от якоря (4–8px).
- **Режим Genre:** country callout **не** показывать (только tooltips маркеров станций).
- Не перекрывать top HUD и bottom transport; при нехватке места — flip callout вверх/вниз от якоря.

### 1.3. Пустые страны

Как на текущем скрине (Sierra Leone, 0 stations):

- Callout: флаг + имя + **«0 stations»**.
- Не оставлять ощущение ошибки; в панели справа: empty state *«В этом секторе пока тихо»* + предложить Genre / Roulette / другую страну.

## 2. Маркеры станций на глобусе

Маркер = проекция станции с валидными `geo_lat` / `geo_long` на сферу.

### 2.1. Данные для визуального веса

Использовать поля Radio Browser (что доступно):

| Сигнал | Поле (типично) | Роль |
|--------|----------------|------|
| Популярность | `votes`, `clickcount` | Рейтинг в подписи при наведении |
| Качество потока | `bitrate`, `codec` | Качество в подписи при наведении |
| Надёжность | не `lastcheckok == 0`, не broken | При broken — не показывать или dimmed |
| Активность now | текущий `stationuuid` | Отдельное состояние **Playing** |

> **Обновление Этапа 9 (ADR-0012):** динамический размер по голосам и цвет по
> битрейту отменены. Все маркеры одинаковые; голоса, битрейт и кодек показываются
> во второй строке подписи при наведении. Разделы 2.2–2.4 приведены к этому виду.

### 2.2. Размер

| Состояние | Радиус на экране (px) |
|-----------|------------------------|
| Все станции, включая кластеры | 3 |
| Playing | тот же радиус + кольцо-пульс 1.4 с |
| Hover | тот же радиус + светлое кольцо с зазором 3.5 px |

Кластер (`count > 1` в одной точке): то же точка; размер группы — в заголовке
подписи (`· +N`).

### 2.3. Цвет (статус)

Все маркеры рисуются одним цветом `palette.marker`; качество потока цветом не
кодируется.

**Модификаторы:**

| Состояние | Визуал |
|-----------|--------|
| Hover | цвет светлеет на 28%, белое кольцо, подпись с именем и деталями |
| Playing | кольцо-пульс того же цвета (1.4 с, +3.5 px) |
| Favorite (опционально) | тонкий золотой ободок |
| Broken / hide | не рисовать |

### 2.4. Tooltip станции (не путать с country callout)

```
┌──────────────────────────────────┐
│ Station Name · +N                │
│ City · 320 kbps · MP3 · 40 votes │
└──────────────────────────────────┘
```

Короткий, без флага страны (флаг — у country callout). Пустые детали опускаются.

## 3. Градиенты и «полосы» на панелях

### 3.1. Общие поверхности

| Поверхность | Заливка |
|-------------|---------|
| Window / space bg | `#070A10` → радиальный или вертикальный лёгкий градиент к `#0B1220` (не плоский чёрный) |
| Glass panel | `linear-gradient(180deg, rgba(30,40,60,0.88), rgba(14,18,28,0.92))` + border `rgba(120,160,255,0.12–0.22)` |
| Top HUD / Bottom transport | та же glass; **верхний блик** 1–2px `rgba(255,255,255,0.06)` на верхнем крае (rim light) |
| Active tab / chip | accent fill 15–25% alpha + border accent 40% |
| Selected station row | accent 12–20% alpha, left bar 2–3px accent |

### 3.2. Heatmap плотности станций (легенда + заливка страны)

Легенда (как на референсе):

```
Low  [■■■■■■■■]  High
     blue → cyan → green → yellow → orange → red
```

Градиент заливки полигона страны (select/hover density):

```
#3B82F6 → #22D3EE → #34D399 → #FBBF24 → #F97316 → #EF4444
```

Интенсивность alpha зависит от нормализованного count (больше станций → теплее и чуть плотнее fill).

### 3.3. Аудиовизуализатор (замена старого FFT)

**Убрать** текущий strip/FFT overlay старого типа.

**Новый:** cava-like **вертикальные столбцы**, 16 / 24 / 32 бара (рекомендуемый default **24**).

Размещение:

- Focus: над bottom transport **или** встроенная полоса в правой части transport (высота ~40–56px);
- не перекрывать центр глобуса.

Градиент **привязан к высоте области столбцов**, а не к отдельному столбцу
(снизу вверх): короткий столбец остаётся зелёным, оранжевый и красный появляются
только на подъёме — иначе тихий эфир выглядел бы «красным» и легенда цвета
нарушалась бы.

| Зона | Цвет |
|------|------|
| Низ | `#22C55E` / `#4ADE80` (салатовый) |
| Середина | `#FBBF24` → `#FB923C` (жёлто-оранжевый) |
| Верх | `#EF4444` / `#F87171` (красный) |

Технически: fragment по высоте области `mix(green, yellow, t)` затем `mix(..., red, t2)`,
не один solid color. В egui 0.37 `LinearGradient` доступен только для штрихов,
поэтому столбец набран семью горизонтальными полосами с интерполяцией цвета
(`widgets::viz_bars`, остановки — `render::bar_color`).

Поведение:

- тишина / stopped — бары на минимуме или idle «дыхание» 2–3px;
- playing — peaks с лёгким falloff (сглаживание вниз 80–150ms);
- без тяжёлых аллокаций на кадр (кольцевой буфер уровней).

### 3.4. Прочие акцентные градиенты

- Кнопка Play primary: радиальный/linear accent → чуть светлее при hover.
- LIVE pill: soft green glow `0 0 12px rgba(61,220,151,0.35)`.
- Volume track (справа внизу): track muted; fill accent gradient left→right soft.

## 4. Интерактив и анимации «высшего разряда»

### 4.1. Камера и глобус

| Событие | Анимация |
|---------|----------|
| ПКМ drag release | inertia / damping (уже в камере) — не обрывать резко |
| Select country | soft ease-out доворот к стране 400–600ms (опционально) |
| Radio Roulette | «перелёт» 0.8–1.4s ease-in-out к цели + brief overshoot 2–3% |
| Zoom wheel | smooth, clamp min/max; не телепорт |

### 4.2. UI chrome

Нормативные длительности, кривые и сценарии — [ADR-0032](../adr/0032-система-анимаций-ui.md)
и [`docs/modules/15-ui-motion.md`](../modules/15-ui-motion.md); таблица ниже —
намерение эскиза.

| Элемент | Motion |
|---------|--------|
| Появление панели станций | width/opacity 200–280ms ease-out |
| Callout страны | fade + 6px rise, 150–200ms |
| Смена вкладки Results/Fav/History | crossfade списка 120ms |
| Чип жанра | scale 0.96→1.0 на press |
| Маркер playing | continuous pulse 1.2–1.6s loop, sin |
| Строка станции on hover | background fade 80ms |

### 4.3. Принципы качества

1. Все motion — **eased**, не linear (кроме бесконечного pulse).
2. Не анимировать всё сразу: камера **или** панель как доминанта.
3. 60fps priority: глобус + бары визуализатора; вторичные тени можно упростить.
4. Reduce motion (`settings.reduce_motion`, ADR-0028/ADR-0032) — мастер-выключатель:
   переходы интерфейса мгновенные, кольцо Listening и пульс статичны, геометрия
   глобуса не двигается, эфир продолжает играть.

## 5. Правки текущего реального UI (второй скрин) — ТЗ агенту

Скрин: idle, тёмная «лысая» Земля, Sierra Leone 0 stations, help слева, пустая правая панель.

### 5.1. Глобус и сцена (критично)

**Проблема:** текстура Земли слишком тёмная, низкий контраст материков, сцена выглядит плоской и «выключенной».

**Сделать:**

1. Осветлить albedo / day texture: материки читаются, океаны остаются тёмно-синими, но не в чёрную дыру.
2. Добавить **ambient + directional** свет (рассветный key light), чтобы был объём.
3. Тонкий **атмосферный обод** (Fresnel) — как на референсе.
4. Night lights на текстуре — умеренно; не перебивать UI.
5. Фон космоса: не чистый `#000`; редкие звёзды + лёгкий vignette, без шума на весь экран.
6. Минимальный zoom по умолчанию — чуть ближе, чем «фарш в центре пустоты», либо крупнее scale сферы в viewport.

### 5.2. Window close / Niri

**Проблема:** нет кнопки закрытия; Super+Q в Niri не закрывает окно как ожидается.

**Сделать:**

1. **Standalone / обычное окно:**  
   - системные decorations **или** явная кнопка close в top HUD (×), по смыслу = **quit process** или hide — продуктово:  
   - **Close (×)** / WM close → по SRS: *hide window, process lives*; реализовано по
     ADR-0018 как честное закрытие root-вьюпорта (окно уходит из раскладки, UI-цикл
     останавливается, эфир, IPC и MPRIS живут), показ — новый прогон `run_native`.
   - Отдельный **Quit** в меню (⋯) — полный выход (`orbitfm quit`).
2. Проверить app-id / window class для Niri rules (`org.modernbyte.OrbitFM` / `orbitfm`) — Super+Q закрывает окно композитора; приложение должно корректно обработать close request (hide vs quit — зафиксировать в UX: по умолчанию **hide**, чтобы радио не умирало).
3. Если нужно именно убить процесс по Super+Q — это поведение WM + optional setting «Close quits»; default = hide.
4. **Noctalia overlay:** кнопки × не обязательны; повторный клик по виджету = `toggle` (hide). Не дублировать красный close в капсуле.

### 5.3. Нижняя панель

1. **Громкость** — перенести **вправо вниз** на transport bar (убрать из перегруза топа, если мешает).
2. Play/Stop primary; Prev/Next — только если есть осмысленная очередь, иначе убрать/disable.
3. Radio Roulette — видимая кнопка.
4. Справа от volume — **новый cava-like visualizer** (24 бара, градиент green→yellow→red).
5. Удалить старый FFT overlay полностью.

### 5.4. Маркеры и callout

1. Country callout с **флагом**, именем, count (см. §1).
2. Все маркеры одного размера и цвета; качество и рейтинг — в подписи при наведении (§2).
3. Playing — pulse + ring.

### 5.5. Контент списка в Country mode

Только станции выбранной страны. Не показывать Seattle/Paris в списке UK (ошибка референс-мокапа не повторять в коде).

### 5.6. Help overlay

Карточку «Right drag / Left click…» — только first run или по кнопке `?`; не держать постоянно, отъедая глобус.

### 5.7. Empty / idle

- «Nothing playing» — нормальный idle.
- Страна с 0 stations — честный callout + empty state в панели, не «сломанный» UI.
