## 1. Продуктовая идея

OrbitFM — не «список радиостанций с картой», а **орбитальный стол (Orbital Desk)**:

- в центре сцены — **3D-глобус**;
- вокруг — тонкий **HUD** (поиск, транспорт, режимы);
- списки и фильтры — **выезжающие панели**, а не постоянные колонки, съедающие глобус.

Уже реализовано в репозитории (не ломаем, встраиваем в новый layout):

- маркеры станций, избранное/история, темы и акценты;
- FFT/spectrum overlay, MPRIS, IPC hide/toggle, Noctalia.

## 2. Режимы отображения окна

| Режим | Триггер | Плотность UI | Глобус |
|--------|---------|--------------|--------|
| **Focus** | Обычный запуск / разворот | Полный HUD | 70–80% кадра |
| **Overlay** | CLI `orbitfm overlay` / «Компоновка» | Капсула (HUD-строка с 16-полосной лентой) | Мини-глобус или только выбранный регион |
| **Listening** | Идёт эфир, низкая активность UI | Минимальный now-playing + пульс | Idle + лёгкая анимация |

Один набор виджетов, параметр `LayoutDensity` / `WindowMode`.

Текущее состояние: фазы 1–7 реализованы — Focus-раскладка (HUD, глобус, правый
drawer, transport), режим «Страна» (hover/контур, поиск страны в HUD, локальные
фильтры и сортировка), режим «Жанр» (переключатель, пресеты и свой тег, маркеры,
поколение поиска), Roulette (случайная станция, перелёт камеры, тост, artist из
страны/штата в MPRIS), живой глобус (Fresnel-обод от сглаженного уровня/flux,
heatmap выбранной и наведённой страны по числу станций), а также WindowMode
Overlay/Listening с капсульными раскладками, IPC-командой `mode` и доступностью
(ADR-0021). Hide/Show доступны через IPC.

## 3. UX и механики управления 3D-глобусом

### 3.1. Мышь

| Ввод | Поведение |
|------|-----------|
| **ПКМ + drag** | Orbit camera: вращение по осям X/Y. При отпускании — **smooth damping** (инерция), уже заложено в `GlobeCamera`. |
| **ЛКМ (клик)** | Raycast из курсора на сферу. Дальше — по **активному режиму поиска** (см. §4). |
| **Колесо** | Zoom in/out с жёсткими min/max дистанции до сферы. |
| **Hover** | Подсветка страны под курсором **или** tooltip названия станции над маркером (приоритет маркера, если курсор в радиусе hit-test). |

### 3.2. Raycasting — ветвление по режиму

**Режим A — «По странам»**

1. Луч → точка на сфере → $(\phi, \lambda)$.
2. GeoService: R-Tree + Point-in-Polygon → страна.
3. Визуально: яркий **контур / мягкая заливка** выбранной страны (heatmap — опционально, §5.4).
4. Подгрузка станций страны → панель списка (§4.1).

**Режим B — «По маркерам» (Global Genre)**

1. Hit-test 2D-проекций маркеров (как сейчас `MARKER_CLICK_RADIUS`).
2. Попадание → **мгновенный** `start_station`.
3. Промах по маркерам в режиме B → не переключать страну (или слабый no-op), чтобы не смешивать модели.

**Общее правило клика (уточнение к макету):**

1. Маркер приоритетен в обоих режимах: клик по нему всегда запускает станцию.
2. Клик по стране выбирает страну **только в режиме A**; в режиме B он не меняет
   выбор и не сбрасывает маркеры.
3. Клик по океану/стране без ISO-кода — no-op; ошибок и тостов не показывает.

### 3.3. Курсор и affordance

- Hover маркера → `PointingHand`, tooltip.
- Hover страны (режим A) → лёгкая подсветка контура до клика.
- Drag ПКМ → курсор «grabbing» (если egui позволяет).

## 4. Режимы работы и фильтрация станций

Переключатель в **верхнем HUD**:

```
[ Страна ]  [ Жанр ]
```

Состояние: `SearchMode { Country, GlobalGenre }`.

### 4.1. Режим A: «Страна → Станции» (локальный поиск)

Поток:

1. ЛКМ по стране на глобусе.
2. Страна выделяется (контур / заливка).
3. **Боковая панель** со списком станций этой страны (не перекрывает глобус целиком).
4. Фильтры **внутри** панели страны:

| Фильтр | UI | API / логика |
|--------|-----|----------------|
| Текст | Search field | Локальная фильтрация загруженной выборки по `name`, `tags`, `country`, `state` |
| Жанры | Чипы: All, Rock, Pop, Jazz, Electronic, News, Metal, … | Локальная проверка `tags`; новый API-запрос не нужен |
| Сортировка | Popularity (votes) · Bitrate · Name | Локальная сортировка; исходная выдача API — по votes |

Страна загружается одним запросом `countrycode=<ISO alpha-2>` (до 100 станций,
`hide_broken=true`); текст и чипы не порождают сетевых запросов. Для отображения
популярности и карточки `Station` дополняется полями `votes`, `country`, `state`
(Radio Browser не отдаёт город отдельным полем).

В верхнем HUD режима A — поиск страны по названию (`GeoService`), Enter или выбор
подсказки выбирает страну и запускает тот же поток. Камера: опциональный soft focus /
лёгкий доворот к стране (без агрессивного lock).

### 4.2. Режим B: «Глобальный жанр → 3D-карта станций»

Поток:

1. Пользователь включает **Global Genre Search** и выбирает жанр (Synthwave, Heavy Metal, …).
2. Запрос к Radio Browser: топ N станций жанра **с валидными lat/lon**.
   - основной список: `tag=<жанр>`, `limit=200`, сортировка по votes;
   - маркеры: `tag=<жанр>`, `has_geo_info=true`, `limit=200`;
   - оба запроса идут параллельно, ошибка гео-запроса не ломает список.
3. На глобусе:

   - подсветка «активной страны» режима A **сбрасывается**;
   - спавнятся **светящиеся маркеры** в координатах станций;
   - размер/яркость маркера зависит от votes и bitrate (визуальный вес).

4. ЛКМ по маркеру → немедленное воспроизведение.

Группировка совпадающих координат — как сейчас (`MARKER_GROUP_SCALE` + count).
Пока идёт загрузка, старые маркеры очищаются сразу, чтобы карта не показывала
чужой жанр.

### 4.3. Совместимость с текущими вкладками

Вкладки **Результаты / Избранное / История** остаются, но:

- в режиме A «Результаты» = станции выбранной страны (+ фильтры);
- в режиме B «Результаты» = станции выбранного жанра (зеркало маркеров);
- **Избранное / История** — быстрый доступ без вращения глобуса (Starred).

## 5. Расширенные фичи (дизайн-уровень)

### 5.1. Audio Visualizer на глобусе

Источник: уже есть spectrum/FFT через mpv (`spectrum_overlay`).

Визуал (приоритеты):

1. **Первый этап визуализатора:** пульсация атмосферы / Fresnel-обода сферы от RMS/flux (данные FFT).
2. **Далее:** пульс **контура выбранной страны** в режиме A.
3. Не блокировать GUI-поток; только данные с audio-подсистемы.

### 5.2. Избранное и история

Уже есть library + JSON. В дизайне:

- вкладка **Starred** / Избранное — всегда в один клик;
- звезда в строке станции;
- offline play сохранённых URL.

(SQLite — возможная эволюция хранения; сейчас действует JSON по ADR-0013, менять
формат в рамках редизайна не требуется.)

### 5.3. Radio Roulette

Кнопка в HUD: **Случайная станция мира**.

Поведение:

1. Выбор случайной станции: `/json/stations/search?order=random&limit=1&has_geo_info=true&hidebroken=true`.
   При пустом `url_resolved` или без координат — до трёх повторов, затем ошибка.
2. **Анимация камеры** «перелёт» к lat/lon (fly-to, 0.8–1.0 с, ease-out; drag отменяет).
3. Автостарт воспроизведения.
4. Краткий toast / HUD: название и страна.

### 5.4. Индикатор плотности эфира (Heatmap / Glow)

- В режиме A после выбора страны или при hover: заливка полигона **градиентом** по числу станций (синий → тёплый).
- В режиме B: можно не красить страны, акцент на маркерах.
- Данные: `count` из ответа search / отдельный aggregate, без лишних запросов на каждый кадр.
- MVP режима A: контур + мягкая заливка выбранной/наведённой страны; интенсивность —
  от числа загруженных станций. Глобальная карта плотности по всем странам — фаза 5
  (потребуется aggregate-эндпоинт или кэш, отдельное решение).

### 5.5. MPRIS / системный медиаплеер

Уже есть MPRIS (Linux). Дизайн ожидает:

- title / artist (станция, страна или теги);
- artUrl (favicon станции), если есть;
- Play/Pause/Stop, volume с медиа-клавиш;
- корректный DesktopEntry / app-id `org.modernbyte.OrbitFM`.

Фактически title, artist (до фазы 4 — теги), artUrl и команды уже публикуются через
playwire. В фазе 4 artist обогащается страной/штатом, добавляются поля `Station`
для карточки. Системные уведомления и статус-бар Niri — потребители MPRIS; отдельный
`notify-rust` не добавляется. SMTC / Now Playing (Win/macOS) — по ROADMAP,
UI-копирайт тот же.

## 6. Композиция экрана (Focus)

```
┌──────────────────────────────────────────────────────────────────┐
│  ◐ OrbitFM  [Страна|Жанр]  search/chips      ● LIVE    ⚙ ? ☰  ×  │  top HUD
├────────────┬─────────────────────────────────────┬───────────────┤
│            │                                     │  Список       │
│  (опц.)    │           3D GLOBE                  │  станций      │
│  жанры     │     markers / country highlight     │  фильтры      │
│  rail      │     atmosphere pulse                │  ★ ☆          │
│            │                                     │               │
├────────────┴─────────────────────────────────────┴───────────────┤
│  ▶ ■  ♥  🎲 Roulette      codec · kbps · vol ─●─ · spectrum      │  transport
└──────────────────────────────────────────────────────────────────┘
```

Принципы:

- глобус не сжимается ниже комфортного минимума;
- список — drawer/rail (ширина ~280–320px), можно свернуть;
- подсказки управления — tooltip / первый запуск, не вечный футер на 2 строки;
- логотипы станций (favicon) в карточках — фаза 6: нужен асинхронный кэш
  изображений и отдельное решение по зависимости; MVP использует текст,
  codec/bitrate и звезду.

### Overlay-капсула

- top: станция + play/stop + volume;
- center: мини-глобус или статичный регион;
- bottom: 5–8 станций / favorites;
- без блока «Оформление» и длинных help-текстов.

## 7. Визуальный язык

**Настроение:** ночная орбита, стекло, мягкий акцент (не кислотный киберпанк).

**Токены (логически; маппятся на текущие theme/accent):**

| Токен | Роль |
|-------|------|
| `bg.space` | Фон окна / clear |
| `surface.glass` | Панели HUD |
| `accent` | Выделение, чипы, ссылки (6 акцентов из settings) |
| `signal.live` | Playing |
| `signal.buffer` | Buffering |
| `marker.default` / `marker.active` | Точки на глобусе |
| `country.hover` / `country.selected` | Контуры |
| `heatmap.low` → `heatmap.high` | Плотность станций |

Типографика: системный sans; метаданные станции — tabular numbers для bitrate.

## 8. Состояния UI (обязательные)

| Состояние | Поведение |
|-----------|-----------|
| Idle, нет выбора | Глобус + пустой/свёрнутый список + CTA |
| Country selected, loading | Скелетон/спиннер в панели списка |
| Country selected, empty | «В этом секторе пока тихо» + сброс фильтров |
| Genre mode, loading markers | Прогресс + глобус без устаревших маркеров |
| Playing | Индикатор «● LIVE» в HUD + pulse/visualizer; имя станции и её логотип — в transport и списке |
| Error (network/audio) | Тост/баннер, не блокирующий глобус |
| Offline favorites | Список из library без запроса API |

## 9. Карта на текущий код (аудит 2026-10-23)

| Требование | Сейчас в коде | Что делаем | Фаза |
|------------|---------------|------------|------|
| ПКМ orbit + damping | `GlobeCamera::update` в `src/render/camera.rs`: yaw/pitch, damping 6.0, min/max 1.4–6.0 | Сохранить; добавить тест fly-to и отмену анимации drag | 4 |
| ЛКМ country / marker | `src/app.rs::draw`: маркер (10 px) приоритетнее, иначе `screen_to_sphere` → `country_at_sphere_point` | Ввести `SearchMode`; маркер играет всегда, страна — только в режиме A | 2 |
| Zoom limits | Есть (`MIN_DISTANCE`/`MAX_DISTANCE`) | Подсказка в tooltip, без изменения контракта | 1 |
| Hover marker tooltip | Есть (`nearest_marker`, `paint_markers`) | Сохранить; hover страны — новый слой `render/countries.rs` | 2 |
| Country → stations | Есть: `countrycode`, limit 30, список 132 px | Панель 300–320 px, limit 100, локальные фильтры и сортировка | 2 |
| Global genre markers | Нет отдельного режима; маркеры строятся из любого поиска, limit 60 | `SearchMode::GlobalGenre`, tag-запрос, limit 200, вес маркера | 3 |
| Favorites / history | Есть JSON (`src/library/`), вкладки в карточке | Перенести в правый drawer, вкладка Starred, поведение не менять | 1 |
| Spectrum | Полоска под глобусом (`SpectrumOverlay`) | Атмосфера/Fresnel pulse в шейдере; полоска — опция | 5 |
| MPRIS | title/artist(теги)/artUrl, play/pause/stop, volume | artist = страна/штат или теги; больше метаданных в карточке | 4 |
| Roulette | Нет | `order=random` + fly-to + toast + автостарт | 4 |
| Heatmap страны | Нет | Контур/заливка выбранной и наведённой страны по count | 5 |
| Country search в HUD | Нет (поиск только станций по имени) | `GeoService::search_countries`, выбор страны без клика | 2 |
| UI-модули | `app.rs` 1638 строк, `Palette` и весь draw внутри | `src/ui/`: `hud`, `station_panel`, `transport`, `globe_view`, `palette`; `app.rs` — оркестратор | 1 |
| WindowMode / Overlay | Только show/hide; overlay = та же карточка | Focus MVP; Overlay/Listening — отдельная фаза и IPC-решение | 6 |
| Favicon-карточки | Нет загрузчика изображений | Асинхронный кэш + отдельное решение по зависимости | 6 |

`Station` сейчас не содержит `votes`/`country`/`state` — это добавится в фазе 2 с
`serde(default)` для совместимости с `library.json`. Города в Radio Browser нет:
карточка показывает `state`/`country`, а название станции часто содержит город.

Аудит в таблице зафиксирован до начала Этапа 8; после закрытия фаз актуальное
состояние ведётся в ROADMAP и CHANGELOG.

`GeoService` умеет только `country_at`/`country_at_sphere_point`; для контура,
hover и поиска страны нужны новые методы, возвращающие геометрию и список стран
(фаза 2). R-Tree и `MultiPolygon` уже внутри — новый датасет не нужен.

## 10. Критерии приёмки дизайна (MVP redesign)

1. В Focus глобус визуально доминирует; список не занимает половину высоты по умолчанию.
2. Режим A: клик по стране → выделение → список с текстом, чипами жанров и сортировкой.
3. Режим B: выбор жанра → маркеры по миру → клик по маркеру стартует эфир.
4. ПКМ-drag с инерцией, scroll-zoom с пределами, hover affordance.
5. Roulette: анимация камеры + play.
6. Overlay остаётся компактным и управляемым с панели Noctalia (фаза 6; MVP Focus
   не должен ухудшить текущий hide/toggle).
7. Темы/акценты продолжают работать через существующий settings.

---

## 11. Вне скоупа этого документа

- Смена GUI-фреймворка.
- Полный PBR/фотореализм Земли.
- Тысячи маркеров без LOD/кластеризации (нужен отдельный perf-ADR при N ≫ 500).
- SQLite и смена формата library/settings (действуют ADR-0013/ADR-0014).
- Новые IPC-команды, кроме отдельно принятого решения для WindowMode.
