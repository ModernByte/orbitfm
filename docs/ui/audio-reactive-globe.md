## 1. Идея

Земля не статичный шар. Она **дышит и слегка деформируется в такт эфиру** —
как капля, которая держит форму, но отзывается на бас, середину и верх.
Движение идёт **строго из аудиосигнала**, а не из случайного screensaver.

Это не замена cava-визуализатору и не «желейный шар». Это второй, более
физичный слой: глобус остаётся глобусом, маркеры и страны остаются на своих
местах, а пользователь в любой момент может забрать камеру себе.

Ключевые принципы:

1. **Малые амплитуды.** Normal — до 2 % squash, High — до 3,5 %. Планета
   дышит, а не разваливается.
2. **Камера пользователя приоритетнее.** Drag, zoom, клик и `fly_to`
   подавляют музыкальную качку и перевороты.
3. **Никакого random.** Стиль, onset и фаза бита — функции сигнала и времени.
4. **Stop — не обрыв.** Возврат в idle-дыхание за 300–500 мс.
5. **Доступность.** Off, Reduce motion, ограничения Overlay/Listening и
   выключенные по умолчанию перевороты.
6. **Аудио не трогаем.** Полосы считаются копией сигнала; PCM остаётся
   побитово тем же (ADR-0027).
7. **Без новых зависимостей.** Анализ — libavfilter через mpv, движение —
   Rust + WGSL.

## 2. Что уже есть и чего не хватает

| Есть | Ограничение |
|------|-------------|

| `GlobeCamera` с orbit/inertia/fly_to/idle | Sway, приоритет и camera roll реализованы (Phase 3) |

| `Settings`: тема, акцент, `viz_bars`, `help_seen`, `motion`, `motion_style`, `allow_flips`, `reduce_motion` | Стиль и `Allow flips` выбираются в HUD; flips реализованы |
| `OrbitRing`: круговой слой за глобусом (ADR-0029) | Не деформирует планету; питается шестью агрегатами, а не полосами |
| cava-визуализатор синтетический (ADR-0022) | Полосы не дают per-bin спектр; это не меняется |

Орбитальное кольцо реализовано вне фаз этого документа (ADR-0029): оно занимает
пространство между силуэтом планеты и краем окна, поэтому деформация глобуса
(Phase 1) должна применяться к сфере, маркерам и hit-test одновременно и не
конфликтовать с экранным радиусом кольца.

## 3. Аудио-фичи

Полосы реализованы в Phase 0 по ADR-0027. Если `bands = None`, движение
деградирует до полного RMS+flux — это аварийный, а не целевой режим.

| Фича | Источник | Использование |
|------|----------|----------------|
| `rms_db` | `@level` / `astats` | общий уровень, дыхание, затухание |
| `bass_db` | `@spectrum` каналы 3–4 | squash, onset, Bass Drop |
| `mid_db` | `@spectrum` каналы 5–6 | Groove Sway, Beat March |
| `high_db` | `@spectrum` каналы 7–8 | Sparkle Twitch, рябь |
| `flux` | `@level` / `aspectralstats` | onset, рябь, резкость |
| `centroid_hz` | `@level` | Auto-стиль, Sparkle |
| `flatness` | `@level` | Ambient Drift |
| `spread_hz` | `@level` | резерв для стилей |
| `beat_phase` | вычисляется в `motion.rs` | качка, Beat March |
| `onset_confidence` | вычисляется в `motion.rs` | перевороты, смена стиля |

Все значения приходят с шагом ~50 мс. UI сглаживает их и не пытается
интерполировать аудио между опросами.

## 4. Модель движения

### 4.1. Нормирование и сглаживание

```text
norm_db(db) = clamp((db - FLOOR_DB) / RANGE_DB, 0, 1)
```

Для полос `FLOOR_DB = -90`, `RANGE_DB = 80` (рабочий диапазон примерно
−90…−10 dB). Для общего RMS используется существующая шкала
`SpectrumOverlay` (−60…0 dB).

Сглаживание — асимметричное:

- атака ~20–40 мс (быстрый отклик на удар);
- спад ~180–300 мс (планета не дёргается на каждом кадре);
- `dt` ограничивается 0…0,1 с; после сна окна значения не «прыгают».

### 4.2. Spring-squash

Цель — объёмное сжатие/растяжение (`amount` = `squash_limit` реактивности):

```text
target = 1 − amount · bass_env + idle
v += (k · (target − s) − c · v) · dt
s += v · dt
s = clamp(s, 1 − amount, 1 + amount)
scale_y = s
scale_xz = 1 / sqrt(scale_y)
```

Параметры: `k = 120`, `c = 14` (околокритическое затухание, без длительного
звона); интеграция полунеявная с шагом ≤ 1/240 с. `scale_xz` сохраняет
объём. При `Off`/`Reduce motion` `s = 1`.

### 4.3. Onset и фаза бита

- кольцевой буфер 2,1 с (43 сэмпла по 50 мс); детектор шагает фиксированно
  по 50 мс независимо от fps;
- базовая линия — медиана и σ последних ≤20 сэмплов (1 с) без последних
  4 (200 мс), минимум 10 сэмплов;
- порог Bass — `median + max(0,04; 0,35 σ)`, flux — `median + max(0,02;
  0,45 σ)`; сила удара нормируется диапазоном 0,25;
- рефрактерный интервал 150 мс;
- `onset_confidence` растёт на `0,30 · strength` и затухает с τ 1,5 с;
  импульс бита — с τ 0,18 с;
- период — медиана последних 4 интервалов, каждый ограничен 1/3…1 с
  (60–180 BPM);
- `beat_phase` сбрасывается в 0 на onset и иначе накапливается по
  `50 мс / period`;
- бит применяется через гейт `((confidence − 0,20) / 0,30).clamp(0, 1)`.

Если onset'ов нет, `beat_phase` не применяется: стили остаются на дыхании,
а не «маршируют по таймеру». Stop, `None` и `Off` сбрасывают детектор.

### 4.4. Стили

| Стиль | Когда Auto выбирает | Характер |
|-------|---------------------|----------|
| Soft Pulse | низкий уровень и flux; fallback без полос | дыхание + лёгкий bass squash |
| Groove Sway | устойчивые onset, сильная середина | yaw-качка ±0,015 рад в фазе бита |
| Bass Drop | бас доминирует, сильный onset | глубокий squash, короткая рябь, лёгкий flash |
| Ambient Drift | низкий flux, высокий flatness | очень медленный дрейф и рябь |
| Sparkle Twitch | высокий centroid, много высоких/flux | мелкая высокочастотная рябь, без качки |
| Beat March | регулярные интервалы, высокая уверенность | шаг на бит, умеренный squash |

Параметры стиля (`StyleParams`): множитель squash, амплитуда sway, множитель
ряби, максимум flash, вклад импульса бита, вес дрейфа и добавка к скорости
ряби. Soft Pulse — `1,0 / 0 / 0,45`; Groove Sway — `0,65 / 0,015 / 0,55` и
бит 0,15; Bass Drop — `1,25 / 0 / 0,50`, flash 0,10 и бит 0,35; Ambient
Drift — `0,45 / 0,006 / 0,70` с дрейфом 1,0; Sparkle Twitch — `0,50 / 0 /
1,0` со скоростью 1,8; Beat March — `0,80 / 0,008 / 0,45` с битом 0,80.

Auto:

- признаки (уровень, flux, доли полос, centroid 200–4000 Гц, flatness)
  сглаживаются EMA с τ 2,5 с, а не одним кадром;
- минимальное удержание стиля 3 с;
- кроссфейд параметров 1 с по smoothstep;
- при недоступности полос Auto ограничивается Soft Pulse / Groove Sway /
  Ambient Drift; ручной стиль, требующий полос, деградирует до Soft Pulse;
- пропажа полос сразу уводит текущий band-стиль в Soft Pulse, не дожидаясь
  удержания.

Ручной стиль не отключает защиту от переворота и приоритет камеры.

### 4.5. Камера и перевороты

- `yaw_sway` — добавка к yaw камеры, только когда нет drag/zoom/click/fly_to:
  `sway = motion.yaw_sway·(1 − priority)`;
- `priority` сглаживается с τ 80 мс: при взаимодействии 150–250 мс выводят его
  к 1, после отпускания качка возвращается плавно; squash/ripple при полном
  приоритете ослаблены до 35 % (`with_camera_priority`);
- авто-вращение ADR-0023 остаётся базовым слоем;
- переворот — **roll камеры** вокруг оси взгляда, а не поворот модели:
  `projection · rotation_z(roll) · view`; все проекции и hit-test используют
  одну матрицу;
- триггер — фронт `pulse ≥ 0,6`; перевороты: default off, 0,9 с (диапазон
  0,6–1,2 с), кулдаун 12 с (диапазон 8–20 с), направление чередуется;
- старт только при `allow_flips`, простое ≥ 2 с, отсутствии drag/`fly_to`,
  `priority ≤ 0,5` и pitch не у края ±85° (запас 5°);
- drag, `fly_to` или снятие `allow_flips` отменяют переворот, остаточный roll
  затухает с τ 80 мс;
- в Overlay/Listening и при Reduce motion перевороты запрещены: `allow_flips`
  для камеры вычисляется как настройка ∧ `Full` ∧ включённая эффективная
  реактивность; в HUD переключатель недоступен при Off/Reduce motion.

### 4.6. Stop и idle

- после Stop/паузы/пропажи спектра цель — idle-дыхание 0,12 Гц,
  амплитуда 0,35 % (Normal);
- `RELEASE_TAU = 0,10 с`: 300 мс → ~5 %, 500 мс → <1 % рабочей амплитуды;
- idle-дыхание рисуется ~15 fps, это меньше существующего авто-вращения
  (30 fps), поэтому худший случай нагрузки не растёт;
- при `Off`/`Reduce motion` дополнительных кадров нет;
- пока окно скрыто, аудио-анализ снят вместе с UI: при показе граф
  возвращается, а дыхание продолжается с текущей фазы.

## 5. Рендер-контракт

### 5.1. Uniform

`CameraUniform` расширяется двумя `vec4`:

```text
motion:  x = scale_y − 1, y = scale_xz − 1,
         z = ripple_amp,   w = ripple_phase
motion2: x = flash,       y = style_id,
         z = beat_phase,   w = time
```

Оба `vec4` реализованы (`CameraUniform` занимает 128 байт). `motion2.y` —
числовой `MotionStyle::id`: Auto 0, Soft Pulse 1, Groove Sway 2, Bass Drop 3,
Ambient Drift 4, Sparkle Twitch 5, Beat March 6; рендерер id не
интерпретирует. Поле `pulse` и старый аудио-пульс удалены из `CameraUniform`
и шейдера 2026-10-24. Fresnel-обод усиливается `flash` на onset и не имеет
фоновой аудио-модуляции. `CameraUniform` должен сохранять 16-байтовое
выравнивание и проходить `bytemuck::Pod`.

### 5.2. Вершинный шейдер

- анизотропный масштаб `vec3(scale_xz, scale_y, scale_xz)`;
- радиальная рябь: три лепестка по долготе, затухание к полюсам,
  амплитуда ≤ 0,4 % (Phase 1: `MotionReactivity::ripple_limit`);
- нормаль для освещения — `normalize(normal / scale)` (обратная
  транспонированная диагональ масштаба); нормаль ряби не считается
  (амплитуда мала);
- `flash` усиливает Fresnel-кромку: `rim = fresnel · (0,12 + motion2.x)`,
  но не заменяет её; предел 0,15.

### 5.3. Согласованность overlay'ев

Squash — линейное преобразование, поэтому применяется и на CPU:

```text
world = unit · vec3(scale_xz, scale_y, scale_xz)
```

- маркеры: точка сферы → `deform.to_world()` → `project`;
- страны: точки колец → `deform.to_world()` → `paint_country`;
- hit-test: луч → обратный масштаб → единичная сфера → единичная точка
  для `GeoService`;
- ripple в hit-test не входит: ≤ 0,4 % радиуса — осознанная граница.

При `Off` деформация — identity; старые тесты и поведение не меняются.

### 5.4. Перерисовка

| Состояние | Кадры |
|-----------|-------|
| Движение активно | `request_repaint_after(33 ms)` |
| Переворот | обычная частота на 0,6–1,2 с |
| Idle-дыхание | ~15 fps |
| Off / Reduce motion | без дополнительных кадров |
| Окно скрыто | 0 (ADR-0018); `@level`/`@spectrum` сняты до показа |

## 6. Настройки и режимы

```rust
pub enum MotionReactivity { Off, Low, Normal, High }
pub enum MotionStyle {
    Auto, SoftPulse, GrooveSway, BassDrop,
    AmbientDrift, SparkleTwitch, BeatMarch,
}
```

| Поле | Default | Примечание |
|------|---------|------------|
| `motion` | `Normal` | Focus; Overlay не выше Low; Listening — Off |
| `motion_style` | `Auto` | ручной стиль доступен в Focus; Auto выбирает по сигналу |
| `allow_flips` | `false` | недоступен при Off/Reduce motion |
| `reduce_motion` | `false` | выключает squash/ripple/sway/flips |

Все поля — `#[serde(default)]`; старый `settings.json` читается без ошибок.
UI — секция Motion в меню шестерёнки HUD (`src/ui/hud.rs`), сохранение
немедленное, как у темы и акцента.

**Анализ включается, если нужен хотя бы одному потребителю:**

```text
analysis_needed = window_visible
               && (visualizer_enabled || (motion != Off && !reduce_motion))
```

Поэтому cava-визуализатор можно выключить, а движение планеты оставить.
`reduce_motion` не отключает эфир и визуализатор — только геометрию и качку.
В `park` окна нет, формула ложна, и `settle_analysis` снимает фильтры до показа.

## 8. Фазы

### Phase 0 — Полосы эфира (ADR-0027) — реализовано

**Задачи:**

1. Спайк на целевых сборках: system mpv (Linux), Flatpak runtime, Windows
   MSYS2, macOS Homebrew. Проверить наличие `acrossover`, `amerge`, `pan`,
   `astats`, `aspectralstats`. Linux проверен; остальные платформы — в Phase 4.
2. Проверить `audio-params/channel-count` до/после `FileLoaded`; выбрать
   stereo/mono/other graph. Свойство может быть `nil` при `FileLoaded` —
   добавлены повторные чтения (8 × 250 мс).
3. Расширить `SpectrumFrame` и `SpectrumTarget` опциональными полосами.
4. Реализовать `@level` + `@spectrum`, чтение 12 ключей, санитизацию
   `-inf`/`NaN`, fallback на `@level`.
5. Замеры CPU аудиопотока (сравнить с текущим фильтром).
6. Обновить `docs/interfaces/01-audio.md`, `docs/modules/01-audio-engine.md`.

**DoD:**

- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, `cargo test` — чисто;
- local tone test: полосы видны, stereo/mono PCM побитово совпадает;
- реальная станция играет без сбоев; отключение/включение анализа не рвёт звук;
- при отсутствии фильтров — `warn!`, звук жив, `bands = None`;
- ни одного нового crate'а.

Проверено 2026-10-24 на Linux (mpv 0.41, FFmpeg n9.0.2): unit-тесты и живые
stereo/mono-прогоны через локальный HTTP-поток; PCM побитово совпадает,
переключение анализа звук не прерывает. Замер CPU на 60 с stereo-WAV:
`@level` ≈ 1,5 с, полный граф ≈ 4,3 с — около 7 % одного ядра, вклад полос
≈ 4,6 п.п.; порядок `acrossover` понижать не нужно.

### Phase 1 — Ядро движения и squash — реализовано

**Задачи:**

1. `motion.rs`: нормирование, сглаживание, spring-squash, idle-дыхание,
   затухание 300–500 мс.
2. `GlobeDeform` и согласованные маркеры/страны/hit-test.
3. `CameraUniform.motion`, шейдерный squash + малая рябь.
4. Настройки `motion`, `reduce_motion`; `analysis_needed`.
5. Репит-правила 30/15 fps; Off — без дополнительных кадров.
6. Тесты пружины, объёма, затухания, identity-деформации.

**DoD:**

- на реальной станции планета дышит, маркеры не «плывут», клик по маркеру
  и стране попадает при Normal;
- Stop → возврат в idle за 300–500 мс;
- Off/Reduce motion визуально неподвижны (кроме статичного Fresnel-обода);
- `cargo` gate чистый; CPU/GPU без регрессии.

Проверено 2026-10-24 на Linux: `cargo fmt`, `cargo clippy --all-targets --
-D warnings` и `cargo test` (258 тестов) чисты; в изолированном Weston с
локальным HTTP-потоком деформация видна по изменению силуэта, Stop возвращает
планету в idle, сам интерфейс не пострадал. Ограничение проверки: headless-среда
без инъекции ввода не позволила открыть меню настроек и переключить
Off/Low/High вручную — эти режимы покрыты unit-тестами; живая проверка на
niri остаётся в Phase 4.

### Phase 2 — Onset, бит и стили — реализовано

**Задачи:**

1. Onset-детектор, `beat_phase`, `onset_confidence`.
2. Шесть стилей и Auto с гистерезисом/кроссфейдом.
3. Расширение uniform (`motion2`), flash-кромка, ripple-параметры.
4. Тесты на синтетических последовательностях: удар, тишина, шум,
   смена стиля, недоступные полосы.
5. Настройка `motion_style` и секция HUD.

**DoD:**

- на трёх разных станциях (речь/поп/электроника) стиль не дребезжит;
- тишина и речь не вызывают «марша» или переворота;
- без полос Auto не выбирает стили, требующие Bass/High;
- настройки сохраняются и читаются после перезапуска.

Проверено 2026-10-24 на Linux: `cargo fmt`, `cargo clippy --all-targets --
-D warnings` и `cargo test` (270 тестов) чисты. Onset, период/регулярность,
рефрактерность, гейт уверенности, выбор стиля по характеру сигнала,
удержание/кроссфейд Auto и деградация без полос покрыты синтетическими
последовательностями; сохранение `motion_style` проверено roundtrip-тестом
`SettingsStore`. Живая проверка на трёх реальных станциях и на niri
отложена до Phase 4: текущая среда не даёт открыть HUD и управлять эфиром
без вмешательства в запущенный экземпляр.

### Phase 3 — Камера, перевороты и режимы — реализовано

**Задачи:**

1. Музыкальный yaw sway и roll в `GlobeCamera`; приоритет drag/zoom/fly.
2. Перевороты: условие, длительность, кулдаун, только при простое.
3. Ограничения Overlay (≤ Low) и Listening (Off).
4. `allow_flips`, `reduce_motion` в UI; недоступность flips при Off.
5. Тесты приоритета камеры, кулдауна, режимов, Reduce motion.

**DoD:**

- во время drag камера не сопротивляется музыке;
- переворот не запускается при `fly_to`, клике, Overlay/Listening;
- Reduce motion и Off полностью исключают качку/roll;
- hit-test и страны согласованы после roll (общая `view_proj`).

Проверено 2026-10-24 на Linux: `cargo fmt`, `cargo clippy --all-targets --
-D warnings` и `cargo test` (278 тестов) чисты. Покрыто unit-тестами: sway
следует за свободной камерой, гаснет при drag и плавно возвращается; squash
и рябь ослабляются до 35 % на полном приоритете; переворот не стартует без
разрешения, простоя, при крайнем pitch и вне фронта onset; длительность 0,9 с

повёрнутая матрица сохраняет согласованность `project_on_sphere` и
`screen_to_sphere_deformed`; `allow_flips` переживает roundtrip настроек.
Режимные ограничения вычисляются в `app.rs` (`Full` ∧ реактивность ∧
настройка) и проверены через существующие тесты `motion_reactivity`;
живая проверка на niri — Phase 4.

## 9. Тесты

**Unit:**

- `band_levels_from_channels`: карта 3–8, power-mean L/R, `-inf` → floor,
  `NaN` → `None`;
- выбор stereo/mono/other graph и fallback;
- spring: ограничение амплитуды, сохранение объёма, устойчивость;
- stop-fade: 300–500 мс до <1 %;
- onset: регулярная последовательность даёт период ≈0,5 с, регулярность
  >0,85 и уверенность >0,5; рефрактерность отсекает повторные удары; Stop
  сбрасывает фазу и уверенность;
- beat phase в 0..1, период 60–180 BPM, гейт уверенности управляет фазой
  и flash;
- Auto: выбор по характеру сигнала (Ambient Drift, Sparkle Twitch,
  Bass Drop, Beat March), удержание 3 с, кроссфейд и запрет band-стилей
  без полос;
- ручной стиль без полос уходит в Soft Pulse; стилевые добавки соблюдают
  лимиты реактивности;
- приоритет камеры: drag/zoom/fly гасят sway и flips; squash/ripple
  ослабляются до 35 %, после отпускания sway возвращается;
- перевороты: старт только при разрешении, простое ≥2 с, сильном onset и
  pitch не у края; длительность 0,9 с, кулдаун 12 с; drag отменяет
  переворот, остаточный roll затухает;
- roll: `project_on_sphere` и `screen_to_sphere_deformed` согласованы после
  поворота матрицы, радиус проекции сохраняется;
- режимы: Overlay ≤ Low, Listening Off;
- `GlobeDeform`: прямой/обратный ray roundtrip, идентичность;
- `CameraUniform` POD/размер/выравнивание;
- `analysis_required`: скрытое окно выключает анализ при любых настройках;
  визуализатор включает анализ и при Reduce motion, движение — только при
  включённой реактивности.

Всего 280 тестов (3 ignored) — `cargo test` зелёный на приёмке.

**Live (вне CI):**

- локальный тон 100 Гц + 1000 Гц: полосы и побитовый PCM — Phase 0;
- реальные станции FLAC и MP3 128 kbps, Stop, режимы и hide/show — Phase 4;
- mono-станция и реконнект — покрыты unit-тестами и ADR-0027, в live не
  форсировались;
- drag во время движения — unit-тесты приоритета камеры;
- CPU/GPU — Phase 4 (см. таблицу выше).

## 10. Критерии успеха

1. Планета реагирует на эфир, но остаётся планетой: амплитуда Normal ≤ 2 %,
   High ≤ 3,5 %.
2. Пользовательский orbit, zoom и `fly_to` не подавляются музыкой.
3. Stop/пауза возвращают в idle-дыхание за 300–500 мс без щелчка.
4. Нет ложных переворотов; default off, кулдаун, режимы, Reduce motion.
5. Нет сбоев звука и роста CPU, заметного на слух/в `top`.
6. Маркеры, страны и клики согласованы при Normal.
7. Старый `settings.json` читается; новые настройки сохраняются.
8. При недоступности полос приложение работает и честно деградирует.
9. Cava-визуализатор не выдаёт себя за реальный спектр; motion использует
   только реальные полосы/агрегаты.
10. Документация, ADR и код совпадают.

## 11. Открытые вопросы (закрыты на приёмке Phase 4)

1. **Каналы до фильтра.** **Закрыт:** после `FileLoaded` воркер до 8 раз с
   интервалом 250 мс читает `audio-params/channel-count` и переустанавливает
   граф; неизвестная раскладка оставляет `@level`.
2. **Сборки libmpv.** **Закрыт статически:** Flatpak собирает mpv 0.41 с
   обычным FFmpeg, Windows берёт MSYS2 UCRT64, macOS — CI-раннер; CI-задачи
   Windows/macOS (check, MSI, DMG) зелёные. Рантайм Flatpak и Windows/macOS
   в этой среде не запускался; fallback `@level` остаётся страховкой.
3. **Порядок `acrossover`.** **Закрыт:** оставлен 8th. Живой замер показал
   около 15 п.п. одного ядра на полный граф поверх декодирования; скрытая
   стоимость устранена снятием анализа в парке, а не снижением качества полос.
4. **Reduce motion и авто-вращение ADR-0023.** **Закрыт:** авто-вращение не
   останавливаем. Подпись Reduce motion прямо ограничивает область
   («Stop squash, ripple and camera sway»), а медленное вращение после 4 с
   простоя — базовая навигация ADR-0023. Изменение потребовало бы отдельного
   ADR.
5. **Idle-дыхание на старте.** **Закрыт:** дышит сразу при запуске, ~15 fps;
   живой замер — около 7 % CPU и 5 % GPU на открытом окне без эфира.
6. **Перевороты.** **Закрыт:** оставлен camera roll; live-прогон не выявил
   расхождений overlay/hit-test. Перевороты по умолчанию off и в live не
   включались; матрица, кулдаун и отмена покрыты unit-тестами.
