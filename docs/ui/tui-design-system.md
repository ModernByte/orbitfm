# OrbitFM TUI — язык дизайна и визуальная спецификация

**Организация:** ModernByte  
**Дата:** 2026-11-21  
**Статус:** спецификация для реализации (дизайн-фундамент трека TUI); код не начат  
**Относится к:** `orbitfm-tui` — терминальный клиент к ядру `orbitfm`
(ADR-0047, интерфейс 16, модуль 19)

Связано: [`docs/ui/design-vision.md`](design-vision.md),
[`docs/ui/visual-spec.md`](visual-spec.md) (desktop-планка),
[`docs/modules/19-tui.md`](../modules/19-tui.md),
[`docs/interfaces/16-tui.md`](../interfaces/16-tui.md),
[`docs/tui/README.md`](../tui/README.md),
[`docs/tui/roadmap.md`](../tui/roadmap.md).

Документ отвечает на один вопрос: **как выглядит и ощущается современный
OrbitFM в терминале**, не копируя egui-глобус и не превращая TUI в цветной
шум. Функциональное поведение (экраны, команды, IPC) живёт в модуле 19 и
интерфейсе 16; здесь — визуальный язык, токены, компоненты, движение и
правила доступности.

---

## 1. Принципы

1. **Продолжение Orbital Desk, а не его копия.** Desktop — «радио Земли в
   неоне»: тёмная сцена, один акцент, стекло, орбитальные кольца. TUI
   берёт из этого **намерение** (неон на тёмном, один акцент, ощущение
   прибора), но живёт в 16 цветах и ячейках терминала. Truecolor-градиент —
   не обязательное условие.
2. **Терминал — фон пользователя.** TUI не заливает экран своим фоном и не
   навязывает палитру. По умолчанию используется `default` фон и `default`
   текст терминала; интерфейс строится **рамками и одним акцентом**. Это
   уважение к рисовке (rice) — прямой сценарий аудитории (аудит TUI §1).
3. **Состояние читается без цвета.** Каждый статус несёт глиф и слово
   (`▶ playing`, `■ stopped`, `! error`). Цвет — усилитель, не носитель
   смысла.
4. **Один акцент на кадр.** Акцент (по умолчанию `cyan`) маркирует действие
   и фокус. Вторичное — `DIM` и серый. Тепловая рампа (зелёный→жёлтый→
   красный) зарезервирована за визуализатором и предупреждениями, не за
   декором.
5. **Спокойствие важнее эффекта.** Тик ≤ 15 FPS, `motion = reduced|off`,
   запрет полнокадровых инверсий и вспышек чаще 3 Hz. TUI может жить в
   tmux часами — он не должен мигать.
6. **Ноль сюрпризов.** `q` выходит из TUI и не трогает эфир; `Q` требует
   подтверждения; ошибки видны в одной строке статуса, не посреди сцены.
7. **Композиция из модулей.** Экран — не монолит, а набор панелей
   (`now_playing`, `visualizer`, `search`, `results`, `favorites`, `history`,
   `status`, `help`). Скрытый модуль исчезает вместе со своей зоной; пустых
   «дыр» и рамок-призраков нет.

## 2. Токены дизайна

Токены — единственный источник цвета, глифов и отступов для всех
отрисовщиков. Они же — публичное соответствие `tui.toml` (§9) и будущего
модуля `src/ui/theme.rs`.

### 2.1. Палитра (ANSI 16, тема `orbit-dark` по умолчанию)

TUI обращается **только** к 16 индексированным цветам или к `Reset`. Прямые
RGB-значения запрещены: терминал пользователя решает, как они выглядят.

| Токен | ANSI | Назначение |
|-------|------|------------|
| `fg.default` | default | основной текст, имена станций |
| `fg.muted` | `BrightBlack` + `DIM` | подписи, страна, bitrate, подсказки |
| `fg.label` | `BrightBlack` | заголовки секций (upcase), служебные метки |
| `accent` | `Cyan` | фокус, выбранная строка, заголовок приложения, активный транспорт |
| `accent.weak` | `Cyan` + `DIM` | неактивный акцент, границы нефокусных панелей |
| `surface` | default | панели не заливаются; отличаются рамкой |
| `border` | `BrightBlack` | обычная рамка панели |
| `border.focus` | `accent` | рамка панели в фокусе |
| `status.playing` | `Green` | `▶ playing`, «эфир идёт» |
| `status.paused` | `Yellow` | `‖ paused` |
| `status.stopped` | `BrightBlack` | `■ stopped` |
| `status.buffering` | `Cyan` | `... buffering` |
| `status.reconnect` | `Yellow` | `↻ reconnecting` |
| `status.error` | `Red` | `! error`, сбой команды |
| `favorite` | `Yellow` | `★` избранное |
| `live` | `Green` | `● live` маркер в шапке |
| `warning` | `Yellow` | предупреждение таймера сна |
| `danger` | `Red` | подтверждение `Q`, необратимое действие |
| `viz.low` | `Green` | низ визуализатора (зона громкости) |
| `viz.mid` | `Yellow` | середина визуализатора |
| `viz.high` | `Red` | верх визуализатора / клиппинг |

Правила контраста:

- текст поверх `accent` — `Black`, и только он (для инверсии выделения);
- `fg.muted` никогда не используется для единственного смыслового сообщения;
- `status.error`/`danger` не применяются к обычному тексту;
- при `NO_COLOR=1` все токены цвета схлопываются в `Reset`, остаётся
  `Modifier` (`REVERSED` для выбора, `DIM` для вторичного, `BOLD` для
  заголовков).

### 2.2. Темы

Тема — это **один акцент** плюс необязательная семантика. Список намеренно
короткий (конфиг `ui.theme`, §9):

| id | Акцент | Настроение |
|----|--------|------------|
| `orbit-dark` (default) | Cyan | неоновая преемственность desktop |
| `ice` | Blue | холодный «диспетчерский» |
| `amber` | Yellow | ретро-CRT, тёплый |
| `green` | Green | фосфорный терминал |
| `magenta` | Magenta | «вечерний эфир» |
| `mono` | default + `BOLD` | без цвета вовсе (эквивалент `NO_COLOR`) |

Тема не меняет семантику статусов: `playing` всегда зелёный (или `BOLD ▶`
в `mono`), `error` всегда красный (или `!` + `REVERSED`). Меняется только
акцент интерфейса.

### 2.3. Глифы

Два набора: `glyphs = "unicode"` (по умолчанию) и `glyphs = "ascii"` (для
шрифтов без Unicode). Переключение — конфиг или автоопределение по
`LANG`/`TERM` (§7.4).

| Смысл | Unicode | ASCII | Комментарий |
|-------|---------|-------|-------------|
| playing | `▶` | `>` | |
| paused | `‖` | `II` | |
| stopped | `■` | `#` | |
| buffering | `...` | `...` | анимируется спиннером |
| reconnecting | `↻` | `@` | |
| error | `!` | `!` | |
| live | `●` | `*` | пульсирует, период 1.4 с |
| favorite on/off | `★` / `☆` | `*` / `o` | |
| sleep timer | `◷ mm:ss` | `[t] mm:ss` | |
| volume | `▁▂▃▄▅▆▇█` | `-` `=` | полный блокгадж |
| gauge fill/empty | `█` / `░` | `#` / `-` | |
| visualizer bars | `▁▂▃▄▅▆▇█` + `▀▄` | `#`, `-`, `=` | half-block единицы |
| ring / scope | Braille `⠁...⣿` | `*`, `.` | §5.4 |
| peak hold | `▔` | `-` | отдельная метка |
| border (rounded) | `╭─╮│╰╯` | `+--+\|` | |
| border (square) | `┌─┐│└┘` | `+--+\|` | `ui.border = "square"` |
| scrollbar | `█ ▒ ░` | `# + -` | |
| spinner | `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` | `\|/-\` | |
| selection bar | `▌` | `>` | левая полоса выбранной строки |
| separator | `·` | `-` | между метаданными |

### 2.4. Плотность и отступы

| Токен | Значение | Применение |
|-------|----------|------------|
| `space.frame` | 1 ячейка | внешняя рамка экрана (опциональна) |
| `space.panel.x` | 1 колонка | внутренний отступ контента панели |
| `space.row` | 1 строка | строка списка |
| `space.group` | 1 строка | пустая строка между смысловыми блоками |
| `fixed.volume` | 4 символа | `100%` / ` 70%` — фиксированная ширина, чтобы не дрожали соседи |
| `fixed.sleep` | 5 символов | `12:00` / ` 1:23` |
| `fixed.bitrate` | 4 символа | `128k` |
| `fixed.country` | 2 заглавные буквы | код страны |
| `fixed.selection` | 1 колонка | полоса `▌` |

Правило: **числовые и позиционные поля фиксированной ширины.** Тик не должен
двигать соседние контролы (это прямо закреплено и в desktop-спецификации
отсчёта таймера сна, ADR-0057).

## 3. Каркас и сетка

```
┌ ORBITFM ● live ─────────────────────────────── v0.1 · core 0.23 ┐  header (1)
│ ▶ Radio XYZ  · DE · 128k · 70% · ◷ 14:32                       │  now playing (1–3)
├───────────────────────────────┬────────────────────────────────┤
│  Orbital Bars                 │  Search · Results              │  content
│   ▂▄▆█▇▅▃▂   ▁▃▅▇█▆▄▂          │  > Station A   US  192k        │  (adaptive)
│                               │    Station B   JP  128k        │
├───────────────────────────────┴────────────────────────────────┤
│ ok · volume 70% · sleep 14:32            viz reactive · 15 fps  │  status (1)
│ j/k move  enter play  p pause  v viz  l layout  ? help  q quit │  footer (1)
└─────────────────────────────────────────────────────────────────┘
```

Ряды, сверху вниз:

1. **Header (1 строка)** — бренд `ORBITFM`, маркер `● live`/`○ idle`,
   версия TUI и ядра справа. Header никогда не скроллится и не скрывается.
2. **Now Playing (1–3 строки)** — компактная карточка текущей станции.
3. **Content** — зоны модулей по пресету компоновки (модуль 19 §6.7).
4. **Status (1 строка)** — слева последнее действие/ошибка, справа источник
   визуализатора и фактический FPS.
5. **Footer (1 строка)** — контекстные клавиши текущего фокуса.

Минимум — **60×18**. При меньшем размере рисуется центрированное сообщение
(`Terminal too small · 60×18 minimum`) без паники; при высоте сцены < 3
строк визуализатор скрывается, а не рисует мусор.

Адаптивность: `< 80` колонок — одна колонка, `pulse` вместо полного
визуализатора; `80–119` — две зоны; `≥ 120` — доступен `dashboard`.

## 4. Компоненты

Все компоненты — чистые функции `(area, state, tokens) -> frame`. Они не
ходят в core и не читают процессы.

### 4.1. Header

```
┌ ORBITFM ● live ─────────────────────── v0.1 · core 0.23 ┐
```

- `ORBITFM` — `BOLD` + `accent` (в `mono` — только `BOLD`);
- маркер: `● live` (`status.playing`) если эфир идёт, `○ idle`
  (`fg.muted`) иначе; при разрыве — `↻ reconnecting` (`status.reconnect`);
- правая часть — `v{tui} · core {core}`, `fg.muted`; при несовместимости —
  `! core schema` (`status.error`);
- в `focus`-пресете header схлопывается до одной строки над нижним блоком.

### 4.2. Now Playing

Одна строка (компактная) или три (широкая):

```
▶ Radio XYZ                          ★  128k · MP3 · DE
Orbital Bars · groove              ◷  14:32
──────────────────────────── volume ██████████████░░░░░░░  70%
```

- первая строка: состояние + имя станции (обрезается с `...`), справа
  фиксированные `bitrate · codec · country`;
- вторая — теги/жанр (dim) и остаток таймера сна;
- третья — полоса громкости (только широкая раскладка).

Пустое состояние — не ошибка: `Nothing playing · press / to search`,
`fg.muted`, центрировано в зоне.

### 4.3. Панель (Panel)

```
╭ Search · Results ─────────────────────────────╮
│ > Station A           US   192k   radio       │
│   Station B           JP   128k   radio       │
│   Station C           FR    96k   stream      │
╰────────────────────────────────────── 3/1245 ─╯
```

- рамка: `border` для нефокусных, `border.focus` для активной; в узком
  режиме рамка заменяется заголовком-строкой `▸ Search · Results`;
- заголовок: `accent` (фокус) или `fg.label`;
- справа в нижней рамке — позиция списка `3/1245` (dim);
- выбранная строка — полоса `▌` (`accent`) + `Modifier::REVERSED`;
- играющая строка — `▶` (`status.playing`) перед именем;
- избранная — `★` (`favorite`) в фиксированной правой колонке.

### 4.4. Строка станции

Единая для results/favorites/history:

```
▶ Radio XYZ              DE  128k  ★
  Radio XYZ — длинное имя, которое обрежется...
```

Ширина колонок: имя — резиновое (min 12, обрезка `...` по `unicode-width`),
страна — 2, bitrate — 4, source — 7, favorite — 1. Отсутствующее поле —
пробелы, не `null` и не `—`.

### 4.5. Громкость и gauges

- volume: `████████████░░░░░░░░` + ` 70%` фиксированной ширины 4;
- минимальный (узкий) вариант: `vol 70%` + 10-ячеечная шкала;
- precision: целые проценты; half-block ступени только в визуализаторе.

### 4.6. Status bar и toast

```
✓ volume 70%                                   viz reactive · 15 fps
! core not running                          viz procedural · 0 fps
```

- иконка `✓`/`!`/`...` + текст сообщения (`success` = `status.playing`,
  `error` = `status.error`);
- сообщение живёт 5 секунд, затем сменяется сводкой состояния; очереди
  тостов нет — последнее важнее;
- справа всегда: `viz {reactive|procedural|off} · {fps} fps` — честная
  маркировка источника (требование ADR-0047 §9.3).

### 4.7. Footer

Контекстные подсказки, `fg.label`, ключи — `BOLD`:

```
j/k move  enter play  p pause  v viz  l layout  ? help  q quit
```

В режиме ввода — подсказки ввода; в оверлее — только клавиши оверлея.

### 4.8. Оверлеи

Модальная поверхность всегда одна; подложка затемняется `Modifier::DIM`
(полноэкранная цветная заливка запрещена — ломает читаемость и плохо
переносится между терминалами).

```
╭ Quit OrbitFM? ───────────────────────╮
│ Stop playback and quit the core?      │
│                                       │
│   [y] yes, stop and quit   [n] cancel │
╰───────────────────────────────────────╯
```

- `QuitConfirm` — `danger` рамка, `y`/`n`;
- `SleepPrompt` — ввод минут `1..=720`, подсказка `enter apply · esc cancel`,
  ошибка диапазона — в строке статуса оверлея;
- `Modules` — чекбоксы `[x] now_playing`, пресеты `1..5`, `space`, `enter`,
  `esc`; текущий фокус — `▌`;
- `Help` — таблица клавиш, версия TUI и ядра, ограничения v1; `?`/`esc`.

### 4.9. Состояния данных

| Состояние | Вид |
|-----------|-----|
| подключение | центр зоны: спиннер + `Connecting to OrbitFM...` |
| нет ядра | `core not running` + `start orbitfm first` (`fg.muted`) |
| пустой список | `Nothing here yet` + подсказка действия, не ошибка |
| разрыв | баннер в status `↻ reconnecting in 4s` + последний снимок с пометкой `stale` |
| ошибка команды | `! {текст}` в status на 5 с; состояние экрана не меняется |
| несовместимость | баннер на весь content: `core schema 2 is newer than this TUI` |

Ни одно состояние не рисует пустой чёрный экран и не паникует.

## 5. Визуализаторы

Визуализатор — модуль, не экран. Полотно — ячейки, half blocks и Braille;
пиксельной графики нет. Визуализатор получает `&SpectrumFrame` или `None`
и никогда не ходит в core.

### 5.1. Общие правила

- сглаживание как в desktop: attack ≈ 28 мс, гравитация 1.8 ед/с, peak-hold
  падает 0.42 ед/с; `dt` ограничен 0.1 с;
- reactive → `Some(frame)`; procedural/idle → `None` и медленное «дыхание»;
- при `playing` без кадров > 2 с источник помечается `procedural`;
- буферы аллоцируются при создании и resize; кадр не выделяет память;
- высота сцены < 3 строк или ширина < 8 — модуль скрывается;
- цвет по вертикали зоны: `viz.low` → `viz.mid` → `viz.high`, а не по
  столбцу (иначе тихий эфир выглядит красным — правило из desktop
  `visual-spec.md` §3.3);
- `motion = off` — статичный читаемый кадр (последний уровень/«дыхание»).

### 5.2. Режимы

| id | Полотно | Композиция |
|----|---------|------------|
| `bars` (default) | half blocks, 8–64 столбца | вертикальные бары, peak-hold, зеркальный градиент зоны |
| `ring` | Braille | полярное кольцо: bass — радиус, mid — вращение, high — мерцание; в центре `▶` или код страны |
| `scope` | Braille 2×4 | осциллограмма/Lissajous: level — амплитуда, centroid — частота, flux — дрожание |
| `pulse` | block gauge, 1–3 строки | один орбитальный индикатор: точка на шкале level; fallback для узкого/`motion=off` |
| `stars` | Braille/точки | созвездие: 80–200 частиц, seed от UUID, flux — варп; T6 |
| `heat` | half blocks | спектрограмма в кольцевом буфере: X — время, Y — полосы/центроид; T6 |

`pulse` включается автоматически при `< 80` колонок или `motion = off`.

### 5.3. Терминальная эстетика

- Нет полноэкранных инверсий, вспышек > 3 Hz и «телевизионного снега».
- Акцент визуализатора — тепловая рампа; акцент интерфейса — отдельная ось.
- При `NO_COLOR` визуализатор остаётся выразительным за счёт глифов
  (плотность, высота, форма), а не цвета.
- В procedural-режиме запрещено выдавать анимацию за реальный спектр —
  статус пишет `viz procedural` (честность из ADR-0047 §9.3).

## 6. Движение и тайминги

| Условие | Тик |
|---------|-----|
| `motion=full`, визуализатор виден, эфир играет | 66 мс (≤ 15 FPS) |
| `motion=reduced` | 250 мс (4 FPS) |
| `motion=off`, эфир остановлен или визуализатор скрыт | 1 с / только по событию |
| ввод и кадры `state` | немедленная перерисовка, `dirty` |

Правила:

- перерисовка только при `dirty`; скрытый модуль не тикает и не подписан;
- анимации интерфейса — мгновенные (терминал не место для easing 200 мс);
  плавность живёт только в визуализаторе и в счётчиках;
- спиннер и пульс `●` — единственные циклические элементы; период пульса
  1.4 с, спиннер 10 кадров;
- `reduced` уменьшает частоту, но не меняет содержание кадра;
- `off` — ни одного таймера на анимацию: кадр собирается по событию.

## 7. Доступность и адаптация

### 7.1. Инварианты

- Смысл не передаётся только цветом: глиф + слово.
- `NO_COLOR` и `TERM=dumb` дают полностью читаемый кадр без цвета.
- `glyphs = "ascii"` — полный паритет по смыслу без Unicode.
- `motion = reduced|off` — снижение/отключение анимации без потери функций.
- Вспышки ≤ 3 Hz; полнокадровая инверсия запрещена.
- Минимум 60×18; меньше — сообщение и ожидание resize, без паники.
- Динамический заголовок терминала и OSC 8 hyperlinks не используются
  (интерфейс 16 §8).

### 7.2. Screen reader

Совместимость со screen reader ограничена природой TUI; паритет с
AccessKit desktop не обещается. Что делаем: линейный порядок чтения
(header → now playing → content → status → footer), короткие подписи,
явные слова состояний (`playing`, `stopped`), отсутствие смысла в цвете.

### 7.3. Клавиатура

Вся навигация доступна без мыши; мышь в v1 выключена. Фокус обходится
`Tab`/`Shift+Tab`; рамка фокуса — accent. Ввод поиска и оверлеи забирают
клавиши первыми (модуль 19 §7).

### 7.4. Автоопределение glyphs

Приоритет: `tui.toml` → `NO_COLOR`/`TERM=dumb` (ascii) → `LANG`/`LC_ALL`
(UTF-8 → unicode) → `ascii`. Явный `glyphs` в конфиге всегда важнее.

## 9. Токены ↔ код ↔ `tui.toml`

### 9.1. `tui.toml` (проект расширения)

К схеме модуля 19 §6.8 добавляются **три** поля отображения; `schema`
остаётся `1`, неизвестные поля игнорируются, невалидные зажимаются.

```toml
schema = 1

[ui]
layout = "desk"        # desk|focus|library|minimal|dashboard
motion = "full"        # full|reduced|off
glyphs = "auto"        # auto|unicode|ascii
border = "rounded"     # rounded|square|none
accent = "cyan"        # имя 16-цветовой палитры (совместимость)
theme = "orbit-dark"   # orbit-dark|ice|amber|green|magenta|mono
frame_fps = 15         # 1..=30
```

`accent` сохраняется для обратной совместимости, но при заданном `theme`
игнорируется (тема главнее). Расширение требует ревизии ADR-0047 и
интерфейса 16 — отдельная задача ADR-волны.

### 9.2. `src/ui/theme.rs` (эскиз API)

```rust
pub struct Theme {
    pub name: &'static str,
    pub accent: Style,
    pub border: Style,
    pub border_focus: Style,
    pub text: Style,
    pub muted: Style,
    pub label: Style,
    pub status: StatusPalette,   // playing/paused/stopped/...
    pub viz: [Color; 3],         // low/mid/high
    pub glyphs: Glyphs,          // набор символов
    pub color: bool,             // NO_COLOR / mono
}

impl Theme {
    pub fn from_config(ui: &UiConfig) -> Self;   // tui.toml + env
    pub fn status_style(&self, s: PlayState) -> Style;
}
```

UI-код не обращается к `Color::Cyan` напрямую — только через `Theme`.
Это делает `mono`, `NO_COLOR`, темы и ascii тривиальными и тестируемыми.

## 10. Что запрещено в дизайне

- Truecolor/RGB как обязательное условие; фон, перекрывающий терминал.
- Цвет как единственный носитель состояния.
- Полноэкранные инверсии, вспышки > 3 Hz, «шум» на весь экран.
- Анимация интерфейса с easing (терминал не рисует 60 FPS интерфейса).
- Дрожание соседних полей от тика (все числа — фиксированной ширины).
- Выдача procedural-анимации за реальный спектр.
- Паника при resize, пустом списке, `station: null`, малом терминале.
- Мышь, image protocol, favicon и OSC 8 в v1.
