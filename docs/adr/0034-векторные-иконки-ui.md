# ADR-0034: Векторные иконки UI и анимация наведения

**Статус:** Принято  
**Дата:** 2026-10-26  
**Участники решения:** ModernByte Architecture

## Контекст

Иконки OrbitFM были нарисованы вручную примитивами `Painter` (`src/ui/icons.rs`):
шестерня из восьми штрихов, полумесяц из триангулированной ленты, сердце из двух
кругов и треугольника. Набор был функциональным, но:

- разные иконки имели разную толщину штриха и оптический вес;
- мелкие глифы (20–24 px) читались хуже системных иконок окружения;
- рисование сложных форм вручную (полумесяц, кубик, сортировка) давало заметные
  глазу погрешности;
- hover-состояния включались скачком и различались от контрола к контролу.

Пользователь запросил «качественные SVG-иконки» и «современные hover-эффекты».
ADR-0016 отклонял `egui_extras` и `resvg` для **favicon**: там нужен растр из
сети, а SVG в выдаче Radio Browser почти нет. Ниже решение явно ограничено
**встроенными UI-иконками**; favicon-путь остаётся на `image` (ADR-0016,
ADR-0025).

Ограничения:

- Linux First, Wayland: иконки не должны зависеть от fontconfig и emoji-шрифтов;
- темы Dark/Light и акцент — цвет иконки задаёт палитра, а не файл;
- Reduce motion — мастер-выключатель (ADR-0032);
- горячий путь кадра не должен декодировать SVG повторно;
- никакой сети, SVG из внешних источников не загружается;
- качество на HiDPI: иконка должна быть резкой при любом `pixels_per_point`.

## Решение

1. **Набор — Lucide 0.544.0 (ISC).** Файлы лежат в `assets/icons/*.svg`, по одному
   на иконку: 24×24 `viewBox`, `fill="none"`, `stroke="#FFFFFF"`,
   `stroke-width="2"`, круглые концы и соединения. Лицензия — в
   `assets/icons/LICENSE`. Заливные варианты (`star-filled`, `heart-filled`,
   `play-filled`, `pause-filled`) отличаются только `fill="#FFFFFF"`.

2. **Цвет — через tint, а не через файл.** Белый штрих умножается на цвет палитры
   (`Image::tint`), поэтому одна и та же иконка работает в Dark, Light, акценте,
   disabled и error-состояниях. Перекраска не создаёт новую текстуру.

3. **Зависимость — `egui_extras` с единственной фичей `svg`.**
   `egui_extras = { version = "0.37", default-features = false, features = ["svg"] }`
   подключает `resvg`/`usvg` и загрузчик SVG. Фичи `http`, `file`, `image`,
   `gif`, `webp` выключены, поэтому загрузчик не умеет ни ходить в сеть, ни
   читать файлы: он обслуживает только `bytes://…` из `include_image!`.
   Рантайм-загрузчики ставятся один раз на `Context` в `OrbitApp::new`
   (`install_image_loaders`).

4. **Отрисовка — `Image::paint_at` в прямоугольник контрола.** Иконка не
   создаёт виджет, не аллоцирует место в раскладке и не показывается в
   AccessKit отдельно: подпись и роль остаются у кнопки. Загрузчик растеризует
   SVG ровно под физический размер прямоугольника (`pixels_per_point × size`),
   поэтому глиф резкий на HiDPI, а не масштабированный растр.

5. **Кэш и горячий путь.** `SvgLoader` кэширует результат по `(URI, SizeHint)`;
   размеры иконок — фиксированные константы (`GLYPH = 19`, знаки пустых
   состояний — 21–22), поэтому кадр попадает в кэш и не декодирует SVG повторно.
   Масштабирование SVG-глифа на hover/press **запрещено**: каждый промежуточный
   размер дал бы новую растеризацию. Геометрия контрола и hit-testing не меняются
   (ADR-0032 §7); анимируются только цвет, альфа подложки и обводки.

6. **Анимация наведения — единый помощник.** `icon_button` и другие контролы
   берут прогресс через `Context::animate_bool_with_time` по стабильному `Id`
   кнопки с длительностью `animation::HOVER` (120 мс). Подложка появляется
   fade-in, иконка подмешивает акцент, нажатие усиливает подложку. При
   `Style::animation_time == 0` (Reduce motion) помощник возвращает конечное
   значение сразу. Один и тот же ритм применяется к иконочным кнопкам,
   pill-кнопкам, чипам, полю поиска и сегментам вкладок; строки списка
   сохраняют собственный hover fade и press scale (ADR-0032 §4).

7. **Доступность.** SVG — декоративная часть кнопки: `WidgetInfo::labeled`
   с подсказкой ставится на `Response`, тултип и клавиатурный фокус не
   меняются. Знаки пустых состояний сопровождаются заголовком и подсказкой,
   поэтому не обязаны попадать в дерево AccessKit как отдельные изображения.

## Альтернативы

| Вариант | Причина отклонения |
|---------|--------------------|
| Оставить ручную отрисовку `Painter` | Разный оптический вес, погрешности форм, дорогая поддержка новых иконок |
| Иконочный шрифт (Nerd Font / Material) | Зависит от fontconfig, конфликтует с системными шрифтами и emoji, нет точного контроля штриха |
| PNG/SVG, растеризованные в билде | Нет перекраски под тему без набора файлов; PNG мылится на HiDPI |
| `resvg` напрямую без `egui_extras` | Дублирует загрузчик, кэш и lifecycle текстур — то же, за что ADR-0016 отклонил image-loader для favicon |
| `egui_extras` с `all_loaders` | Тянет HTTP/file/image/gif/webp и открывает пути загрузки, которые проекту не нужны |
| Сторонний crate иконок с готовыми shape-функциями | Ещё одна зависимость и свой формат; SVG-файлы проще ревьюить и заменять |

## Последствия

**Положительные:**

- единый оптический вес и современный вид иконок во всех режимах;
- перекраска под тему, акцент и disabled без дополнительных ассетов;
- резкость на HiDPI за счёт растеризации под фактический размер;
- hover-эффекты одинаковы у всех контролов и уважают Reduce motion;
- SVG-файлы читаемы, лицензия и версия зафиксированы в репозитории.

**Отрицательные / Риски:**

- в дереве появляется `resvg`/`usvg` (заметный объём кода) — приемлемо ради
  качества иконок; фичи загрузчиков ограничены;
- первая растеризация иконки происходит в кадре её первого показа; набор
  маленький и кэшируется, но холодный старт получает несколько лишних
  миллисекунд;
- SVG-файлы — доверенные ассеты репозитория; загрузка SVG из сети или favicon
  по-прежнему запрещена (ADR-0016, ADR-0025);
- добавление иконки требует скачать файл Lucide, а не нарисовать форму в коде.
