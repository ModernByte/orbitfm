# ADR-0058: Экран предупреждения таймера сна

**Статус:** Принято  
**Дата:** 2026-11-06  
**Участники решения:** ModernByte Architecture, владелец продукта

## Контекст

За минуту до действия таймера сна пользователь должен увидеть красивое
центрированное окно предупреждения: обратный отсчёт, убывающий круговой
прогресс-бар и рампа «зелёный → жёлтый → красный». «Отменить» в окне
отменяет **только действие**, а не таймер: эфир останавливается по дедлайну,
машина не спит/не выключается. Это решение владельца.

Окно должно работать в двух состояниях:

- стол открыт — предупреждение можно показать потомком;
- процесс припаркован — UI-пасса нет, нужен отдельный прогон.

## Решение

### 1. Одна функция на оба носителя

`src/ui/sleep_warning.rs::show(...) -> Vec<WarningAction>`.

- Размер 420×320, `decorations(false)`, `transparent(true)`, стекло по всему
  rect (helper `widgets::alert_surface`, куда переезжает цикл теней).
- Кольцо — сегментная полилиния: arc-API в egui 0.37 нет; прецедент
  `orbit_ring.rs`. `SEGMENTS = 96`.
- В центре — отсчёт ~48 px, ниже — кнопка «Отменить» и строка действия
  («Остановить эфир», «Остановить эфир и усыпить», «Остановить эфир и
  выключить»).
- Рампа `warning_color(p)` на существующем `mix_colors`: `p ≥ 0,5` →
  жёлтый→зелёный, иначе красный→жёлтый. На концах — чистые цвета, в середине
  — смесь.

### 2. Носители

| Состояние | Носитель |
|-----------|----------|
| стол открыт | immediate-потомок от стола |
| открыто окно настроек | immediate-потомок от окна настроек (TLS-рендер регистрируется на каждый `run_native`) |
| процесс припаркован | `ParkOutcome::Warn` + отдельный `run_native` той же `Session` |

Несколько прогонов `run_native` легальны (ADR-0018/0021); правило «не более
одного GUI-процесса» соблюдено — процесс один. Показ ровно один на таймер:
флаг `warning_shown`; сбрасывается в `set`/`clear`.

### 3. Семантика отмены

- Cancel ⇒ `sleep_action_once = Nothing` + `warning_shown = true`:
  **действие** отменяется, таймер досчитывает, громкость возвращается через
  `CancelFade { restore_volume }`.
- Esc и `close_requested` потомка = Cancel (безопасная трактовка).
- Отдельной кнопки «выключить сейчас» нет.

### 4. Интеграция

- `warning_start` = `deadline − warning_lead` (60 с), входит в `next_event`.
- `poll_sleep_events` при достижении `warning_start` и `sleep_warning = true`
  ставит флаг и выбирает носитель.
- После истечения окно закрывается до выполнения действия (ADR-0055).
- Правило WM: `size 420 320,title:^OrbitFM · Sleep Warning$` (ADR-0051,
  ADR-0053).

## Последствия

**Положительные:**

- у пользователя есть минута, чтобы отменить сон/выключение;
- одинаковый вид на всех носителях;
- отмена не ломает таймер и не оставляет звук на прежней громкости.

**Отрицательные / риски:**

- отдельный прогон в парковке — ещё один `run_native`; окно предупреждения
  должно быть закрыто до `Suspend`, иначе WM может не успеть;
- прозрачное окно без рамки на некоторых композиторах получает SSD-скругления
  — live-проверка;
- рампа и кольцо рисуются каждый кадр: 96 сегментов дёшевы, но в последнюю
  минуту кадров больше.

## Альтернативы

| Вариант | Причина отклонения |
|---------|--------------------|
| Системное уведомление | нет отсчёта и кнопки отмены в нужном виде |
| Только тост | не «красивое центрированное окно» |
| Всегда отдельный прогон | лишний запуск, когда стол уже открыт |
| Отмена = сброс таймера | решение владельца: отменяется только действие |
| Кнопка «выключить сейчас» | лишний риск и scope |

## Уточнение (2026-11-10): app-id окна предупреждения

Правило `size 420 320,title:^OrbitFM · Sleep Warning$` из §4 работает только
вместе с app-id: niri матчит пару «класс + заголовок», а Wayland не наследует
app-id от родителя — без явного `with_app_id` потомок получает `app_id = null`
(разбор и источник — ADR-0053, «Уточнение (2026-11-10)»). Билдер
`warning_viewport_builder()` в `src/app.rs` теперь несёт
`with_app_id(crate::APP_ID)`; у корневого носителя `RootSurface::Warning`
app-id ставит `main.rs::run_window` при любом раскладе.

Измерено под niri 26.04: окно предупреждения —
`app_id="org.modernbyte.OrbitFM"`, floating, 420×320. Тест
`child_viewports_carry_app_id_and_titles_for_window_rules` держит контракт
(заголовок, размер 420×320, минимум 360×280, без рамки, прозрачность, app-id).
