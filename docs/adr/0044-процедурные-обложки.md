# ADR-0044: Процедурные обложки вместо серых квадратов

**Статус:** Принято  
**Дата:** 2026-11-01  
**Участники решения:** ModernByte Architecture, Юрий Анатольевич

## Контекст

Когда favicon станции отсутствует, не проходит политику ADR-0025, не
декодируется или сеть недоступна, `FaviconCache` возвращает `None`, а UI рисует
серый квадрат с инициалами. В офлайн-режиме это выглядит мёртво: глобус и
список живы, а обложки — нет.

Задача — генерировать абстрактную обложку на лету из метаданных станции, чтобы
интерфейс оставался «живым» без сети. Требования:

- вход: жанр/теги, цвета страны, спектр/RMS для пульсации;
- никаких новых сетевых путей и ослабления allowlist;
- генерация должна быть дешевле, чем TCP + JPEG-декод;
- не ломать существующие счётчики favicon-кэша и инварианты ADR-0016/0025;
- работать на слабой GPU (Intel UHD).

## Решение

### 1. Где живёт генерация

`src/ui/procedural.rs` — детерминированный генератор `ColorImage` 64×64 по
`Station`. Он не ходит в сеть, не читает файлы, не знает про `Session`.
Вызов — из `FaviconCache::texture_or_procedural(station)`: при отсутствии
готовой текстуры URL создаётся процедурная и кладётся в тот же кэш как
`Ready`, с ключом `procedural:<uuid>`. Это сохраняет потолок 256 записей,
LRU-вытеснение и счётчики; сетевой favicon при появлении позже заменит запись
только при явном `retry_failed`/новом кадре, как и раньше.

### 2. Входные данные и палитра

Детерминированный хеш FNV-1a от `stationuuid` задаёт:

- угол и частоту двух градиентов;
- фазу и число «орбит»/зерен;
- сдвиг палитры.

Палитра строится из:

1. акцентного цвета темы (база);
2. цвета страны — таблица ISO→RGB не вводится; берутся уже существующие
   цвета маркеров/флагов через `flag_emoji`-палитру или акцент, чтобы не
   выдумывать данные;
3. жанровых ключевых слов (`jazz`, `classical`, `electronic`, `rock`, `news`,
   `ambient`, `pop`, `folk`) — небольшой фиксированный набор оттенков;
4. `votes` — насыщенность, `bitrate` — контраст.

Никаких внешних данных и случайных чисел: одинаковый UUID всегда даёт одну
картинку, кэш и скриншоты воспроизводимы.

### 3. Пульсация

Пульсация не перерисовывает текстуру каждый кадр. В UI поверх обложки
рисуется полупрозрачное кольцо/свечение, яркость которого зависит от
`SpectrumFrame::rms_db` и уже существующего сглаживания визуализатора. Это
дёшево, не требует обновления GPU-текстуры и уважает Reduce motion: при
выключенном движении кольцо статично.

### 4. Почему не отдельный wgpu-пайплайн

Обложка в текущем UI — 64×64 px (favicon-слот строки, transport и капсулы).
Генерация 4096 пикселей на CPU при первом показе дешевле, чем создание
отдельного render pass, uniform-буфера, bind group и синхронизации на каждый
прямоугольник; на Intel UHD лишний пайплайн заметнее, чем 16 КБ вычислений.
Профиль задачи — «дешевле TCP + JPEG», а не «любой ценой GPU»: CPU-вариант
выполняет это с большим запасом. Если появится крупная обложка Now Playing,
решение пересматривается отдельным ADR с замером.

### 5. Границы

- процедурная обложка не публикуется в MPRIS/SMTC: там действует `PublishGate`
  и реальный `art_url`; выдуманный URL нарушил бы ADR-0025;
- генератор не пишет файлы и не читает окружение;
- ошибка/паника генератора не должна ломать кадр: `catch_unwind` в App, как у
  декодера favicon;
- Reduce motion и `motion = Off` отключают пульсацию, но не картинку.

## Альтернативы

| Вариант | Причина отклонения |
|---------|--------------------|
| Оставить серый квадрат | Не выполняет UX-цель «живой офлайн» |
| Скачивать заглушку | Новый сетевой путь; в офлайне недоступен |
| Полноценный wgpu-шейдер на каждую строку | Дороже по состоянию и пайплайнам при 64 px; риск на Intel UHD |
| Случайные картинки без метаданных | Невоспроизводимо, кэш и тесты теряют смысл |
| Генерировать SVG | Нужен растеризатор; существующий image-граф не принимает SVG (ADR-0025) |

## Последствия

**Положительные:**

- ни одна станция больше не выглядит «сломанной» из-за отсутствия favicon;
- ноль новых сетевых запросов и зависимостей;
- детерминированная картинка тестируется без GPU;
- кэш и его инварианты не меняются.

**Отрицательные / Риски:**

- палитра субъективна; жанровый словарь ограничен и не претендует на полноту;
- процедурная обложка не отражает реальный логотип станции;
- при появлении крупных обложек архитектуру генерации придётся пересмотреть;
- пульсация требует уже включённого спектра, иначе кольцо статично.
