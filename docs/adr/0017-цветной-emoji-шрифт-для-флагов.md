# ADR-0017: Цветной emoji-шрифт для флагов стран

**Статус:** Принято  
**Дата:** 2026-10-23  
**Участники решения:** ModernByte Architecture, Юрий Анатольевич  

## Контекст

Референс-макет `docs/ui/OrbitFM_ Радио Земли в неоне.png` показывает флаг страны
(`🇬🇧 United Kingdom / 128 stations`) в тултипе наведения на глобус. План фазы 6
обещал флаг-эмодзи через `flag_emoji` (ISO alpha-2 → региональные индикаторы,
`src/ui/widgets.rs`). Функция корректно возвращает пару codepoint U+1F1E6…,
но egui рисовал их как tofu-квадраты: в бандле шрифтов epaint (`default_fonts`)
нет глифов региональных индикаторов.

Факты на момент решения:

- `epaint` 0.37 рендерит цветные глифы (COLR/CPAL и битмап-страйки CBDT/CBLC)
  только под feature `color_fonts` (`epaint/src/text/font_face.rs`, путь
  `rasterize_color_glyph`, `GlyphBitmap::is_color`);
- egui 0.37 **не прокидывает** `color_fonts` как свою feature — включить её
  через `eframe`/`egui` невозможно;
- `vello_cpu`, `skrifa`, `peniko`, `glifo` уже присутствуют в `Cargo.lock` и
  компилируются (эпайнтовские зависимости), новых crate'ов в граф не добавляется;
- система предоставляет `/usr/share/fonts/noto/NotoColorEmoji.ttf` (битмап-флаги);
- UI-модули не читают файловую систему (ADR-0015, п. 1) — чтение шрифта относится
  к App-оркестратору.

## Решение

1. **Включить `color_fonts` через прямую зависимость от `epaint`.**
   В `Cargo.toml` добавлен `epaint = { version = "0.37", features = ["color_fonts"] }`.
   Feature-unification Cargo включает `color_fonts` для единственного собранного
   `epaint`, который используют `egui`/`eframe`. Это стандартный идио́м проброса
   транзитивной feature, которую верхний crate не экспортирует. Новых crate'ов
   не появляется — только подфичи `vello_cpu/png` и `vello_cpu/text` у уже
   присутствующих пакетов.

2. **Регистрация шрифта — в `OrbitApp::new` (`src/app.rs`).**
   Функция `install_emoji_font` перебирает несколько стандартных путей к
   `NotoColorEmoji.ttf`, читает первый существующий и вызывает
   `Context::add_font` с `FontInsert` в семейство `Proportional` с приоритетом
   `Lowest` (только как запас — основные текстовые глифы берутся из `Ubuntu-Light`).
   Чтение файла — побочный эффект, поэтому живёт в App, а не в UI-модулях.

3. **Деградация без шрифта.** Если ни один путь не найден, функция пишет
   `debug!` и молча возвращается: UI работает как раньше, просто без глифов-флагов.
   Приложение не падает и не требует конкретного дистрибутивного пакета.

4. **Флаг остаётся только в тултипе глобуса** (`src/ui/globe_view.rs`), как в
   макете. Контекстная строка drawer'а панели — текстовая «Country: …» без эмодзи,
   чтобы постоянный (не наведение) элемент не зависел от наличия emoji-шрифта.

## Альтернативы

| Вариант | Причина отклонения |
|---------|--------------------|
| Бандлить `NotoColorEmoji.ttf` в репозиторий | ~10+ MiB бинарник в git ради одного тултипа; лицензия/размер неоправданны |
| `monochrome_emoji_fonts` (бандл epaint) | Монохромные «флаги» — контурные прямоугольники без узнаваемых расцветок, ниже соответствие макету |
| Рисовать флаги векторно по ISO | Нужна таблица раскладок/цветов на ~200 стран — объём данных и риск ошибочных флагов («не выдумывать») |
| Бейдж с кодом ISO («GB») вместо флага | Отход от макета, где явно цветной флаг |
| Ждать/требовать `egui/color_fonts` passthrough | egui 0.37 такой feature не экспортирует; блокирует задачу на неопределённый срок |

## Последствия

**Положительные:**

- тултип глобуса достигает макета: цветной флаг + название + число станций;
- ни одного нового crate'а в графе зависимостей;
- чистая деградация при отсутствии шрифта;
- флаги не tint'ятся цветом текста (`is_color` в epaint), цвет корректный.

**Отрицательные / Риски:**

- `color_fonts` — относительно свежий путь epaint; CPU-растеризация цветных
  глифов идёт через `vello_cpu`. Обычные глифы этим путём не проходят, регресса
  текста не наблюдается (проверено live-скриншотом);
- прямая зависимость от `epaint` — согласованность версий с `egui`/`eframe`
  ложится на SemVer-диапазон `0.37`; при мажорном апгрейде GUI-стека запись
  нужно пересмотреть (возможно, egui добавит собственный passthrough);
- привязка к системному шрифту: на машине без Noto Color Emoji флаги не появятся
  (приложение продолжит работать).

## Ревизии

- 2026-11-01: ADR-0041 добавляет встроенный сабсет региональных индикаторов
  (`NotoColorEmoji-flags-subset.ttf`). Системный полный Noto Color Emoji
  остаётся предпочтительным и подключается раньше, но флаги больше не зависят
  от наличия пакета в системе.
