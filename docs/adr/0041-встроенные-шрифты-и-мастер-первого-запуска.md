# ADR-0041: Встроенные fallback-шрифты и мастер первого запуска

**Статус:** Принято  
**Дата:** 2026-11-01  
**Участники решения:** ModernByte Architecture, Юрий Анатольевич

## Контекст

Чистая система без пакетов `noto-fonts-cjk`, `noto-fonts-arabic` и
`noto-fonts-emoji` показывает в интерфейсе tofu: иероглифы, арабскую вязь и
флаги стран. ADR-0030 §7 сознательно оставлял CJK системным шрифтам, а
ADR-0017 — флаги системному Noto Color Emoji. Это допустимо для машины
разработчика, но противоречит цели «читаемый интерфейс сразу после установки»:
пользователь AppImage/Flatpak не обязан доустанавливать шрифты вручную.

Одновременно первый запуск требует ручной правки конфигурации композитора:
окно OrbitFM должно быть плавающим, без рамки и тени, а правила живут в
`hyprland.conf` или `config.kdl`. Установщик интеграций (ADR-0037) намеренно не
редактирует чужие конфиги, поэтому новичок видит только сниппет в документации.

Ограничения:

- бюджет бинарника — **+3–6 МиБ**, шрифты не должны превращаться в «ещё один
  AppImage»;
- `epaint` 0.37 не умеет bidi-раскладку: иврит/арабский шейпятся, но строки не
  зеркалятся автоматически;
- Application Core не знает про egui, а UI-модули не читают файловую систему
  (ADR-0015, п. 1);
- настройки создаются только при первом изменении; отсутствие
  `~/.config/orbitfm/settings.json` — единственный надёжный признак первого
  запуска;
- правило «не редактировать чужие конфиги» и запрет `killall`/`pkill`
  (ADR-0037) остаются в силе.

## Решение

### 1. Встроенный набор шрифтов

В `assets/fonts/` лежат четыре файла, лицензия SIL OFL 1.1 и README с точными
командами `pyftsubset`:

| Файл | Содержимое | Размер |
|------|------------|--------|
| `NotoSans-Regular.ttf` | латиница, кириллица, греческий, пунктуация | ~0,6 МиБ |
| `NotoSansArabic-Regular.ttf` | арабская вязь с формами | ~0,2 МиБ |
| `NotoSansCJK-Regular-subset.otf` | все CJK-символы каталога UI, пунктуация U+3000–303F, кана, хангыль | ~1,8 МиБ |
| `NotoColorEmoji-flags-subset.ttf` | только региональные индикаторы U+1F1E6–1F1FF | ~0,8 МиБ |

Итого около **3,5 МиБ** — внутри бюджета. Полный CJK-шрифт (5,9–11 МиБ) не
бандлится: произвольные названия станций за пределами подмножества остаются
зависимостью системы. Все строки интерфейса покрыты встроенным набором, кроме
хинди: деванагари остаётся системным шрифтом (Noto Sans Devanagari), как и
раньше. Тест `fonts::tests` фиксирует сумму `include_bytes!` ≤ 6 МиБ и
сигнатуры всех четырёх файлов.

### 2. Регистрация — `src/ui/fonts.rs`

App-оркестратор вызывает `fonts::install(ctx)` один раз при создании окна:

1. `FontData::from_static(include_bytes!(...))` — zero-copy, файлы уже в
   бинарнике;
2. каждый шрифт добавляется в `Proportional` и `Monospace` с
   `FontPriority::Lowest`: он никогда не подменяет основной `Ubuntu-Light` и
   подхватывается только при отсутствии глифа;
3. системный `NotoColorEmoji.ttf` (если есть) ставится **раньше** встроенного
   набора: полный emoji предпочтительнее, а встроенные флаги остаются
   гарантией;
4. отсутствие системного шрифта больше не логируется как деградация —
   встроенный набор уже установлен.

Чтение файлов остаётся в App-слое; `ui/fonts.rs` получает `Context` и не знает
ни про настройки, ни про Session.

### 3. Мастер первого запуска

Признак первого запуска: `SettingsStore::existed_at_load() == false` и
`settings.onboarding_done == false`. Существующий `settings.json` без нового
поля мастера не показывает — миграция не беспокоит действующих пользователей.

Мастер — отдельное модальное окно presentation-слоя (не страница настроек), три
шага:

1. **Язык и тема.** Тот же перечень 17 языков и три темы, что в настройках;
   выбор применяется сразу, без перезапуска.
2. **Окружение и окно.** `integration::wm::detect()` читает
   `HYPRLAND_INSTANCE_SIGNATURE`, `NIRI_SOCKET`, `XDG_CURRENT_DESKTOP` и
   `DESKTOP_SESSION`. Для Hyprland кнопка «Настроить окно» выполняет
   `hyprctl keyword windowrulev2 …` с фиксированными аргументами (без shell) —
   правила действуют до перезагрузки композитора, файлы пользователя не
   меняются. Для niri runtime-правил в IPC нет: показывается готовый KDL-блок
   из `wm-configs/orbitfm-niri.kdl` и кнопка «Копировать». KDE/GNOME и прочие
   получают нейтральную подсказку и кнопку перехода в настройки.
3. **Интеграции.** Кнопка открывает модальное окно настроек на категории
   «Интеграции» (ADR-0042); отметка о завершении мастера сохраняется отдельно,
   поэтому отказ от интеграций не блокирует выход.

Мастер локализован; при арабском языке содержимое шагов рисуется
`Layout::right_to_left` — epaint по-прежнему не зеркалит вложенный текст, но
сама компоновка перестаёт быть жёстко левой. Это ограничение фиксируется в
интерфейсе 12 и остаётся единственным RTL-компромиссом.

### 4. Персистентность и безопасность

- `Settings` получает `onboarding_done: bool` (`#[serde(default)]`), запись —
  тем же атомарным durable путём (ADR-0031, ред. 2).
- Завершение мастера не требует изменения темы/языка: достаточно нажать
  «Готово».
- Мастер не редактирует файлы композитора, не запускает оболочку и не
  перезапускает процессы. Для Hyprland используется только документированный
  `hyprctl keyword`; при ошибке IPC показывается сниппет, а не «попробуйте ещё
  раз с sudo».
- Сниппет niri копируется через `Context::copy_text`; в буфер попадает только
  статический текст правила, без путей и секретов.

## Альтернативы

| Вариант | Причина отклонения |
|---------|--------------------|
| Полный Noto CJK + полный Noto Color Emoji | +15–25 МиБ: выходит за бюджет и раздувает AppImage/Flatpak |
| Только системные шрифты (статус-кво) | Не выполняет критерий «читаемо на чистой системе» |
| Автоправка `hyprland.conf` и `config.kdl` | Нарушает ADR-0037 и риск потери пользовательских комментариев |
| `killall`/`pkill` для перезапуска оболочки | Запрещено в пользовательском пути; заменяется IPC/сигналом |
| Полная bidi-раскладка через новый crate | Вне бюджета задачи; epaint 0.37 не предоставляет hook, а обходной слой затронул бы весь UI |

## Последствия

**Положительные:**

- интерфейс читается на минимальной системе без доустановки шрифтов;
- первый запуск на Hyprland/niri даёт рабочие правила окна без правки файлов;
- мастер можно пропустить, а решение фиксируется один раз;
- фиксированный бюджет шрифтов проверяется тестом, а не обещанием.

**Отрицательные / Риски:**

- хинди по-прежнему требует системного шрифта с деванагари — это единственный
  язык каталога, не покрытый встроенным набором;
- произвольные CJK-названия станций вне сабсета по-прежнему требуют системного
  шрифта;
- Hyprland-правила живут до перезапуска композитора; постоянная установка
  остаётся в `wm-configs/`;
- RTL-текст шейпится, но не зеркалится epaint'ом;
- каждое новое поле каталога требует перевода на 17 языков.

## Ревизии

- 2026-11-01: решение принято. Пересматривает ADR-0030 §7 в части «CJK — только
  системные шрифты» и ADR-0017 в части «флаги только из системы»: системный
  шрифт остаётся предпочтительным, встроенный — гарантией.
