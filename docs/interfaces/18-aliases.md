# Интерфейс: алиасы URL станций

**Организация:** ModernByte  
**Дата:** 2026-11-03  
**Статус:** Контракт (ADR-0050)

Локальная подмена адреса эфира для конкретной станции каталога: станция
остаётся собой (тот же `stationuuid`, имя, страна, теги, избранное, история,
минуты), а играет по адресу, который указал пользователь.

## 1. Назначение и границы

- починить станцию с мёртвым `url_resolved`, не создавая дубль через
  `play-url` (ADR-0040);
- не менять каталожные данные и не портить экспортируемую библиотеку
  (интерфейс 15, схема 1);
- не ослаблять политику публичных URL (ADR-0025): алиас проверяется строже,
  чем импорт внешнего потока;
- не давать веб-странице ни читать, ни ставить алиасы (ADR-0038).

Алиас — данные пользователя, а не свойство каталога: на поиск, фильтры,
отбор кандидатов рулетки и `ECO` он не влияет.

## 2. Хранение

Поле `aliases` в `$XDG_DATA_HOME/orbitfm/library.json` (интерфейс 08).
Схема файла не меняется: отсутствие поля читается как пустой список,
старые файлы не требуют миграции и не переписываются, пока алиас не
поставлен. Запись атомарная и с правами `0600` — тот же цикл, что у
избранного и истории.

```json
{
  "favorites": [],
  "history": [],
  "aliases": [
    {
      "stationuuid": "c685c086-b716-4edd-b313-d4a7baf1084c",
      "url": "https://stream.example.org/swisspop.aac",
      "label": "stream.example.org",
      "added_at": 1762156800
    }
  ]
}
```

| Поле | Правило |
|------|---------|
| `stationuuid` | ключ; одна запись на станцию, повторная постановка заменяет |
| `url` | как ввёл пользователь; схемы `http`/`https`; до `ALIAS_URL_LIMIT = 2048` байт |
| `label` | хост из `url`, вычисляется при записи; его показывают CLI и UI |
| `added_at` | Unix-время постановки, только для порядка и отладки |

`ALIAS_LIMIT = 200` записей. Переполнение — ошибка записи, вытеснения нет:
молча потерять алиас хуже, чем отказать. Алиас станции, которой нет ни в
избранном, ни в истории, ни в текущей выдаче, не удаляется.

## 3. Применение

Единственная точка — `StationLibrary::launch_url` (`src/library/mod.rs`);
`Session::start_station` (`src/session/playback.rs`) только зовёт её:

1. адрес запуска = алиас по `stationuuid`, если он есть, иначе
   `station.url_resolved`;
2. выбранный адрес проходит ярус 1 (`services/ssrf.rs`) до `audio.play`;
3. дальше — обычный путь: история, `note_stats_start`, клик-трекинг,
   метаданные.

`Station` не переписывается ни в одном месте: подмена существует только в
момент запуска. Все поверхности (списки панели и поиска, HUD, капсулы,
очередь, рулетка, `play <uuid>`, MPRIS, попап, GNOME, бар-модули) получают её
автоматически, потому что идут через `start_station`.

## 4. Проверки и приватность

- Алиас обязан пройти `parse_publishable` / `is_public_destination` (ярус 1)
  так же, как каталожный адрес. Приватные, loopback, link-local,
  многоадресные и несхемные адреса отклоняются и при записи, и при запуске.
- Ярус 2 (`artwork::public_verdict`) и гейт публикации метаданных
  (`session/publish_gate.rs`) получают адрес запуска, а не каталожный.
- `artwork_allow_http` на алиас не влияет: это политика обложек.
- `alias` запрещён браузерному native host (ADR-0038) целиком — и постановка,
  и чтение.
- В `status`, `status --json` (схема 1) и `events` алиасы не попадают: адрес
  эфира в статусе не появляется вообще.

## 5. Команды

| Команда | Ответ |
|---------|-------|
| `alias <stationuuid>` | `alias <stationuuid> <url>` или `alias none` |
| `alias <stationuuid> <url>` | `ok alias <хост>` — поставить или заменить |
| `alias <stationuuid> remove` | `ok alias removed` |
| `alias list` | по строке `alias <stationuuid> <url>` на запись; `alias none`, если пусто |

- `list` и `remove` — служебные слова на своей позиции, `stationuuid` — UUID.
- Невалидный адрес: `error <причина>` без изменения файла; причина — текст
  яруса 1 (приватный адрес, неизвестная схема, слишком длинный).
- Команды обслуживает живой экземпляр, как `stats` и `sleep`: сами GUI не
  поднимают, без запущенного процесса — `OrbitFM не запущен` и код 1.

## 6. Смежные подсистемы

| Подсистема | Поведение со включённым алиасом |
|---|---|
| Статистика (ADR-0049, интерфейс 17) | ключ остаётся `stationuuid`, минуты не разъезжаются |
| Экспорт/импорт (ADR-0046, интерфейс 15) | алиасы не экспортируются и не импортируются; в файл уезжает каталожный `url_resolved` |
| Клик-трекинг (ADR-0004) | отправляется по `stationuuid`, как для обычной станции |
| `ECO` (ADR-0043) | подмена не ищется: она меняет `stationuuid` и выбрасывает адрес пользователя; `ECO`-индикатор не показывается |
| Реконнект (ADR-0003) | работает по адресу запуска; при его гибели — обычная ошибка, каталог обратно не подставляется |
| Методы запуска | `next`/`previous`, рулетка, `play-library`, попап — тот же `start_station` |

## 7. Пометка в интерфейсе

Строка станции с алиасом получает подпись «ручная ссылка» и `label` — тем же
механизмом, что бейдж избранного (`src/ui/station_row.rs`). Полный `url` в UI
не показывается. Редактора алиасов в окне настроек нет: постановка — через
CLI, как экспорт и импорт библиотеки.

## 8. Тесты контракта

- `alias_roundtrip_sets_replaces_and_removes` — постановка, замена, снятие,
  `library.json` без поля читается пустым списком и не переписывается;
- `alias_rejects_private_and_oversized_urls` — ярус 1 отклоняет приватные,
  loopback, несхемные и длинные адреса, файл не меняется;
- `alias_url_is_used_at_start` — `start_station` берёт адрес алиаса, а
  каталожный `url_resolved` остаётся в станции;
- `alias_key_keeps_stats_and_history` — статистика и история продолжают
  считаться по `stationuuid`;
- `eco_skips_station_with_alias` — экономная подмена не ищется для
  алиасной станции;
- `alias_commands_parse_and_answer` — разбор `alias`, `alias <uuid> <url>`,
  `alias <uuid> remove`, `alias list`, отказ неизвестным аргументам;
- `native_host_forbids_alias` — команда запрещена браузерному хосту.
