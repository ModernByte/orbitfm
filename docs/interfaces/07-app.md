# Интерфейс: Application Core

Application Core не экспортирует публичный трейт для других crate’ов — он является точкой сборки.

Тем не менее, фиксируем контракт поведения:

## Обязанности

1. Инициализировать все подсистемы в корректном порядке.
2. Реализовывать `eframe::App`.
3. Маршрутизировать `IpcCommand` и `MediaCommand` в соответствующие модули.
4. Управлять видимостью окна (show/hide, а не destroy).
5. При клике по глобусу в режиме «Страна»:
   - при попадании в маркер станции (радиус 10 px) запустить представителя группы;
   - иначе получить точку на сфере от `GlobeCamera::screen_to_sphere`
   - спросить страну у `GeoService::country_at_sphere_point`
   - мягко довернуть камеру к центру страны (`country_shape().focus_point()`)
   - запросить станции страны через `RadioBrowserClient` с фильтром `countrycode`
   - обновить UI (заголовок страны, результаты, пустое состояние)

   В режиме «Глобальный жанр» клик по стране не меняет контекст (no-op); маркеры
   станций остаются кликабельными.
6. Для каждого поиска параллельно запрашивать гео-станции (`has_geo_info=true`)
   и строить маркеры; лимиты: название/страна — 100 на список и 100 на маркеры,
   жанр — 200 на список и 200 на маркеры; ошибка гео-запроса не влияет на список.
7. Для выбранной страны или жанра хранить локальное состояние фильтров (`text`,
   `genre`, `sort`) и применять его к результатам без сетевых запросов; повторный
   запуск поиска при активном контексте фильтрует уже загруженный список.
8. Хранить избранное и историю через `StationLibrary`: записывать станцию в историю
   при успешном запуске и переключать избранное по действию пользователя.
9. Хранить тему и акцент через `SettingsStore`: применять их к egui при старте и
   сохранять при изменении пользователем.
10. Обслуживать Roulette: запросить случайную станцию с координатами, запустить её,
    довернуть камеру и показать тост; отдельной IPC-команды нет.

## Порядок инициализации

Текущий (Этап 8, фазы 1–4):

```
1. IpcServer::try_bind()          — ошибка AlreadyRunning → повторная отправка команды
2. AudioEngine::new()             — ошибка фатальна для запуска
3. GeoService::from_embedded()    — ошибка фатальна: без границ стран нет поиска
4. MediaControls::new(wake)       — ошибка логируется, приложение работает без MPRIS
5. RadioBrowserClient::new()      — без сетевых обращений
6. StationLibrary::load_default() — ошибка логируется, используется ephemeral()
7. SettingsStore::load_default()  — ошибка логируется, используется ephemeral()
8. фоновая задача refresh_servers — прогрев пула; ошибка только логируется
9. фоновая задача: audio events → wake()
10. IpcServer::run(wake, shutdown) — accept-loop
11. eframe::run_native + OrbitApp — GUI, после закрытия которого сервер
                                    останавливается и сокет удаляется
12. OrbitApp::new                 — применяет тему и акцент к egui, создаёт
                                    GlobeRenderer из wgpu_render_state
                                    и кладёт его в callback_resources
```

`GeoService` создаётся до `MediaControls`, чтобы ошибка датасета проявилась раньше
инициализации D-Bus. Если `wgpu_render_state` недоступен, приложение продолжает
работать без 3D-глобуса (`globe_ready = false`).

## Реакция на команды

| Команда       | Действие |
|---------------|----------|
| Toggle/Show/Hide | Изменение `window_visible` + ViewportCommand |
| Play          | Поиск станции в результатах последнего поиска, затем `radio.get_station` (таймаут 8 с); `audio.play(url_resolved)`, запись в историю, асинхронный `radio.send_click`, обновление media |
| Stop          | `audio.stop()`; последний URL и станция сохраняются для повторного запуска из MPRIS |
| Volume        | `audio.set_volume(level)`, обновление media |
| Status        | `status <state>`, при активной станции `stationuuid`/`name`, затем `volume <0.00>` и `window visible\|hidden` |
| Quit          | Корректное завершение всех подсистем и выход |

`MediaCommand` обрабатывается в том же цикле:

| Команда | Действие |
|---------|----------|
| Play | снять паузу; если поток остановлен — повторно запустить последний URL |
| Pause | поставить на паузу |
| PlayPause | переключить в зависимости от `PlaybackState` |
| Stop | `audio.stop()` |
| SetVolume | `audio.set_volume()` |
| Next/Previous | не действуют: переключение станций вне текущего объёма |

Аудио-вызовы из синхронного `logic()` выполняются через
`tokio::runtime::Handle::block_on`; сами операции короткие (ответ аудио-потока с
таймаутом 3 с). Поиск станций выполняется асинхронно: результат приходит в
`mpsc`-канал, `WakeFn` будит GUI.

Ответ клиенту формируется после обновления состояния App и отправки `ViewportCommand`;
применение команды оконным менеджером асинхронно и в ответе не подтверждается.
`window` в `status` отражает состояние, управляемое OrbitFM, а не минимизацию WM.

## GUI

Раскладка Focus (Этап 8, фазы 1–4): HUD сверху (58 px), глобус занимает центр,
drawer справа (310 px, не более 42% ширины), transport снизу (48 px). При ширине
окна < 900 px drawer превращается в overlay поверх глобуса с кнопкой закрытия.
UI вынесен в `src/ui/`; модули возвращают `UiAction`, а `OrbitApp` применяет их
после отрисовки кадра. `UiAction` — внутренний тип, не публичный контракт.

- глобус: ЛКМ выбирает маркер станции или страну, ПКМ + перетаскивание вращает,
  колесо масштабирует; наведение на страну показывает контур, выбранная страна —
  акцентный контур с заливкой; курсор `PointingHand` над страной и маркером,
  `Grabbing` при вращении;
- клик по стране запускает поиск станций `countrycode=<ISO alpha-2>` (до 100,
  по голосам, `hide_broken=true`) и мягко доворачивает камеру к центру страны,
  в drawer показывается `Страна: …`; в режиме жанра drawer показывает
  `Жанр: …`, а клик по стране игнорируется;
- HUD «Страна» ищет страну по названию или ISO-коду: до 6 подсказок, Enter
  выбирает первую, клик — любую; выбор очищает запрос и запускает поиск станций;
- переключатель `Страна | Жанр` задаёт `SearchMode`; смена режима инвалидирует
  текущий поиск, очищает результаты, маркеры и локальные фильтры;
- в режиме «Жанр» кнопка выбора открывает popup с чипами Rock/Pop/Jazz/Electronic/
  News/Metal/Classical/Synthwave и полем своего тега (Enter или «Искать»);
  выбор запускает глобальный tag-поиск (`limit=200`, маркеры `limit=200`);
- в активном контексте (страна или жанр) кнопка HUD называется «Фильтр» и
  применяет поле к загруженному списку без сети; в свободном поиске — «Найти»;
- панель фильтрует результаты локально по имени/тегам/стране/штату,
  жанровым чипам All/Rock/Pop/Jazz/Electronic/News/Metal и сортирует по
  популярности, битрейту или имени; фильтры не делают сетевых запросов;
- каждый поиск дополнительно запрашивает станции с координатами
  (`has_geo_info=true`) для маркеров: 100 для названия/страны, 200 для жанра;
  маркеры группируются по координатам с округлением до 2 знаков, дубликаты по
  UUID отбрасываются;
- маркерам назначается вес 0..1 из голосов (sqrt-сжатие к 5000) и битрейта
  (линейно к 320), смесь 70/30; вес группы — максимум по станциям; радиус и
  свечение растут с весом, активная станция получает +2 px;
- ответы поиска несут номер поколения; ответ прошлого режима/жанра отбрасывается,
  поэтому старые маркеры не возвращаются после смены контекста;
- маркеры рисуются egui-оверлеем после `paint_globe`; наведение в радиусе 10 px
  показывает подпись, клик запускает станцию, текущая станция подсвечена;
- строка «На карте: N станций» показывает число пригодных станций;
- HUD: логотип, поле поиска и кнопка «Найти» (Enter в поле также запускает поиск),
  now-playing с состоянием, громкость, кнопка «Список» и меню «Настройки»
  (тема, акцент, скрыть окно, выход);
- drawer: вкладки «Результаты / Избранное (N) / История (N)» показываются, если есть
  результаты или сохранённые станции; новый поиск возвращает вкладку «Результаты»;
  список прокручивается на всю высоту drawer; сворачивание — «Список» или «×»;
- у каждой строки списка и у текущей станции в transport есть звезда: она добавляет
  станцию в избранное или убирает её оттуда; кнопки рисуются векторно и не зависят
  от глифов шрифта;
- успешный запуск станции записывается в начало истории; в истории доступна кнопка
  «Очистить историю»; подтверждение и ошибки библиотеки показываются тостом;
- transport: play/pause, stop, звезда, «Рулетка», `codec · kbps · страна` текущей
  станции и чекбокс «FFT»; без станции показывается «поток без параметров»/«Эфир не выбран»;
- «Рулетка» запрашивает случайную станцию с координатами (до трёх попыток),
  запускает её, перелетает камерой к точке за 900 мс и показывает тост с названием
  и страной; ошибка показывается тостом и не прерывает текущий эфир; кнопка
  заблокирована, пока запрос выполняется;
- MPRIS: artist — «штат, страна» (или одно из них), иначе теги; artUrl — favicon,
  title и URL станции без изменений;
- тост показывает одно сообщение 3 секунды внизу по центру; подсказка первого
  запуска исчезает через 10 секунд или после взаимодействия с глобусом;
- состояние поиска (`Поиск…`), ошибки каталога и «Станции не найдены» отображаются
  в drawer;
- при отсутствии `wgpu_render_state` вместо глобуса показывается «3D-глобус недоступен»;
- чекбокс «FFT» включает экспериментальный визуализатор; при включении внизу области
  глобуса рисуется спектральная огибающая `FFT · <частота> · <RMS> дБ`,
  ошибка фильтра показывается тостом и не прерывает воспроизведение;
- при активном воспроизведении статус содержит UUID и имя станции.

## Зависимости

`OrbitApp` использует конкретные реализации (`AudioEngine`, `GeoService`,
`RadioBrowserClient`, `MediaControls`, `StationLibrary`, `SettingsStore`,
`GlobeCamera`) и каналы `tokio::sync` как границы. Подмена реализаций в тестах не требуется; модульные тесты
проверяют чистые функции (`format_status`, `playback_label`, `station_label`,
`country_label`, `truncate`), геометрию иконок и логику внутри модулей.
