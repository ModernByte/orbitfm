# Интерфейс: Application Core

Application Core не экспортирует публичный трейт для других crate’ов — он является точкой сборки.

Тем не менее, фиксируем контракт поведения:

## Обязанности

1. Инициализировать все подсистемы в корректном порядке.
2. Реализовывать `eframe::App`.
3. Маршрутизировать `IpcCommand` и `MediaCommand` в соответствующие модули.
4. Управлять видимостью окна (show/hide, а не destroy).
5. При клике по глобусу:
   - при попадании в маркер станции (радиус 10 px) запустить представителя группы;
   - иначе получить точку на сфере от `GlobeCamera::screen_to_sphere`
   - спросить страну у `GeoService::country_at_sphere_point`
   - запросить станции страны через `RadioBrowserClient` с фильтром `countrycode`
   - обновить UI (заголовок страны, результаты, пустое состояние)
6. Для каждого поиска параллельно запрашивать гео-станции (`has_geo_info=true`,
   `limit=60`) и строить маркеры; ошибка гео-запроса не влияет на список.
7. Хранить избранное и историю через `StationLibrary`: записывать станцию в историю
   при успешном запуске и переключать избранное по действию пользователя.

## Порядок инициализации

Текущий (Этап 7):

```
1. IpcServer::try_bind()          — ошибка AlreadyRunning → повторная отправка команды
2. AudioEngine::new()             — ошибка фатальна для запуска
3. GeoService::from_embedded()    — ошибка фатальна: без границ стран нет поиска
4. MediaControls::new(wake)       — ошибка логируется, приложение работает без MPRIS
5. RadioBrowserClient::new()      — без сетевых обращений
6. StationLibrary::load_default() — ошибка логируется, используется ephemeral()
7. фоновая задача refresh_servers — прогрев пула; ошибка только логируется
8. фоновая задача: audio events → wake()
9. IpcServer::run(wake, shutdown) — accept-loop
10. eframe::run_native + OrbitApp — GUI, после закрытия которого сервер
                                    останавливается и сокет удаляется
11. OrbitApp::new                 — создаёт GlobeRenderer из wgpu_render_state
                                    и кладёт его в callback_resources
```

`GeoService` создаётся до `MediaControls`, чтобы ошибка датасета проявилась раньше
инициализации D-Bus. Если `wgpu_render_state` недоступен, приложение продолжает
работать без 3D-глобуса (`globe_ready = false`).

## Реакция на команды

| Команда       | Действие |
|---------------|----------|
| Toggle/Show/Hide | Изменение `window_visible` + ViewportCommand |
| Play          | Поиск станции в результатах последнего поиска, затем `radio.get_station` (таймаут 8 с); `audio.play(url_resolved)`, запись в историю, асинхронный `radio.send_click`, обновление media |
| Stop          | `audio.stop()`; последний URL и станция сохраняются для повторного запуска из MPRIS |
| Volume        | `audio.set_volume(level)`, обновление media |
| Status        | `status <state>`, при активной станции `stationuuid`/`name`, затем `volume <0.00>` и `window visible\|hidden` |
| Quit          | Корректное завершение всех подсистем и выход |

`MediaCommand` обрабатывается в том же цикле:

| Команда | Действие |
|---------|----------|
| Play | снять паузу; если поток остановлен — повторно запустить последний URL |
| Pause | поставить на паузу |
| PlayPause | переключить в зависимости от `PlaybackState` |
| Stop | `audio.stop()` |
| SetVolume | `audio.set_volume()` |
| Next/Previous | не действуют: переключение станций вне текущего объёма |

Аудио-вызовы из синхронного `logic()` выполняются через
`tokio::runtime::Handle::block_on`; сами операции короткие (ответ аудио-потока с
таймаутом 3 с). Поиск станций выполняется асинхронно: результат приходит в
`mpsc`-канал, `WakeFn` будит GUI.

Ответ клиенту формируется после обновления состояния App и отправки `ViewportCommand`;
применение команды оконным менеджером асинхронно и в ответе не подтверждается.
`window` в `status` отражает состояние, управляемое OrbitFM, а не минимизацию WM.

## GUI

- глобус: ЛКМ выбирает маркер станции или страну, ПКМ + перетаскивание вращает,
  колесо масштабирует;
- клик по стране запускает поиск станций `countrycode=<ISO alpha-2>` (до 30,
  по голосам, `hide_broken=true`), в карточке показывается `Страна: …`;
- каждый поиск дополнительно запрашивает до 60 станций с координатами
  (`has_geo_info=true`) для маркеров; маркеры группируются по координатам с
  округлением до 2 знаков, дубликаты по UUID отбрасываются;
- маркеры рисуются egui-оверлеем после `paint_globe`; наведение в радиусе 10 px
  показывает подпись, клик запускает станцию, текущая станция подсвечена;
- строка «Маркеры: N станций с координатами» показывает число пригодных станций;
- поле поиска и кнопка «Найти» (Enter в поле также запускает поиск);
- до 30 результатов, отсортированных по голосам; выбор строки запускает станцию;
- вкладки «Результаты / Избранное (N) / История (N)» показываются, если есть
  результаты или сохранённые станции; новый поиск возвращает вкладку «Результаты»;
- у каждой строки списка и у текущей станции есть звезда: она добавляет станцию в
  избранное или убирает её оттуда;
- успешный запуск станции записывается в начало истории; в истории доступна кнопка
  «Очистить историю»;
- ошибки чтения/записи библиотеки показываются в карточке и не прерывают
  воспроизведение;
- состояние поиска (`Поиск…`), ошибки каталога и «Станции не найдены» отображаются
  в карточке;
- при отсутствии `wgpu_render_state` вместо глобуса показывается «3D-глобус недоступен»;
- чекбокс «FFT» в заголовке включает экспериментальный визуализатор; при включении
  внизу области глобуса рисуется спектральная огибающая `FFT · <частота> · <RMS> дБ`,
  ошибка фильтра показывается в карточке и не прерывает воспроизведение;
- при активном воспроизведении статус содержит UUID и имя станции.

## Зависимости

`OrbitApp` использует конкретные реализации (`AudioEngine`, `GeoService`,
`RadioBrowserClient`, `MediaControls`, `StationLibrary`, `GlobeCamera`) и каналы
`tokio::sync` как границы. Подмена реализаций в тестах не требуется; модульные тесты
проверяют чистые функции (`format_status`, `playback_label`, `station_label`,
`country_label`, `truncate`) и логику внутри модулей.
