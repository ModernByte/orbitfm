# Интерфейс: Локализация

Контракт каталога строк и выбора языка (ADR-0030). Модуль `src/i18n` зависит
только от `settings::Language` и std; egui, session и services сюда не входят.

```rust
/// Язык интерфейса. `System` — способ выбрать язык, а не язык каталога.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum Language {
    #[default]
    System,
    English,
    Russian,
    French,
    German,
    Spanish,
    Italian,
    Portuguese,
    Chinese,
    Korean,
    Japanese,
}

impl Language {
    pub const ALL: [Self; 11];

    /// Стабильный код для `settings.json`: `system`, `en`, `ru`, ….
    pub fn code(self) -> &'static str;
    /// Название языка в нём самом.
    pub fn native_name(self) -> &'static str;
    pub fn from_code(code: &str) -> Option<Self>;
    /// `ru_RU.UTF-8`, `de_DE@euro`, `pt-BR` → язык; `C`/`POSIX` → English.
    pub fn from_tag(tag: &str) -> Option<Self>;
    /// `System` → язык из `LC_ALL`/`LC_MESSAGES`/`LANG`; никогда не `System`.
    pub fn resolve(self) -> Self;
}

/// Каталог уже разрешённого языка; английский — fallback.
pub(crate) fn catalog(language: Language) -> &'static Catalog;

/// Подстановка именованных плейсхолдеров: `{count}`, `{total}`, `{station}`,
/// `{country}`, `{genre}`, `{name}`, `{tags}`.
pub(crate) fn fill(template: &str, args: &[(&str, &str)]) -> String;

pub(crate) fn theme_label(ui: Language, theme: ThemeMode) -> &'static str;
pub(crate) fn accent_label(ui: Language, accent: AccentColor) -> &'static str;
pub(crate) fn motion_label(ui: Language, motion: MotionReactivity) -> &'static str;
pub(crate) fn style_label(ui: Language, style: MotionStyle) -> &'static str;
/// `System` показывает подпись каталога, остальные — `native_name()`.
pub(crate) fn language_label(ui: Language, value: Language) -> &'static str;
```

## Каталог

`Catalog` — это struct с вложенными группами: `common`, `hud`, `panel`,
`transport`, `capsule`, `overlay`, `settings`, `tray`, `notices`, `labels`.
Поля — `&'static str`. Каждый языковой файл — литерал `Catalog`, поэтому
пропущенное поле — ошибка компиляции, а не пустая строка в интерфейсе.
Каталогов десять: английский источник и девять переводов. `catalog` —
исчерпывающий `match` по `Language`, поэтому новый вариант enum не соберётся,
пока для него нет каталога: список языков и список строк расходятся на этапе
компиляции, а не в рантайме. `Language::System` читает английский источник —
`Session` резолвит окружение до того, как язык доходит до UI.

## Границы

Переводится пользовательский интерфейс: HUD, панель, transport, капсулы,
help/legend, drawer, трей, тосты, AccessKit-подписи.

Не переводятся: CLI-справка, IPC-протокол и `status`, заголовки окон
(`OrbitFM`, `OrbitFM · Overlay`, `OrbitFM · Listening`), app-id, названия
станций/стран/тегов из Radio Browser, MPRIS-метаданные и технические `detail`
ошибок.

## Смена языка

`Session::effective_language()` возвращает resolved язык настроек.
`Session::set_language(language)` сохраняет выбор и обновляет снимок трея;
UI читает каталог на следующем кадре. Перезапуск не нужен. `TraySnapshot`
содержит resolved `language`, поэтому меню перестраивается при изменении
снимка.
