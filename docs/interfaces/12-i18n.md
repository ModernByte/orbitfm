# Интерфейс: Локализация

Контракт каталога строк и выбора языка (ADR-0030). Модуль `src/i18n` зависит
только от `settings::Language` и std; egui, session и services сюда не входят.

```rust
/// Язык интерфейса. `System` — способ выбрать язык, а не язык каталога.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub enum Language {
    #[default]
    System,
    English,
    Russian,
    Ukrainian,
    Polish,
    French,
    German,
    Spanish,
    Italian,
    Portuguese,
    Turkish,
    Arabic,
    Hindi,
    Indonesian,
    Chinese,
    Korean,
    Japanese,
}

impl Language {
    pub const ALL: [Self; 17];

    /// Стабильный код для `settings.json`: `system`, `en`, `ru`, ….
    pub fn code(self) -> &'static str;
    /// Название языка в нём самом.
    pub fn native_name(self) -> &'static str;
    pub fn from_code(code: &str) -> Option<Self>;
    /// `ru_RU.UTF-8`, `de_DE@euro`, `pt-BR` → язык; `C`/`POSIX` → English.
    pub fn from_tag(tag: &str) -> Option<Self>;
    /// `System` → язык из `LC_ALL`/`LC_MESSAGES`/`LANG`; никогда не `System`.
    pub fn resolve(self) -> Self;
}

/// Каталог уже разрешённого языка; английский — fallback.
pub(crate) fn catalog(language: Language) -> &'static Catalog;

/// Подстановка именованных плейсхолдеров: `{count}`, `{total}`, `{station}`,
/// `{country}`, `{genre}`, `{name}`, `{tags}`.
pub(crate) fn fill(template: &str, args: &[(&str, &str)]) -> String;

pub(crate) fn theme_label(ui: Language, theme: ThemeMode) -> &'static str;
pub(crate) fn accent_label(ui: Language, accent: AccentColor) -> &'static str;
pub(crate) fn motion_label(ui: Language, motion: MotionReactivity) -> &'static str;
pub(crate) fn style_label(ui: Language, style: MotionStyle) -> &'static str;
/// `System` показывает подпись каталога, остальные — `native_name()`.
pub(crate) fn language_label(ui: Language, value: Language) -> &'static str;
```

## Каталог

`Catalog` — это struct с вложенными группами: `common`, `hud`, `panel`,
`transport`, `capsule`, `overlay`, `settings`, `tray`, `notices`, `labels`.
Поля — `&'static str`. Каждый языковой файл — литерал `Catalog`, поэтому
пропущенное поле — ошибка компиляции, а не пустая строка в интерфейсе.
Каталогов шестнадцать: английский источник и пятнадцать переводов (ru, uk,
pl, fr, de, es, it, pt, tr, ar, hi, id, zh, ko, ja). `catalog` —
исчерпывающий `match` по `Language`, поэтому новый вариант enum не соберётся,
пока для него нет каталога: список языков и список строк расходятся на этапе
компиляции, а не в рантайме. `Language::System` читает английский источник —
`Session` резолвит окружение до того, как язык доходит до UI.

Арабский каталог переводит строки, но не меняет направление раскладки: egui
0.37 не поддерживает bidi-зеркалирование, поэтому порядок элементов остаётся
слева направо. Это ограничение UI, а не контракта каталога.

## Подписи раздела «Статистика»

Раздел статистики прослушивания (ADR-0049, `docs/interfaces/17-stats.md`) живёт
в окне настроек, поэтому его строки принадлежат группе `settings`
(`SettingsText`) и именованы по существующей схеме: имя категории — короткое поле
без суффикса (как `appearance`, `window`, `about`), подзаголовок страницы —
`*_page_hint`, подсказка контрола — `*_hint`.

| Ключ | Назначение |
|------|------------|
| `stats` | Подпись категории «Статистика» и заголовок раздела |
| `stats_page_hint` | Подзаголовок страницы категории |
| `stats_hint` | Подсказка под суммарной строкой раздела |
| `stats_total` | Подпись суммарного прослушанного времени |
| `stats_week` | Подпись времени за последние 7 календарных дат |
| `stats_month` | Подпись времени за последние 30 календарных дат |
| `stats_stations` | Заголовок списка топ-10 станций |
| `stats_countries` | Заголовок списка топ-10 стран |
| `stats_tags` | Заголовок списка топ-10 тегов |
| `stats_enabled` | Подпись тумблера учёта (`controls::switch_row`) |
| `stats_enabled_hint` | Подсказка тумблера: учёт только на устройстве |
| `stats_clear` | Кнопка «Очистить» |
| `stats_clear_confirm` | Подпись подтверждения очистки |
| `stats_empty` | Пустое состояние раздела, когда счётчиков нет (по образцу `favorites_empty`, `history_empty`) |
| `stats_cleared` | Ответная строка раздела сразу после очистки; IPC-ответ `ok stats cleared` не переводится |
| `stats_duration` | Подпись длительности в строке списка |
| `stats_duration_minutes` | Шаблон минут: `{minutes}` — число минут |
| `stats_duration_hours` | Шаблон часов: `{hours}` и `{minutes}` |

Шаблоны длительности подставляются через `fill` ровно как
`settings.sleep_minutes` («`{minutes} min`»), поэтому тест каталога требует
одинакового набора плейсхолдеров во всех каталогах. Строки переводятся на все
16 языков — `Language::System` читает английский источник (см. «Каталог» выше).
Новые `NoticeKey` не появляются: ошибки записи по-прежнему отдаются
существующим тостом `SettingNotSaved` (ADR-0049 § 7).
Объект `ui` ответа `stats --json` (интерфейс 17 § 5) берёт подписи из этой же
группы, как `ui` в `status --json`.

## Границы

Переводится пользовательский интерфейс: HUD, панель, transport, капсулы,
help/legend, окно настроек, трей, тосты, AccessKit-подписи.

Не переводятся: CLI-справка, IPC-протокол и `status`, заголовки окон
(`OrbitFM`, `OrbitFM · Overlay`, `OrbitFM · Listening`), app-id, названия
станций/стран/тегов из Radio Browser, MPRIS-метаданные и технические `detail`
ошибок.

## Смена языка

`Session::effective_language()` возвращает resolved язык настроек.
`Session::set_language(language)` сохраняет выбор и обновляет снимок трея;
UI читает каталог на следующем кадре. Перезапуск не нужен. `TraySnapshot`
содержит resolved `language`, поэтому меню перестраивается при изменении
снимка.
