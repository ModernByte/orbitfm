# Интерфейс: экспорт и импорт библиотеки (схема 1)

**Организация:** ModernByte  
**Дата:** 2026-11-03  
**Статус:** Контракт схемы 1 (ADR-0046)

Переносимый JSON-снимок избранного и истории для desktop → Android Companion
и обратно. Формат версионируется полем `schema`; ломающие изменения требуют
`schema: 2` и нового раздела здесь.

## 1. Назначение

- перенести библиотеку между desktop-экземплярами и будущим Android-приложением
  без аккаунта, сервера и сетевой синхронизации;
- дать стабильный контракт для импорта на Kotlin без чтения внутреннего
  `library.json`;
- не ослаблять политику публичных URL: файл недоверенный.

## 2. Транспорт и команды

| Команда | Действие | Ответ |
|---------|----------|-------|
| `library-export <path>` | Сериализовать библиотеку и атомарно записать файл | `ok exported <favorites>` |
| `library-import <path>` | Прочитать файл и слить с локальной библиотекой | `ok imported <favorites> favorites, <history> history, <skipped> skipped` |

`<path>` — остаток строки после имени команды; пробелы в пути допустимы.
Относительный путь разрешается от текущего каталога процесса, абсолютный
используется как есть. Пустой путь — `error`.

Браузерный native host не получает эти команды: allowlist отвечает
`forbidden`. IPC-сокет доступен только текущему пользователю, поэтому право
писать файл не шире обычных прав процесса.

## 3. Схема

```json
{
  "schema": 1,
  "app": "orbitfm",
  "exported_at": 1762137600,
  "favorites": [],
  "history": []
}
```

| Поле | Тип | Обязательность | Смысл |
|------|-----|----------------|-------|
| `schema` | integer | да (при импорте) | Версия формата; поддерживается только `1` |
| `app` | string | нет | `"orbitfm"`; пустая строка допустима, чужое значение — ошибка |
| `exported_at` | integer | нет | Unix-время экспорта в секундах, информационное |
| `favorites` | array | нет | Избранные станции |
| `history` | array | нет | История прослушивания, новые записи первыми |

Станция — те же поля, что в `library.json` и `status --json`:

```json
{
  "stationuuid": "960cf833-0601-11e8-ae97-52543be04c81",
  "name": "SomaFM Groove Salad",
  "url": "http://ice1.somafm.com/groovesalad-128-mp3",
  "url_resolved": "https://ice1.somafm.com/groovesalad-128-mp3",
  "homepage": "https://somafm.com",
  "favicon": "https://somafm.com/img3/groovesalad-400.png",
  "tags": "ambient,chillout",
  "countrycode": "US",
  "language": "english",
  "votes": 120,
  "country": "The United States Of America",
  "state": "California",
  "bitrate": 128,
  "codec": "MP3",
  "geo_lat": 37.7749,
  "geo_long": -122.4194,
  "source": "radio"
}
```

- `stationuuid` — ключ слияния и обязательное поле импорта; пустой UUID
  отбрасывается.
- `url` и `url_resolved` — публичный `http(s)` без userinfo. Если одно поле
  пустое, оно заполняется вторым до проверки.
- `homepage` и `favicon` — необязательные публичные `http(s)`; непрошедшая
  проверка ссылка становится `null`, станция при этом сохраняется.
- `geo_lat`/`geo_long` — оба в диапазонах `-90..=90` и `-180..=180` или оба
  `null`.
- `source` — `radio` (каталог Radio Browser) или `stream` (внешний поток из
  `play-url`, ADR-0040). Отсутствующее поле читается как `radio`.

## 4. Экспорт

1. Берётся текущее избранное и история в порядке хранения.
2. Строки санитизируются: управляющие символы схлопываются, длина ограничена
   (UUID 64, имя 256, URL 2048, теги 512, страна/язык/регион 128).
3. JSON сериализуется с отступами для читаемости.
4. Запись идёт через `storage::write_atomic`: временный файл в том же
   каталоге → `fsync` → `rename` → `fsync` каталога на Unix.
5. На Unix файл получает права `0600`: он содержит stream URL пользователя.

Экспорт не меняет библиотеку и не требует открытого окна. Родительский каталог
создаётся. Снимок отражает библиотеку как есть, включая синтетические
`stream`-станции из `play-url`: их локальные адреса может отклонить импорт
(см. §5).

## 5. Импорт

Импорт — **слияние**, а не замена. Алгоритм:

1. Прочитать файл; если размер больше 2 МиБ — ошибка до разбора.
2. Разобрать JSON; проверить `schema == 1` и `app ∈ {"", "orbitfm"}`.
3. Если суммарно станций больше 5000 — ошибка.
4. Для каждой станции из `favorites`, затем из `history`:
   - санитизировать строки и проверить URL/координаты;
   - пропустить без UUID или с непрошедшим URL, увеличив `skipped`;
   - пропустить дубликат UUID внутри локальной библиотеки и внутри файла;
   - иначе добавить в конец соответствующего списка.
5. Нормализовать историю: дедупликация и обрезка до `HISTORY_LIMIT` (20).
6. Сохранить `library.json`, если появилось хотя бы одно добавление.

Локальная запись при совпадении UUID побеждает: имя, URL и метаданные
пользователя не перезаписываются импортом. Одинаковые UUID в `favorites` и
`history` допустимы — это разные списки.

Ответ содержит фактически добавленные значения. Для файла только с публичными
станциями повторный импорт даёт `ok imported 0 favorites, 0 history, 0 skipped`.
Локальные `stream`-станции с приватными или link-local адресами экспортируются
как часть библиотеки, но при импорте не проходят политику публичных URL: они
пропускаются и каждый раз попадают в `skipped`. Это осознанное ограничение
переноса, а не ошибка слияния.

## 6. Ошибки

| Причина | Ответ |
|---------|-------|
| Файл не читается | `error <путь>: <io-ошибка>` |
| Файл больше 2 МиБ | `error <путь>: файл больше 2097152 байт` |
| Невалидный JSON | `error импорт: <serde-сообщение>` |
| `schema` не 1 | `error импорт: поддерживается schema 1, получено N` |
| Чужой `app` | `error импорт: приложение X не поддерживается` |
| Больше 5000 станций | `error импорт: больше 5000 станций` |
| Пустой путь | `error library-import: ожидается путь к файлу` |
| Ошибка записи `library.json` | `error не удалось сохранить библиотеку: …` |

Некорректная отдельная станция не отменяет импорт: она попадает в `skipped`.

## 7. Безопасность

- Файл недоверенный: никаких `file://`, `data:`, приватных literal-адресов,
  link-local и URL с userinfo.
- Проверка выполняется до сохранения и до любого воспроизведения.
- Импорт не ходит в сеть и не запускает станции.
- Экспорт не пишет ничего, кроме указанного пути и временного файла рядом.
- Android-клиент обязан повторить те же правила; общая таблица классов
  запретов — ADR-0025.

## 8. Совместимость и Android

- `schema` растёт только при удалении/переименовании полей или изменении
  семантики. Новые поля добавляются без смены версии.
- Android v1 читает и пишет только схему 1; неизвестная версия — понятная
  ошибка пользователю, без частичного импорта.
- `library.json` desktop не является публичным контрактом; Android работает
  только с этим форматом.
- `exported_at` не влияет на слияние и может отсутствовать.

## 9. Тесты

- roundtrip export → import публичных станций без потерь и без дублей;
- повторный импорт публичного файла даёт нулевые добавления;
- локальные `stream`-станции экспортируются, но импортом пропускаются
  (`skipped`), в том числе при повторном импорте;
- `schema: 2` и чужой `app` отклоняются;
- файл > 2 МиБ и > 5000 станций отклоняются;
- приватные, link-local, `file://` и userinfo URL пропускаются;
- управляющие символы вычищаются, координаты вне диапазона обнуляются;
- Unix-права экспортированного файла — `0600`, временный файл убран;
- локальная запись побеждает при совпадении UUID.
