# Модуль: Настройки оформления

**Путь в коде:** `src/settings/*`  
**Ответственность:** Хранение темы, акцентного цвета, языка, параметров визуализатора, аудио-движения и opt-in HTTP-обложек, локальная персистентность.  
**Зависимости:** serde, serde_json, thiserror

---

## 1. Назначение

Единственная точка работы с пользовательскими предпочтениями оформления.  
Модуль не зависит от egui и GUI: он хранит перечисления `ThemeMode`,
`AccentColor`, `MotionReactivity` и `MotionStyle`, а Application Core применяет
их к стилям, палитре и движению глобуса. Решения — ADR-0014, ADR-0019,
ADR-0028.

## 2. Состав модуля

| Файл | Назначение |
|------|------------|
| `mod.rs` | `SettingsStore`, `Settings`, `ThemeMode`, `AccentColor`, `MotionReactivity`, `MotionStyle`, `VIZ_BAR_CHOICES`, `default_path` |
| `language.rs` | `Language`, разрешение `System` из локалей, `deserialize_language` для устойчивости к неизвестному коду (ADR-0030) |

## 3. Данные

| Поле | Значения | По умолчанию |
|------|----------|--------------|
| `theme` | `system`, `dark`, `light` | `system` |
| `accent` | `blue`, `green`, `amber`, `violet`, `rose`, `cyan` | `blue` |
| `language` | `system`, `en`, `ru`, `fr`, `de`, `es`, `it`, `pt`, `zh`, `ko`, `ja`; неизвестный код не ломает файл | `system` |
| `viz_bars` | 16, 24, 32 (иное притягивается к ближайшему) | 24 |
| `volume` | `0.0..=1.0`, вне диапазона клампится при загрузке и записи | `0.7` |
| `visualizer_enabled` | визуализатор и аудиокольцо | `true` |
| `artwork_allow_http` | разрешить favicon по HTTP, если HTTPS недоступен (ADR-0025 ред. 3) | `false` |
| `help_visible` | видимость карточки управления глобусом; `?` в HUD, тумблер окна настроек и `Esc` пишут выбор (ADR-0036) | `true` |
| `motion` | `off`, `low`, `normal`, `high` | `normal` |
| `motion_style` | `auto`, `soft-pulse`, `groove-sway`, `bass-drop`, `ambient-drift`, `sparkle-twitch`, `beat-march` | `auto` |
| `allow_flips` | перевороты камеры на onset | `false` |
| `reduce_motion` | отключает геометрию и качку, эфир продолжается | `false` |

Акценты — пресеты с фиксированными RGB-компонентами (`AccentColor::rgb`).
Произвольный цвет отложен: перетаскивание color picker приводило бы к записи
файла несколько раз в секунду.

`MotionReactivity` задаёт пределы `squash_limit` (2,5/5,0/9,0 % для
Low/Normal/High), `ripple_limit` (0,50/1,00/1,80 %) и `idle_amplitude`
(0,7/0,7/1,0 %); `capped` ограничивает режим окна. `MotionStyle` содержит
`Auto` и шесть стилей; `ALL` питает список выбора окна настроек, `id` уходит в
`CameraUniform.motion2.y`, `requires_bands` задаёт деградацию без полос. Подписей
у самих enum'ов нет — строки даёт `i18n::labels` (ADR-0030).
`Auto` — значение по умолчанию: стиль выбирается по сглаженным признакам
сигнала с удержанием 3 с и кроссфейдом 1 с (Phase 2). При выключенной
реактивности глобус вращается сам в простое (ADR-0023, развитие 2026-10-27);
под секцией Motion об этом предупреждает `motion_spin_hint`.

## 4. Персистентность

```
$XDG_CONFIG_HOME/orbitfm/settings.json
$HOME/.config/orbitfm/settings.json   (если XDG_CONFIG_HOME не задан/относителен)
```

- Формат — JSON `{ "theme": "...", "accent": "..." }`, читаемый вручную.
- Запись атомарная: `settings.json.tmp` + `rename`; каталог создаётся при
  необходимости.
- Запись синхронная и только при изменении значения; повторная установка того же
  значения не пишет файл.
- Отсутствующий файл — значения по умолчанию, не ошибка.
- Повреждённый JSON — `SettingsError::Parse`; Application Core создаёт
  `SettingsStore::ephemeral()`, которая не пишет файл, поэтому повреждённые данные
  не теряются.
- Ошибки записи не прерывают воспроизведение; GUI показывает их тостом.

## 5. Применение в GUI

- `configure_style(ctx, settings)` вызывается при старте и после каждого
  изменения: `Context::set_theme` получает `System`/`Dark`/`Light`,
  для обеих тем настраиваются прозрачные `panel_fill`/`window_fill`.
- `selection.bg_fill` и `hyperlink_color` используют акцент; цвет текста на
  выделении выбирается по яркости акцента.
- `Palette::for_ui(theme, accent)` вычисляет цвета панелей, приглушённого текста,
  ошибок, подложек и маркеров. В светлой теме акцент для текста затемняется,
  маркеры остаются яркими.
- Маркеры глобуса используют один цвет `palette.marker` (ADR-0012, обновление
  Этапа 9); качества и рейтинга в цвете больше нет.
- Окно настроек (ADR-0031) содержит выбор темы и шесть акцентных образцов;
  ошибки хранилища показываются локализованным тостом.
- Секция `Motion` в окне настроек: `dropdown` реактивности `Off`/`Low`/`Normal`/`High`,
  тумблеры `Reduce motion` и `Allow flips`, `dropdown` `Motion style` (`Auto`
  или один из
  шести стилей); изменения применяются сразу и сохраняются. `Allow flips`
  недоступен при `Off` и `reduce_motion`. При `reduce_motion` эффективная
  реактивность — `Off`, авто-вращение остановлено, но настройка `motion` не
  перезаписывается. Под строками — подсказка `motion_spin_hint`: без
  реактивности глобус вращается сам.
- Число столбцов визуализатора (`viz_bars`), видимость визуализатора
  (`visualizer_enabled`) и язык (`language`) меняются там же; громкость
  пишется по отпусканию слайдера, а клик, клавиша и щелчок колеса над ним —
  дискретный ввод, который пишет сразу (ADR-0031 § 8).
- Тумблер «Разрешить HTTP-обложки» (`artwork_allow_http`, категория «Внешний
  вид») сохраняет настройку и сразу переключает политику фетчера через
  `ArtworkFetcher::set_allow_http` (общий `AtomicBool`, ADR-0025 ред. 3).
  Включение дополнительно возвращает в очередь favicon, помеченные `Failed`,
  поэтому станции с HTTP-only обложкой подхватывают иконку без перезапуска и без
  повторного поиска.
- Чекбокс карточки управления (`help_visible`) — в секции `Window`: значение
  по умолчанию `true`, `?` в HUD и `Esc` меняют то же поле; старый ключ
  `help_seen` не читается, поэтому после обновления карточка снова видна
  (ADR-0036 § 5).

## 6. Ограничения

- Нет произвольного цвета, градиентов и пользовательских файлов тем.
- `System` следует теме, которую eframe получает от окружения; если оконный
  менеджер её не сообщает, egui использует тёмную тему.
- Настройки не синхронизируются между машинами и не доступны через IPC.
- Светлая палитра требует отдельной проверки контраста при добавлении новых
  элементов.

## 7. Тестирование

Unit-тесты в `src/settings/mod.rs` покрывают XDG-пути и fallback на `HOME`,
значения по умолчанию, roundtrip темы, акцента, языка, громкости, видимости
визуализатора, `artwork_allow_http` и `help_visible`, настроек движения
(включая `motion_style` и `allow_flips`), недостающие поля, повреждённый файл и
эфемерное хранилище.
Отдельно проверяются
устойчивость к неизвестному коду языка (`language: "klingon"` → `System`,
остальные поля сохраняются) и кламп громкости при загрузке и записи. В
`src/settings/language.rs` — уникальность кодов и нативных имён, roundtrip
кодов, разбор locale-тегов и приоритет `LC_ALL > LC_MESSAGES > LANG`.
В `app.rs` проверяются маппинг режима темы, выбор контрастного текста и
затемнение акцента в светлой палитре.

Живой тест: изолированные `XDG_CONFIG_HOME`/`XDG_DATA_HOME`, переключение
«Системная/Тёмная/Светлая» и акцентов, проверка `settings.json`, перезапуск и
сохранение выбора.
