# Модуль: Локализация

**Путь в коде:** `src/i18n/`  
**Ответственность:** Компилируемый каталог пользовательских строк и выбор языка.  
**Зависимости:** `settings::Language`, std. Без egui, session и сетевых слоёв.

---

## 1. Назначение

Единственная точка получения текста интерфейса. Решение — ADR-0030, контракт —
`docs/interfaces/12-i18n.md`.

## 2. Состав модуля

| Файл | Назначение |
|------|------------|
| `mod.rs` | `catalog`, `fill`, ре-экспорт подписей enum'ов |
| `catalog.rs` | `Catalog` и группы `CommonText`, `HudText`, `PanelText`, `TransportText`, `CapsuleText`, `OverlayText`, `SettingsText`, `TrayText`, `NoticeText`, `LabelText` |
| `en.rs` | английский источник и fallback |
| `ru.rs`, `fr.rs`, `de.rs`, `es.rs`, `it.rs`, `pt.rs`, `zh.rs`, `ko.rs`, `ja.rs` | девять переводов, по файлу на язык |
| `labels.rs` | подписи `ThemeMode`, `AccentColor`, `MotionReactivity`, `MotionStyle`, `Language` |

## 3. Выбор языка

`Language` хранится в настройках. `System` разрешается из
`LC_ALL` → `LC_MESSAGES` → `LANG`; пустые значения пропускаются, тег обрезается
по `.UTF-8`, `@modifier` и региону. `C`/`POSIX` и неизвестный язык дают
английский. `resolve` никогда не возвращает `System`.

Явно выбранный язык окружение не переопределяет. OrbitFM не вызывает
`setlocale`: меняется только текст приложения.

## 4. Каталог

Группы покрывают все поверхности: HUD, панель, transport, капсулы, overlay-
подсказки, окно настроек, трей, избранное, Notice-сообщения и подписи enum'ов.
Английский — источник истины; остальные языки повторяют структуру. Пустые
строки и расхождение `{placeholder}` с английским запрещены тестом каталога:
`fill` иначе молча оставит `{count}` в интерфейсе.

Динамические строки — шаблоны с именованными плейсхолдерами и `fill`. Правил
склонения нет: формулировки нейтральные (`Results ({count})`,
`{count} of {total}`).

## 5. Типизированные Notice

Application Core не импортирует этот модуль. `session::Notice` несёт
`NoticeKey` и технический `detail`; presentation переводит ключ и добавляет
`detail` как есть. Так ядро остаётся UI- и языко-агностичным.

## 6. CJK и emoji

eframe собирается с официальной фичей `system_fonts`: fontconfig находит
системный CJK-шрифт. Если шрифта нет, иероглифы будут tofu — документированная
зависимость окружения. Noto Color Emoji для флагов по-прежнему подключается
вручную в presentation-слое.

## 7. Тесты

- коды и нативные имена уникальны, коды round-trip;
- locale-теги (`ru_RU.UTF-8`, `de_DE@euro`, `pt-BR`, `C`, `POSIX`, мусор);
- приоритет `LC_ALL > LC_MESSAGES > LANG`;
- неизвестный код в JSON → `System`, остальные поля сохраняются;
- каждый каталог без пустых строк и с тем же набором `{placeholder}`, что у
  английского;
- каждый язык переводов отдаёт свой каталог, а не английский (сравнение
  указателей);
- `System` читает английский источник;
- `fill` подставляет все вхождения и не трогает неизвестные плейсхолдеры.
