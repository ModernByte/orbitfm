# Security and privacy

**Русский** · [English](../en/privacy.md)

Полная модель угроз — в [SECURITY.md](../../../SECURITY.md); здесь то, что
полезно знать, не открывая документ.

- **Управлять плеером может любой процесс вашего пользователя.** Команды идут по
  локальному транспорту: сокет `$XDG_RUNTIME_DIR/orbitfm.sock` с правами `0600` на
  Linux, `$TMPDIR/orbitfm-<uid>/orbitfm.sock` на macOS,
  `\\.\pipe\orbitfm-<хеш профиля>` на Windows. Каталог сокета принадлежит
  пользователю и закрыт от остальных; имя канала Windows своё у каждого профиля.
  Разграничения прав между процессами одного пользователя нет и быть не может —
  это приложение пользовательской сессии, а не сервис. Никаких сетевых портов
  OrbitFM не слушает вообще.
- **Станции — недоверенные данные.** Имя, страна и теги из общей базы очищаются от
  управляющих последовательностей и двунаправленных символов, а панели и бары
  получают их без права разметки: имя станции не может перекрасить чужой бар или
  подменить строку терминала.
- **Наружу уходит только необходимое:** запросы к зеркалам Radio Browser (поиск,
  карточка станции), счётчик кликов провайдера при запуске станции, сам поток и
  адрес обложки; резолв ссылки по явному `play-url` читает плейлист или страницу,
  но не больше 1 МиБ. Телеметрии, аналитики, фоновых опросов и обновлений «с
  собой» нет; User-Agent — `OrbitFM/1.0 (ModernByte; Linux; Rust)`.
- **Обложки грузятся по политике, а не как попало.** Ссылка `favicon` приходит из
  чужого каталога, поэтому адрес проходит два яруса: синтаксический (приватные и
  служебные диапазоны, `localhost`, `*.local`, `*.internal`, одноярлыковые хосты
  вроде `http://router/`, облачные метаданные) и по адресам DNS — все они обязаны
  быть публичными, а каждый редирект проверяется заново. По умолчанию работает
  только `https`: адрес `http` поднимается до `https`, а явный тумблер «Разрешить
  HTTP-обложки» — осознанный выбор владельца. Тот же вердикт по DNS решает, попадёт
  ли адрес в системные метаданные MPRIS/SMTC/Now Playing: он считается фоном и
  переиспользуется 60 секунд, поэтому домен, резолвящийся во внутреннюю сеть, не
  попадает в `artUrl`.
- **Длинная сессия не растёт бесконечно.** Кэш обложек держит не больше 256
  записей и не больше восьми загрузок в полёте, тело ответа — не больше 512 КиБ,
  сторона картинки — не больше 512 px.
- **Артефакты релиза не подписаны.** `SHA256SUMS` — контрольные суммы, а не
  подпись: сертификатов у проекта нет, поэтому проверяйте скачанное по суммам и
  берите сборки только из раздела Releases.

## Что хранится на диске

| Файл | Что внутри | Куда уходит |
|------|------------|-------------|
| `~/.config/orbitfm/settings.json` | тема, язык, громкость, компоновка, профиль сети, настройки сна | никуда |
| `~/.local/share/orbitfm/library.json` | избранное, история, ручные ссылки станций | никуда |
| `~/.local/share/orbitfm/stats.json` | минуты прослушивания по станциям, странам и тегам | никуда |
| `~/.local/share/orbitfm/cache/stations-snapshot.json` | офлайн-снимок каталога | никуда |

Аккаунтов, облачной синхронизации и телеметрии нет. Наружу уходят только запросы
к каталогу, потоку выбранной станции и адресу её обложки — как при любом сетевом
запросе, ваш IP-адрес виден вещателю.
