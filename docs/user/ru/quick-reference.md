# Шпаргалка

**Русский** · [English](../en/quick-reference.md)

← [Домой](index.md)

Всё, что нужно каждый день, на одной странице: режимы окна, команды, жесты,
файлы и числа. Каждый пункт ведёт на страницу, где он объяснён подробно.

## Режимы окна

| Режим | Размер | Как открыть |
|---|---|---|
| Focus | 1100×800 | `orbitfm show`, `orbitfm mode focus`, значок в трее |
| Overlay | 500×620 | `orbitfm overlay`, `orbitfm mode overlay` |
| Listening | 420×152 | `orbitfm mode listening` |
| Panel | 400×640 | `orbitfm panel` — выпадающая панель для бар-виджета |

Закрытие окна только скрывает его: эфир, трей, MPRIS и команды продолжают
работать. По-настоящему завершает процесс только `orbitfm quit`.
Подробности — [«Режимы окна»](window-modes.md).

## Команды

Без аргументов `orbitfm` работает как `toggle`. Команды окна запускают процесс,
если он ещё не идёт; командам воспроизведения, сна, статистики и библиотеки
нужен уже запущенный плеер.

| Задача | Команда |
|---|---|
| Показать / скрыть / выйти | `orbitfm show`, `orbitfm hide`, `orbitfm quit` |
| Сменить раскладку | `orbitfm mode focus\|overlay\|listening\|panel`, `orbitfm mode` (спросить) |
| Панель и капсула | `orbitfm panel`, `orbitfm overlay` |
| Состояние для скриптов | `orbitfm status`, `orbitfm status --json`, `orbitfm events` |
| Играть станцию из каталога | `orbitfm play <uuid>` |
| Играть внешний поток | `orbitfm play-url <url>` — `.m3u`, `.pls`, прямая ссылка или страница со звуком |
| Транспорт | `orbitfm playpause`, `orbitfm next`, `orbitfm previous`, `orbitfm roulette`, `orbitfm stop` |
| Громкость | `orbitfm volume 0.0–1.0`, `orbitfm volume-up`, `orbitfm volume-down` |
| Таймер сна | `orbitfm sleep <1–720>`, `orbitfm sleep clear` |
| Поведение таймера | `orbitfm sleep action nothing\|suspend\|power-off`, `orbitfm sleep fade 0\|60\|120\|180\|300`, `orbitfm sleep inhibit on\|off`, `orbitfm sleep warning on\|off` |
| Профиль сети | `orbitfm network unlimited\|metered\|offline-first` |
| Тема | `orbitfm theme system\|dark\|light` |
| Избранное | `orbitfm favorite`, `orbitfm favorite <uuid>` |
| Перенос библиотеки | `orbitfm library-export <файл>`, `orbitfm library-import <файл>` |
| Статистика прослушивания | `orbitfm stats`, `orbitfm stats --json`, `orbitfm stats clear` |
| Ручной адрес станции | `orbitfm alias <uuid> [<url>\|remove]`, `orbitfm alias list` |
| Окно настроек | `orbitfm settings` |
| Интеграции | `orbitfm integration status\|install\|uninstall <цель>` |

Полный список с объяснениями — [«Управление и горячие клавиши»](controls.md).

## Мышь

| Жест | Результат |
|---|---|
| Левый клик по стране | Выбрать страну: поворот камеры, подсветка, список станций |
| Левый клик по маркеру | Запустить станцию и прокрутить список к её строке |
| Перетаскивание правой кнопкой | Вращение глобуса; резкий взмах продолжает крутить его по инерции |
| Колесо | Зум; над ползунком — изменить значение на 5 % за щелчок |
| Наведение на страну | Контур и карточка с флагом, названием и числом станций |
| Клик вне стран | Снять выбор страны |

## Клавиатура

Клавиши работают, пока окно OrbitFM в фокусе; системных глобальных горячих
клавиш нет.

| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab` | Переход по элементам управления |
| `↑` / `↓` | Переход по списку станций |
| `Space` или `Enter` | Запустить выбранную станцию; `Space` без выбора — пуск/пауза |
| `/` или `Ctrl+F` (`Cmd+F`) | Перейти в поле поиска |
| `Enter` | Запустить поиск или выбрать первую подсказку |
| `Esc` | Закрыть настройки, затем карточку управления мышью |
| `Ctrl+,` (`Cmd+,`) | Открыть или закрыть настройки |

Медиа-клавиши и системный виджет плеера работают через MPRIS — [«Трей и MPRIS»](tray-and-mpris.md).

## Где лежат файлы

| Путь | Что там |
|---|---|
| `~/.config/orbitfm/settings.json` | Тема, язык, громкость, движение, поведение сна, профиль сети |
| `~/.local/share/orbitfm/library.json` | Избранное и история |
| `~/.local/share/orbitfm/stats.json` | Минуты прослушивания и топы |
| `~/.local/share/orbitfm/cache/stations-snapshot.json` | Офлайн-снимок карты |
| `~/.local/share/orbitfm/integrations/<цель>.json` | Квитанции установленных интеграций |
| `$XDG_RUNTIME_DIR/orbitfm.sock` | Локальный канал команд (права `0600`) |
| `~/.local/bin/orbitfm` | AppImage, поставленный установщиком одной командой |

В macOS сокет лежит в `$TMPDIR/orbitfm-<uid>/`, в Windows команды идут через
канал `\\.\pipe\orbitfm-<хеш профиля>`. Что хранится и что уходит в сеть —
[«Безопасность и приватность»](privacy.md).

## Числа и значения по умолчанию

| Значение | Смысл |
|---|---|
| 17 | Языков интерфейса: «Системный» плюс 16 |
| 70 % | Громкость по умолчанию; колесо и стрелки — шаг 5 %, `volume-up`/`volume-down` — 10 % |
| 16 / 24 / 32 | Столбцов визуализатора; по умолчанию 24 |
| 1–720 мин | Таймер сна из командной строки; в интерфейсе — 15 / 30 / 45 / 60 / 90 |
| 0–300 с | Затухание перед стопом; по умолчанию 300 с |
| 500 | Станций в офлайн-снимке |
| 1000 / 250 | Мировая выборка для карты: профиль unlimited / metered |
| 800 | Станций с координатами в слое карты страны |
| 100 / 200 / 100 | Страница каталога: страна / жанр / поиск по названию |
| 20 / 8 | Записей истории / станций избранного в капсуле Overlay |
| 10 | Станций, стран и жанров в топах статистики |
